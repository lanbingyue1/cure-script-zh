# **7. 否定形式与过去时里的形容词**

[**第 7 课：日语否定动词的秘密，以及形容词的 <code>conjugations</code>（活用）**](https://www.youtube.com/watch?v=KIPhvGxp43c&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=7)

今天我们要谈否定。而为了做到这一点，我们不得不介绍日语的一个根本秘密，学校和教科书几乎从来不会告诉你。它让整个日语变得容易得多得多。但在我们讲到那个之前，我们先看看日语否定的根本基础。

## 形容词 ない

**否定的根本基础是形容词 <code>ない</code>。** 这个形容词的意思是 <code>non-exist / not-be</code>（不存在 / 不是）。

![](../media/image1007.webp)

表示 <code>exist</code>（存在）的词——对任何物体、任何无生命的东西，天空、大海、宇宙、一粒米、一朵花、一棵树、任何东西——都是 <code>ある</code>。所以，如果我们想说 <code>There is a pen / A pen exists</code>（有一支笔 / 一支笔存在），我们说 <code>ペンがある</code>。但如果我们想说没有笔，我们说 <code>ペンがない</code>。

![](../media/image573.webp)

那么，为什么「存在」我们用动词，而「不存在」我们用形容词呢？因为这贯穿整个日语。每当我们 DO 某件事时，我们用一个动词。无论我们走路、唱歌、跑步还是别的什么——那都是一个动词。**但如果我们不做它，那我们就把 <code>ない</code> 附加到那个动词上，而那就成了这个句子的引擎。** 所以当我们说我们**不**在做某事时，**我们并不是在用动词，我们是在用形容词。**

为什么是这样呢？因为日语非常有逻辑。当我们做某件事时，一个动作正在发生。那是一个动词。但当我们不做它时，没有任何动作在发生，我们是在描述一种非动作的状态。所以，那是一个形容词。好。

所以，如果我们想说 <code>There is no pen</code>（没有笔），我们说 <code>ペンがない.</code> 但如果我们想说 <code>This is not a pen</code>（这不是一支笔）呢？那和前面并不完全是一回事，对吧？那么，我们要怎么说呢？

如果我们想说 <code>There is a pen</code>（有一支笔），如我们所知，我们说 <code>これは (</code>これ<code> – </code>this<code>)... これはペンだ</code>。<code>As for this, pen = / As for this, it's a pen.</code>（至于这个，笔 = / 至于这个，它是一支笔。）

![](../media/image230.webp)

![](../media/image37.webp)

:::

但如果我们想说 <code>This is not a pen</code>（这不是一支笔），我们说 <code>これは *(zeroが)* ペンではない</code>。

![](../media/image213.webp)

那意味着什么呢？**嗯，<code>で</code> 是 <code>だ</code> 或 <code>です</code> 的 て形。** 所以我们仍然保有 <code>これはペンだ</code>，只是形式变成了 <code>これはペンで</code>，然后我们附加上了 <code>ない</code>。所以我们说的是，<code>As for this, as for being a pen, it isn't / This is not a pen</code>（至于这个，至于作为一支笔，它不是 / 这不是一支笔）。好。

## 动词的否定形式

那么现在让我们进入这个问题最大的部分，也就是动词。为了把一个动词变成否定，**我们必须附加 <code>ない</code>，** **而我们是通过把它附加到 あ-词干上来做到这一点的。**

![](../media/image488.webp)

那意味着什么呢？嗯，让我们看看词干系统。日语动词词干系统是这世上最简单、最有逻辑、最美丽的动词变形系统。它几乎绝对规则。一旦你知道怎么做，你就能做出任何变形（除了 て形 和 た形，那些你都已经知道了）。

但学校和教科书不告诉你这个。它们不告诉你这个，而是把每一个 <code>conjugation</code>（它们这么叫它，而它们其实并非活用）……它们把每一个都呈现为一个单独的个例，配着看似随机的单独规则。而因为它们不告诉你整个系统的根本逻辑，又因为它们描述那些发生的变化时，仿佛它们真的是用罗马字母写的，而它们其实是用假名写的，它就真的看起来像那样。

---

学生们真的以为他们必须把每个个例当作独立的个例，为每个个例学习单独的规则。其实你不必。你只需要知道词干系统。

那让我们看看它。如我们已经学过的，每个动词都以一个 う 段假名结尾。我在这里把图表横过来放，原因你一会儿就会看到。所以红框里的这些假名是能够结束一个动词的假名。不是每一个 う 段假名，而是其中大多数。所以我们有像 <code>かう</code>（买）、<code>きく</code>（听）、<code>はなす</code>（说）、<code>もつ</code>（拿）等等这样的动词。

现在，如你所见，还有另外四种一个动词可能会以此结尾的方式。而这四种方式中的每一种都被使用，它们被称为动词词干。

![](../media/image36.webp)

今天我们只看 あ-词干，因为那是我们做否定所需要的。那么，要构成 あ-词干，我们只需把动词的最后一个假名从 う 段移到 あ 段。所以 <code>きく</code>（听）变成 <code>きか</code>，<code>はなす</code>（说）变成 <code>はなさ</code>，<code>もつ</code>（拿）变成 <code>もた</code>，等等。

![](../media/image816.webp)

这个系统里只有一个例外——我说「这个系统」时，我指的是整个系统、所有词干——只有这一个例外，那就是**当一个词以 う 假名结尾时，词干不变成 <code>-あ</code>，而是变成 <code>わ</code>。** 所以 <code>かう</code> 的否定不是 <code>かあない</code>，而是 <code>かわない</code>。而只有 あ-词干 里我们才有这个例外，所以那是整个系统里唯一的例外，而你能看出它为什么存在：<code>かあない</code> 并不像 <code>かわない</code> 那样好念，对吧？

**所有其他的都完全规则。** <code>きく</code>（听）变成 <code>きかない</code>（不听）；<code>はなす</code>（说）变成 <code>はなさない</code>（不说）；<code>もつ</code>（拿）变成 <code>もたない</code>（不拿），等等。

而如我们已经知道的，**对于一段动词，它们永远只是丢掉那个 <code>-る</code>，然后加上我们想加的任何东西**，所以 <code>たべる</code>（吃）变成 <code>たべない</code>（不吃）。就是这样。我们就是这样把任何动词变成否定的。非常非常简单。

## 形容词的否定形式

那么，形容词呢？我们怎么把形容词变成否定呢？嗯，当我们对一个形容词做变形时，**我们所做的总是把它末尾的 <code>-い</code> 变成 <code>-く</code>：** <code>あかい</code>（是红的）变成 <code>あかく</code>；<code>かわいい</code>（是可爱的）变成 <code>かわいく</code>；こわい（是可怕的）变成 <code>こわく</code>。

![](../media/image303.webp)

而这也是我们构成形容词 て形 的方式：<code>あかく</code> 变成 <code>あかくて</code>。

![](../media/image926.webp)

**而这也是我们构成否定的方式：** <code>あかい</code> 变成 <code>あかくない</code>（不红）。

![](../media/image860.webp)

现在有趣的是，这个 -く 和 て形 里发生的事正好相反，对吧？如果一个词以 -く 结尾，在 て形 里我们把它变成 -い。**但在形容词里，我们把 -い 变成 -く。**

## 过去时里的形容词

如果我们想把一个形容词放进过去时，**我们去掉 -い，用 -かった。** 所以 <code>こわい</code>（是可怕的）变成 <code>こわかった</code>（过去可怕）。而因为 <code>ない</code> 也是一个 い形容词，当我们把它放进过去时，我们同样说 <code>なかった</code>。所以，如果我们想说 <code>Sakura runs</code>（小樱跑），我们说 <code>さくらがはしる</code>；如果我们想说 <code>Sakura doesn't run</code>（小樱不跑），我们说 <code>さくらがはしらない</code>；如果我们想说 <code>Sakura ran (in the past)</code>（小樱（过去）跑了），我们说 <code>さくらがはしった</code>——因为它是一个五段动词；

::: info
注意 た 前面的 っ，而不只是第 5 课里给出的 た，五段动词第 1 组。*  
:::

而如果我们想说 <code>Sakura didn't run (in the past)</code>（小樱（过去）没跑），我们说 <code>さくらがはしらなかった</code>。<code>はしらない</code>，然后我们把 <code>ない</code> 放进过去时：<code>はしらなかった</code>。

![](../media/image187.webp)

现在，如我们大家所知。<code>さくらがはしる</code> 是相当不自然的日语，就像它是相当不自然的英语一样。我们在英语里说 <code>Sakura is running</code>，而在日语里我们说 <code>さくらがはしっている</code>。所以如果我们想把这一切放进过去时，我们怎么做呢？嗯，我们只需把那个 <code>いる</code> 放进过去时。

所以我们说 <code>さくらがはしっていた</code>——<code>Sakura was running</code>（小樱当时正在跑）。

![](../media/image554.webp)

而如果我们想说 <code>Sakura wasn't running</code>（小樱当时没在跑），我们说 <code>さくらがはしっていなかった</code>。那个 <code>いる</code> 是一个简单的一段动词，所以我们只需丢掉 -る 并加上 た *（肯定的过去）* 或 ない *（否定）*，而在过去时里，就是 なかった。*（因为 ない 在过去时变成 なかった）*

![](../media/image12.webp)

**我总是说日语就像乐高。** **一旦你知道基本的积木块，你就能建造任何东西。** **而日语里几乎没有例外。**

## 例外

在今天我们一直在谈论的整个范围里，其实只有两个例外。我要把它们介绍出来，好让你知道你需要知道的一切。

**每一个动词都通过加上 <code>ない</code> 来变成否定，唯一的真正例外是动词 <code>ます</code>，它是一个让词变得正式的补助动词。** *（礼貌）* **我们把它加到动词的 い-词干上**，我们稍后会看 い-词干，但我想你已经能猜到它是什么了。

所以，<code>はなす</code> 变成 <code>はなします</code>，<code>きく</code> 变成 <code>ききます</code>，等等。当你把 <code>ます</code> 变成否定时，它并不像你会预期的那样变成 <code>まさない</code>——**它变成 <code>ません</code>。**

![](../media/image360.webp)

**因为它是正式的，它有点老派，它使用古老的日语否定 <code>せん</code> 而不是 <code>ない</code>。**

![](../media/image941.webp)
:::

唯一另一个表面上的例外是，<code>いい</code>，也就是形容词 <code>[良]{い}い</code>，意思是 <code>is-good</code>（是好的），它有一个更古老的形式 <code>[良]{よ}い</code>，而后者仍然被相当频繁地使用。而**当我们对 <code>いい</code> 做任何变形时，它会变回 <code>よい</code>**，所以在过去时里我们不说 <code>いかった</code>，**我们说** <code>**よ**かった</code>——而如果你看过很多动漫，你大概经常听到这个。

![](../media/image253.webp)

<code>よかった</code>，字面上是 <code>(zeroが)よかった</code>——<code>(It) was good / That turned out well / That's great</code>（（它）很好 / 那结果不错 / 那太棒了）。而如果你想说某样东西不好，你不说 <code>いくない</code>，**你要说** <code>**よ**くない</code>。而以上就是仅有的例外。
