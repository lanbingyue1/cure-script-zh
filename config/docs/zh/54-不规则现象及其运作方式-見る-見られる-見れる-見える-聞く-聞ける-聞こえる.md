# **54. 不规则现象及其运作方式 | 見る, 見られる, 見れる, 見える, 聞く, 聞ける, 聞こえる**

[**日语中的不规则现象及其运作方式 | 見る、見られる、見れる、見える、聞く、聞ける、聞こえる | 第 54 课**](https://www.youtube.com/watch?v=WuMCOHisAvY&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=56&pp=iAQB)

こんにちは。

今天我们要讲日语里的一些例外，它们怎么运作，以及为什么存在。而在讲这些的同时，我想我们会获得一些关于日语如何自成一体的洞见，以及我们如何理解它。

那么我们今天要讲的是 見る、見られる、見れる、見える、聞く、聞ける、聞こえる。嗯，看起来是一大堆让人困惑的东西，对吧？但事实上，我们在那里有的只是 <code>見る</code> 和 <code>聞く</code> 的基本辞书形——<code>see</code> 和 <code>hear</code>——以及它们各自的可能形，再加上一个替代的、例外的可能形。

![](../media/image822.webp)

现在，就 <code>見る</code> 而言看起来是两个，但实际上是一个，我们马上就会讲到这点。

我总是说，日语是一门非常、非常规则且有逻辑的语言，而传统观点认为它只有两个不规则动词：<code>来る</code> 和 <code>する</code>。嗯，正如我之前提到的，它其实还有少数几个其他小例外，而我所谓小例外，指的是那些其实并不算不规则动词、但在某一个特定领域、仅仅一个地方变得不规则的动词。这样的动词不多，但有几个，而这就是其中的两个。

我们想看看它们是什么，更重要的是，它们为什么是这样、它们意味着什么，我们如何理解它们。

那么，先从我们理解动词的规则可能形，也就是 <code>able to do</code> 形怎么运作开始，对吧？我们只要把动词变成它的 え 词干，再加上那个非常简单的可能补助动词 <code>る</code>，它就一个字符：る。那是五段形。

而一段形：在一段里我们就像一贯做的那样，只要去掉 -る，换上我们想放上去的东西。在这个情况下，一段的可能补助动词是 <code>られる</code>。

![](../media/image384.webp)

所以，如我们所见，<code>見られる</code> 是 <code>見る</code> 的规则可能形，而它是一段动词；<code>聞ける</code> 是 <code>聞く</code> 的规则可能形，而它当然是五段动词。

那我为什么说 <code>見る</code> 只有一个变体而不是两个？嗯，那是因为那个变体是 <code>見える</code>，我们待会儿会回到这一点。

<code>見れる</code> 其实是一段形受到了一种我们称为 <code>ら抜き</code> 的现象影响。<code>ら抜き</code> 字面意思是 <code>taking out the ら</code>（去掉那个 ら）。

![](../media/image123.webp)

这是日语里相当普遍发生的事。一旦你真正开始使用日语，你会经常碰到它，所以也许就是现在。它不过就是在动词的一段可能形里去掉 <code>ら</code>、丢掉 <code>ら</code>。

这被视作不合语法的用法，不仅英语的日语教科书这么认为，日语母语的语法教科书也这么认为。它被认为是不合语法的，但它非常、非常普遍，比你会时不时听到的大多数流行错误用法要普遍得多。而我认为这大概会是语言的一种演化。

现在，西方人往往喜欢说：“嗯，如果有很多人都在使用一种错误用法，那你怎么能说它是错的？它肯定是一种新的正确用法，因为 **correct**（正确）不过就是人们使用的东西。”

而我认为这是一个错误，而且是个相当危险、不负责任的错误，因为虽然语言确实在演化，但语言的演化和被理论化的物种演化大体相同。也就是说，物种从突变中演化。突变发生得相对频繁，而其中大多数都消亡了。

只有少数突变——通常是在它们有某种特殊优势的情况下——真正留存下来，成为该物种演化的一部分。语言也是如此。大多数被相当多的人采用的错误用法都会消亡。只有极少数最终成为语言真正演化的一部分。

所以，如果你做西方目前在做的事，也就是把语言的误用放进词典，你实际上就是在短路语言自我纠正的功能。语言经过一代人左右、也许二三十年的时间，会排斥大多数违背其基本逻辑的用法。极少数用法的最终结果会是对基本逻辑做出微小的改变。

而这就是为什么在早期阶段就把语言的误用放进词典是个错误，因为在那个早期阶段，我们无从知道它们是真的会成语言的真正演化，还是会在下一代之内消亡。我们确实知道的是，在大多数情况下、在绝大多数情况下，它们会在下一代之内消亡，而把它们放进词典，就是在干扰语言那个自我纠正的过程。

我会说，这很重要，因为正是这种思维方式，让西方的日语教学如此糟糕。就是那种假定语言是一件完全非理性的东西、只是碰巧以它选择的任何方式演化的思维方式。

![](../media/image1081.webp)

而它并不是。语言受逻辑支配。而日语比大多数语言更受逻辑支配。

但如果你拒绝这个观念，如果你认为语言只是非理性的、偶然的、意外的，任何人碰巧使用的任何东西都和别的东西一样正确，那么你最终就会把语言教成一堆你不得不学的大杂烩，因为那些东西碰巧就在那里，而且没有任何底层逻辑。

而这确实就是支撑现代西方日语教学的那个谬误。好了，这是一段题外话。

让我们回到 <code>見られる</code>。<code>見られる</code> 是他们会使用的形式，因为那目前才是正确用法。

于是我们有 <code>見る</code>、<code>見られる</code> 和 <code>見える</code>。我们有 <code>聞く</code>、<code>聞ける</code> 和 <code>聞こえる</code>。

## 规则与不规则可能形

那么这两种可能形，规则可能形和不规则可能形，之间有什么区别？

现在，在这里的每一种情况下，不规则可能形就是我打算称作“强制自移形”（forced self-move form）的东西。嗯，正如我们在关于可能的那节课里所知道的<sup>[[10]](./10-补助动词-可能形补助动词.md)</sup>，可能通常是自移——如果你不知道 <code>self-move</code> 是什么，你也应该看看关于自移动词和他移动词的那节课<sup>[[15]](./15-他动词与自动词.md)</sup>。它们有时被叫作——并不完全准确——他动词和自动词。

所以，比如，如果我们想说 <code>I can read the book</code>，在日语里我们其实是说 <code>the book does readable to me</code>。所以我说 <code>*(私は)*本が読める</code>。这是自移。

书是施事，它作用于它自身。它在让自己变得可读，字面上它在 <code>doing readable</code>（做“可读”这件事）。

![](../media/image792.webp)

::: info
私 的振假名应该是 わたし。
:::
这没有确切的英语翻译，因为我们并不是在说书是可读的（IS readable）；它不是一个形容词性短语。我们说的是书“做可读”（DOES readable）。

所以我们只能习惯于这个事实：日语比英语更乐意把存在状态当作动词性动作来处理。

所以如果我们想说 <code>I can read the book / *As for me, the book does readable*</code>，我们说 <code>*(私は)*本が読める</code>，但如果我们只是想表达 <code>I can read / *I do readable*</code>，我们可能会说 <code>読める</code> 或 <code>(私は)私が読める</code>，而这次我们同样有一个自移动词。

![](../media/image1123.webp)

在一种情况下我们说 <code>I do readable (I am able to read)</code>，另一种情况下我们说 <code>the book does readable (the book does being able to be read)</code>，它就是这么运作的。

不过，也可能在他移的语境里使用可能形。通常这发生在修饰小句里。这些有时被西方教科书称为 <code>subordinate clauses</code>（从属小句），它们确实是，但我认为把它们叫作 <code>modifying clauses</code>（修饰小句）更好、更清楚，而我在修饰小句上做了不少工作，所以如果你想知道我到底是什么意思，我推荐那个视频。

所以，尤其在修饰小句里，我们可以把可能形当作他移动词使用。比如，我们可能会说 <code>さくらを見られる日を楽しみにしている</code>。这意思是 <code>I'm looking forward to the day when I can see Sakura.</code>（我期待着我能看到樱的那一天。）

![](../media/image157.webp)

如你所见，这里我们说 <code>さくらを見られる</code>，把 <code>見られる</code>（可能形，<code>being able to see Sakura</code>）当作一个带宾语（宾语是樱）的他移动词使用。

现在，我们能用 <code>見られる</code> 这么做，能用 <code>聞ける</code> 这么做，但我们不能用 <code>見える</code> 或 <code>聞こえる</code> 这么做。它们被迫只能用来自移动词。

而总的来说，因为可能动词在日语里大多是自移的，不管我们谈的是别的东西还是我们自己在谈，我们都以自移的方式使用它们，而那两种是最常用的。其实我们也可以把其他形式、也就是规则形式 <code>見られる</code> 和 <code>聞ける</code> 用作自移动词，但它们也可以被用作他移动词。

---

说到 <code>見える</code> 和 <code>見られる</code>，有一个细微差别，那就是 <code>見える</code> 通常表示能够、实际上是身体上能够看到某物，而 <code>見られる</code> 更多暗示有看到某物的机会。

所以如果我们说 <code>芝居/しばいが見られる</code>，我们说的是我有机会看这出戏。如果我们说 <code>芝居が見える</code>，我们可能是指我前面的那位女士摘下了她的大帽子，所以我能看到这出戏了。

不过，单凭这一点，我认为还不足以为这两个词形留存进现代日语提供充分理由。重要的理由——它基于看和听以及我们用来表达看和听的表述的本质——是这个：它们俩都用在英语里我们会说某物 <code>looks like</code> 某物、或某物 <code>sounds like</code> 某物的地方。你不能用标准版本 <code>聞ける</code> 和 <code>見られる</code>" 来做这个。你必须用这些变体。

所以如果你说 <code>さくらはカエルに見える</code>，你是在说 <code>Sakura looks like a frog</code>（樱看起来像只青蛙）。

所以当我们说 <code>looks like</code> 时，我们用一个名词加目标助词 に，或者用一个形容词时，我们用形容词的 く 词干。所以我们说 <code>カエルに見える</code>——<code>looks like a frog</code>——或者我们可以说某人 <code>若く見える</code>——<code>she looks young</code>（她看起来很年轻）。

---

而且我们也可以不只是把它用于某物在我们的耳朵里听起来如何、或在我们眼里看起来如何，还可以用于它的外表如何。

所以我们可以说 <code>奇妙/きみょうに聞こえる</code>——<code>it sounds strange / sounds peculiar</code>（听起来奇怪／怪异）。所以，我们这里不一定是在谈实际的声音。它可能不是一个听起来奇怪的噪音。它可能是某人说的听起来奇怪的话。

---

所以我们用形容词的副词形式、或造形容词的目标助词 に，来描述某物在我们看来如何、在我们听来如何，无论是字面上还是比喻上。

而这就是这些替代可能形得以留存的真正原因。它们有这种特定含义，而另一种形式、也就是规则形式，不可能有这种含义。

而承担那种含义的正是这个强制性的、必须是自移的版本，这并不是巧合，因为某物的样子、某物的声音，永远必须是自移的。我们谈的不是我们对那个样子做了什么、或我们对那个声音做了什么，而是它本身看起来和听起来如何。

所以这个极端自移的版本 *(見える/聞こえる)*，它不能用于他移的语境，正是在看和听两种情况下被用来描述某物在我们听来如何、在我们看来如何的东西。
