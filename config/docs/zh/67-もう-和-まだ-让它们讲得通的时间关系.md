# **67. もう 和 まだ：让它们讲得通的时间关系**

[**もう 和 まだ：让它们讲得通的时间关系（mou and mada）第 67 课**](https://www.youtube.com/watch?v=sBhD_Z5_pHw&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=69&ab_channel=OrganicJapanesewithCureDolly)

こんにちは。

今天我们要讲 <code>もう</code> 和 <code>まだ</code>，这两个表达可能有点让人困惑，尤其是 <code>もう</code>。

![](../media/image1031.webp)

如果我们在日英词典里查 <code>もう</code>，我们会被告知它意思是 <code>now, already, soon, before long</code>（现在、已经、很快、不久），有时甚至还有 <code>not any more</code>（不再），此外还有 <code>another</code>（另一个）的意思，并且是一个表达恼怒的词。它怎么可能同时意思这么多不同的时间关系？嗯，我们今天就会揭晓。而我们会看到，它远没有看起来那么令人困惑。

但首先我想看看 <code>まだ</code>，它稍微不那么令人困惑，但会给我们理解 <code>もう</code> 真正如何运作所需的原则。好的。

## まだ

那么，<code>まだ</code> 有一组不那么令人困惑的释义。大多数时候我们被告知它意思是 <code>still</code>（仍然）或 <code>not yet</code>（还没有）。

![](../media/image281.webp)

那我们就从看它真正是什么意思、真正做什么开始。<code>まだ</code> 做若干件事。它告诉我们关于现在时间的事。它把现在时间放进一个向过去延伸、并且预期会结束、或至少它结束的可能性正被考虑的时间段里。大多数时候它预期会结束。

现在，这做了三件事。它告诉我们关于现在的事，所以我们可以说它其实是说 <code>now</code> 的一种方式，但 <code>now</code> 与过去和未来有一种特定关系。

![](../media/image674.webp)

那是什么关系？嗯，如你所见，我们有两样东西。我们有 <code>now</code> 所位于的那段时间，以及一个转变点。

既然它是一段时间，它就不可能永远持续下去，所以有一个转变点，在这点上它转变到另一段具有其他性质、预期在未来、或至少在未来被当作一种可能性考虑的时间。现在，<code>まだ</code> 给了我们两个对比。那段时间与它将会、或可能将会改变的未来形成对比，但当下时刻与它本可能被预期改变的那段过去形成对比。

![](../media/image130.webp)

所以这在英语里本质上就是 <code>still</code>（仍然）。而这可能显得有点抽象，但我想当我们看到它怎么运作时，就会足够清楚地理解它。

所以，如果我们说 <code>宿題はまだしなかった</code>，我们是在说 <code>I haven't done my homework yet</code>（我还没做作业）或 <code>I still haven't done my homework.</code>（我仍然还没做作业。）

![](../media/image935.webp)

现在，如你所见，这意味着我们处在一段我还没做作业的时间里。这段时间向过去延伸，并与一个我将已经做完作业的未来时期形成对比。但当下时刻正与一个我本可能、或本应该做完作业的过去时刻形成对比。

![](../media/image466.webp)

这就是为什么我们说 <code>まだ</code>，也是为什么在英语里我们会说 <code>still</code> 或 <code>haven't yet</code>。换句话说，过去有一个它本可能被预期发生的时刻，但它没有发生。所以它仍然处在一种直到未来才会改变的状态里。而这就是我们在英语里用 <code>still</code> 和 <code>yet</code> 这类词时所表达的意思。

如果我们说 <code>さくらはまだ若い</code>，我们是在说 <code>Sakura is still young.</code>（樱还年轻。）

![](../media/image171.webp)

现在再一次，我们所说的是  
现在时间位于一个樱年轻的时期里，  
那个时期向过去延伸，并预期在未来某个时候改变。她不会永远年轻，她会变老。所以我们能看到，樱年轻的那段时间与她会变老的未来形成对比。

但当下时刻正与过去形成对比。

![](../media/image323.webp)

这就是为什么我们说 <code>まだ</code>，或为什么在英语里我们会说 <code>still</code>。我们所说的是 <code>She hasn't stopped being young yet</code>（她还没停止年轻）。相对于她在过去停止年轻的可能性，她在过去并没有停止年轻——她现在仍然年轻，尽管她在未来不会年轻。

如果我们说 <code>さくらはまだ大人ではない</code>，我们是在说 <code>Sakura is not yet grown-up</code>（樱还没长大）。

![](../media/image206.webp)

所以现在我们在用否定，而这就是为什么 <code>まだ</code> 能意思是 <code>still</code> 或 <code>not yet</code>。至少在这个情况里，它只取决于它是被用在否定中这个事实。

所以，如果我们说 <code>さくらはまだ大人ではない</code>，我们是在说在现在这个时期樱没长大。即便你也许以为她不久前已经长大了，她也没有。但当然她在未来会成长。

如你所见，它之所以既被翻译成 <code>still</code> 又被翻译成 <code>not yet</code>，是因为日语把事情表达得和英语稍微不同。在英语里我们说 <code>Sakura is not yet grown-up</code>。但在日语里我们实际说的是 <code>Sakura is still not grown up</code>（樱仍然没长大）。

不过，要让 <code>まだ</code> 意思是 <code>not yet</code>，我们并不必有一个明示的否定。比如，如果某人对你说 <code>日本語は上手いね</code>——<code>Your Japanese is very good, isn't it?</code>（你日语很好，对吧？）嗯，即使你只能磕磕巴巴挤出 <code>こんにちは</code>，日本人也往往会这么说。而即便你的日语真的很好，你大概也会回答 <code>いえまだまだです</code>。

![](../media/image1146.webp)

<code>まだまだ</code> 在这个情况里意思是 <code>not yet</code>。换句话说，我们仍然处在我日语还不好的那个时期里。那个改变并没有如你所说的在过去发生；它将不得不在未来发生。

而一点文化小注
在西方，反驳一个对你说好话的人有时会被认为有点无礼，但在日语里我们一直这么做。不这么做反而会被认为有点傲慢。

## もう

现在，我们接着讲 <code>もう</code>，在那里我们会遇到几个表面上更复杂的情况，但如我们将看到，它们其实并不复杂。

![](../media/image1126.webp)

<code>もう</code> 本质上与 <code>まだ</code> 相反。它在英语里最好的翻译是它意为 <code>already</code>（已经）。它的意思是，我们现在处在一个向未来延伸的时间段里。所以，正好和 <code>まだ</code> 相反。

那段时间被拿来与现状尚不成立的过去相比，而现在被拿来与那个转变本可能被预期发生、但事实上它已经发生了的未来相比。

![](../media/image141.webp)

所以如果有人说 <code>宿題をしなさい。</code>（<code>Do your homework!</code> 做作业！），你可能会回答 <code>もうやったよ</code>（<code>I already did it</code> 我已经做了）。

所以我们所说的是，我们现在处在我的作业已经做完、我已经做了它的那段时间里，而那个转变并不会如你可能以为的在未来发生；它已经在过去发生了。

![](../media/image1121.webp)

那么为什么它有时被翻译成不同于 <code>already</code> 的意思，比如 <code>now</code>？嗯，如我们所见，<code>まだ</code>（<code>still</code>）和 <code>もう</code>（<code>already</code>）其实都是 <code>now</code> 的一种。我们谈的是现在。我们只是在我们谈现在时，与过去和未来做出不同的对比。

![](../media/image235.webp)

所以，当然，<code>もう</code> 确实意为 <code>now</code>，就像 <code>already</code> 一样。但因为不同语言里的词极少占据[**意义光谱**](https://www.youtube.com/watch?v=CpiELpGR-VU&ab_channel=OrganicJapanesewithCureDolly)完全相同的区段，有时我们会使用 <code>もう</code>，用在本会用 <code>now</code> 的地方。

![](../media/image359.webp)

而因为日英词典是以英语为中心的，在那些情况里它们会试着把 <code>もう</code> 翻译成意为 <code>now</code>。

所以，比如，如果你伤到了自己，正站起来，有人说 <code>大丈夫?</code>，而你回答 <code>もう大丈夫</code>，  
你把它翻译成英语通常会是 <code>I'm all right now</code>（我现在没事了）。

![](../media/image416.webp)

在英语里你通常不会说 <code>I'm already all right</code>。现在，在日语里你也可以说 <code>今大丈夫</code>，它也意为 <code>I'm all right now</code>，但当你说 <code>もう大丈夫</code> 时，你是在特别加上那么一层细微含义：你之前没事，而你现在没事，相对于在不久的将来某个时候没事。换句话说，你不需要更多时间恢复了，你没事。在英语里，我们不用 <code>already</code> 来表达那个。逻辑上我们可以，但实际上我们通常不会。

现在，说 <code>もう</code> 也被用作一个表达恼怒或恼火的词是完全正确的：<code>もう!</code>

![](../media/image1052.webp)

它把各种各样的抱怨或嘟囔压缩进去，或者它可以只是单独一个：<code>もう!</code> 那是怎么运作的？有趣的是，<code>already</code> 在某些情况下在英语里也能带一点那种细微含义。所以，如果有人说 <code>Enough already!</code>（够啦！），他们的意思是，在此时、相对于未来某个时候，我受够它了。而那正是 <code>もう!</code> 在日语里往往表达的意思。所以那真的够简单了。

### 第二个 もう？

不过，<code>もう</code> 有一个方面在你理解它之前有点点令人困惑，那就是其实有两个词 <code>もう</code>。现在，这也许有点争议，但事实上在音高重音词典里它们实际上被给了两种不同的重音，一种给我们一直在谈的那个 <code>もう</code>，也就是意为 <code>already</code> 的那个，另一种给另一个 <code>もう</code>，它在许多方面相当接近，我稍后会解释它为什么相当接近。但首先我们看看它不那么接近的地方。

这个第二个 <code>もう</code>，我认为，最终与助词 <code>も</code> 有关，它有着同样的加添式含义 <code>another</code>（另一个）。

![](../media/image129.webp)

所以如果我们说 <code>もう一つ</code>，我们是在说 <code>another one</code>（再来一个）。如果我们说 <code>もう一人</code>，我们是在说 <code>another person</code>（再来一个人）。所以，当我们那么表达时，我们能看出我们其实在处理两个不同的词、两个不同的概念。

现在，接着它就变得有点更令人困惑了，而我要告诉你为什么。它甚至让日本人困惑，他们在许多情况下其实并没把这个音高重音的事搞对，因为它们是两个不同词这个想法往往甚至被日语母语者相当程度地丢失了。

而原因是有许多情况它们变得相当接近。为什么？嗯，如我们所见，<code>もう</code> 告诉我们一种时间关系，它是一个与时间有关的词，它意为 <code>already</code>。而词典也告诉我们它意为 <code>soon</code>（很快）。它们为什么说它意为 <code>soon</code>？

嗯，它单靠自己并不意为 soon，但它在某些组合里意为 <code>soon</code>。所以，比如，如果我们说 <code>もうすぐ</code>，它意为 <code>soon</code>，我们真正说的是：<code>すぐ</code> 意为 <code>soon</code>，而 <code>もう</code> 意为 <code>already</code>，所以那个 <code>もう</code> 是在强调那个 <code>soon</code>：它已经很快了，它不会在未来某个时候很快，它现在马上就快了。

![](../media/image352.webp)

现在，我们也可以说 <code>もう少し</code>。比如，如果一些人正走着去某地，他们已经走了很久，正变得累了，有人可能会说 <code>もう少し!</code>，它意思是 <code>just a little more / just a little extra</code>（再一点点／再多一点点）。它可能意为 <code>just a little more effort</code>（再多一点努力），但它也能意为 <code>just a little more time</code>（再多一点时间）。

![](../media/image639.webp)

所以，你看，<code>もうすぐ</code> 和 <code>もう少し</code>，尽管它们是不同的词 <code>もう</code>，在某些情况下有着非常相近的意思。

而另一个 <code>もう</code>，那个加添式的 <code>もう</code>，也常常被用来表达时间关系。所以如果我们说 <code>もう一度</code>，我们是在说 <code>one more time</code>（再一次）。现在，这显然意思非常接近我们说 <code>もう一つ</code> 时的意思，后者意为 <code>one more thing</code>（再来一个东西）——再来一颗糖，再来任何东西。

但它也非常常与 <code>一度</code> 一起用：再一次。<code>もう二度来ない</code> 意思是 <code>I'll never come again</code>（我再也不会来了），字面上是 <code>I won't come for another second time</code>（我不会再来第二次）。

![](../media/image44.webp)

所以我们能看出，这两个 <code>もう</code> 相当接近地踏向同一片领域。它们都能被用于时间关系，而在少数语境里，像 <code>もう少し</code> 和 <code>もうすぐ</code>，意思几乎一模一样。

但一旦我们理解了这两个以及它们如何运作，我想就不会再有更多混淆的余地了……
