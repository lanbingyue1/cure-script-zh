# **7.5. 活用**

[**日语活用，轻松搞定！通往一切活用的超简单钥匙。**](https://www.youtube.com/watch?v=FhyrskGBKHE&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=8)

今天我们要讲日语活用。

你可能会问，是哪种特定的活用？嗯，全部。除了 た 形和 て 形，那两个我们会在另一个视频里讨论<sup>[[81]](./81-所有日语词形的全局原则.md)</sup>。

为什么我们要一次把它们全讲完？因为我们能。因为日语活用的运作方式全都一样。它非常简单、非常有逻辑、非常一致，而且非常非常容易理解。

然而，当我们翻开教科书，我们会得到一个印象：每种特定的活用都有一大堆不同的规则和形式要你去学。为什么会这样？既然它其实这么简单，教科书为什么把它弄得看起来那么复杂？

两个原因。第一个是它们坚持活用是那种**欧洲概念**。其实，我们所做的事根本不是活用。

*如果你真的爱看长文，第 13 课底下有一段非常长的、[**有趣的讨论**](https://www.youtube.com/watch?v=cvV6d-RETs8&lc=UgzXdC7vyB-XKN543tt4AaABAg)，所以怎么称呼它由你决定，叫它活用也行，尤其是当它多半就是这么叫的时候，至少先让自己熟悉它。*
:::

::: details 只是我一段啰嗦的术语笔记，还有一些别的啰嗦……（点箭头展开）
从语言学上讲，可以说日语里确实有某种类似活用的东西，但它似乎和欧洲语言相当不同，这很可能就是 Dolly 避开这个词的原因，好不让我们那样去理解它、然后被搞糊涂。至于大多数资料来源为什么叫它活用，那就另说了。

再说一遍，别把这当成定论，它只是要避开 <code>conjugation</code> 这个词在欧洲语言语境里带出的某些联想，因为日语里有某种形式的活用，就像形容词性名词基本上是名词、但不是专有名词一样（不过那只是众多模型中的一个）。  
这只是为了说明，看待事物有多种方式，它并不是严格非黑即白的，它只是一个模型；而既然你没法一次把所有东西都解释清楚，你就会把某些东西简化。

## 活用入门

::: info
这是 Dolly 在她的书 <code>Unlocking Japanese</code> 里关于活用所说的话，记在心里就好：

![](../media/image408.webp)
:::

**我们一直在做的事，就是把一个简单的补助动词——或者补助形容词，或者补助名词——接到动词的词干上。**

而一旦我们看清它是怎么运作的，它就变得非常非常简单、容易理解。

另一个问题是，他们花很多时间去按罗马音系——也就是字母表——来解释发生的那些变化。但事实上，那会造成大量困惑和困难。

**一旦我们从它实际存在的体系来看它，也就是说，\*日语\*音系，一切就都变得非常有逻辑。**

我会说它是 100% 一致、有逻辑又简单的——只不过整个体系里有一个例外，还有两个不规则动词，所以也许我们最好说 99.9% 有逻辑、一致又容易理解。

好。那么，让我们把那张总表交给你，它会向你展示这一切是怎么运作的。

チャートをください!

那么，这就是那张熟悉的日语假名表，包含日语全部的音。

![](../media/image321.webp)

我把它横过来放了，原因很快就会明了。所有日语动词都以中间那一行的某个假名结尾——因为我把它横过来了，它看起来像一列。那就是 う 行——う、く、す、つ、ぬ 等等。

不过，没有以 ゆ 结尾的动词，所以我们可以去掉这两列，把表简化。

![](../media/image263.webp)

其实，只有一个以 ぬ 结尾的动词——就是 しぬ，死——所以我们也可以把它去掉，让表看起来更简单，但为了完整我把它留着了。

所以，**每个动词都以红框里的某个假名结尾。** 我们来给每一种可能的词尾举一个例子：  
かう，买；きく，听；はなす，说；もつ，拿；しぬ，死；とぶ，飞；のむ，喝；とる，取。

那么，如你所见，动词还可能有另外四种词尾，而事实上那几种词尾每一种都被用到了。

![](../media/image778.webp)

**而当我们用别的词尾之一时，动词就不再是动词，而变成我所谓的「黏性词干」，也就是一个我们再往上粘别的东西的词干。**

## い 词干

那么，这就是 い 词干。

![](../media/image670.webp)

::: info
如果你奇怪为什么 そう 在那里、却没在这里提到。它会在第 24 课出现。 ![](../media/image481.webp)
:::

用 い 黏性词干时，我们把 う 行的假名换成对应的 い 行假名。于是，かう 变成 かい，きく 变成 きき，はなす 变成 はなし，等等。

我们用 **い** 行黏性词干做什么？

### 补助动词 ます

嗯，你们肯定都见过的那件事，就是我们可以把补助动词 ます 接到 い 行黏性词干上。

![](../media/image664.webp)

**ます 不是一种活用。它是一个动词。它是一个补助动词，接在 い 行黏性词干上**。**它不改变动词的意思，但让它变得正式。** *（礼貌）*

所以，かう 是普通的、不正式的说法，意思是买；かいます 是正式的说法。きく 是不正式的说法，听；ききます 是正式的说法。

### 补助形容词 たい

我们用 い 行黏性词干还能做什么？

嗯，我们可以接上补助**形容词** たい。**たい 是一个补助形容词，意思是「想要」。**

所以，かいたい 意思是想要买；ききたい，想要听；はなしたい，想要说，等等。

::: info
虽然在英语里它通常被译成动词，但在日语里它是一个形容词。
:::

### 把动词变成名词

**我们也用 い 行黏性词干来接名词，好把一个动词转换成一个新名词。**

所以，かいもの，也就是买-东西：它的意思是购物。のみもの，喝-东西，意思是一杯饮料。はなしかた（かた 意思是形式或形状）……はなしかた 意思是说的方式、说话的方式。

那么现在我们知道怎么把它们都接上了，只除了那些叫 <code>る-verbs</code> 的词，也就是一段动词，而它们非常非常简单，因为你对它们所做的一切、永远都只是**直接去掉 る，你就得到了这一段动词所有可能的黏性词干。**

所以 たべる 变成 たべ；たべます 是这个动词的正式形式；  
たべたい，想要吃；たべもの，吃-东西，食物。

::: info
另外还存在一个名词 買い（它是一个名词），意思是购物、购买、产品等。  
所以它们在意思上相似，我不知道它和 買い物 之类之间有什么关联，但只是让你知道存在几个这样的例子。它也表明并非每一个以 い 结尾的词都自动是形容词，尽管绝大多数是……也许这个 い 在过去也是某个汉字词，而现在它不再采用汉字的写法了？？？谁知道呢……

![](../media/image473.webp)
:::



## あ 词干

那么现在我们来到 あ 行黏性词干，而它有一个例外。

![](../media/image269.webp)

而你会说，<code>Ah, languages! Full of exceptions!</code>

**这是整个体系里唯一的例外**，而且它是一个非常自然的例外，你完全能理解。

以 う 结尾的动词不会变成 <code>かあ</code>，**它会变成 <code>かわ</code>**，这说起来、在对话里听起来都容易得多，对吧？

所以 かう 不会变成 <code>かあない</code>，**它会变成 かわない。**

::: info
在视频下面的评论里，有一位 <code>pycage</code> 写了一条有洞见的[**评论**](https://www.youtube.com/watch?v=FhyrskGBKHE&lc=UgzzF0FxyJJZX7z94Yp4AaABAg)，讲到只要考虑日语的历史，这个例外其实甚至根本不算例外。如果你有兴趣可以去看看 (o^▽^o) 不过那是一个相当更进阶的解释。
:::

那我们用 あ 词尾词干来做什么？

### 补助形容词 ない

我已经提到过它<sup>[[7]](./7-否定形式与过去时里的形容词.md)</sup>——大概最常见的用法，就是把补助形容词 ない 接到动词的黏性词干上。

![](../media/image386.webp)

**它接在 あ 黏性词干上**，所以 かう，买，变成 かわない，不买；  
きく，听，变成 きかない，不听；  
はなす 变成 はなさない，不说，等等。非常简单。

### 使役

我们也用 あ 黏性词干来构成使役、以及动词所谓的 <code>passive</code> 形式*（受动）*，而这些 <code>conjugations</code> 常常给初学者带来不少麻烦。

而我做了一些视频*（后面的课）*，展示它们其实有多简单、它们如何运作、它们是什么意思，以及如果你按它们实际的样子去理解它们，一切有多简单。

今天我们只看结构。

那么，动词的使役形式，意思是**让某人做某事，或使某人做某事**，是通过**把补助动词 せる / させる 接到 あ 行**黏性词干来构成的。

![](../media/image161.webp)

那么，我说 せる / させる——那是什么意思？

**嗯，它的意思是这个补助动词其实有两种形式。**

せる 接到我们正在处理的那些黏性词干上——所有会变化的那些。  

::: info
Dolly 这里指的是五段动词。
:::

而 させる 接到一段——也就是所谓 <code>る-verb</code>——的黏性词干上。

凡是补助动词有轻微差异的地方，我们总是发现较长的那个版本接到一段动词上，因为那种动词通常更短。

---

一段动词，我们把整个最后一个音节去掉；而五段动词、那些会变化的黏性词干，我们不去掉最后一个音节，而是把它变成一个不同的音。

所以，せる / させる 构成动词的使役形式。

かう 变成 かわせる，让买、使买；  
はなす 变成 はなさせる，让说、使说；

::: info
はなす 是一个以 す 结尾的五段动词，所以它变成 あ 词干 + せる，看起来就与一段动词的使役形式 させる 一样。Dolly 在后面的课里会解释这类东西。
:::

のむ，变成 のませる，让喝、使喝；

而 たべる 变成 たべさせる，让吃、使吃。  

::: info
たべる 是一个一段动词，所以它只是删掉 る 再加上 させる 来构成使役。
:::

### 受动 / 被动

所谓的被动——它其实并不是真正的被动*（这一点可以争论，但现在我们先跟着 Dolly）*，我们有一个视频帮你理解它真正在做什么、以及那其实有多简单——所谓的被动，也就是**受动形式**，是用**补助动词 れる / られる**构成的。

所以，かう 变成 かわれる，意思是 get bought、被买、get bought——**get bought 更好，因为那更接近日语真正的意思**，而当你看了那个视频<sup>[[13]](./13-被动活用-受动补助动词.md)</sup>你就会明白；

きく 变成 きかれる，get heard；のむ 变成 のまれる，get drunk——**我不是说喝醉，我说的是那杯咖啡被喝掉的那种方式；** たべる 变成 たべられる，get eaten。

---

所以如你所见，真的——除了那一个例外，把这些接在一起并没有很多很多种不同的方式。产生困惑，是因为它被呈现为一种*（<code>West-based</code>）*活用，而且因为它被解释得好像是用罗马字母写的一样。

我们可以看出它其实非常非常规则。

我们只是移到 あ 行，加上补助形容词 ない、补助动词 れる / られる、补助动词 せる / させる，就这么简单。

## え 词干

现在我们来到 え 行黏性词干。

![](../media/image790.webp)

就像别的那些一样，它完全一致。你只要把 う 行的假名换成对应的 え 行假名。

所以 かう 变成 かえ，きく 变成 きけ，はなす 变成 はなせ，等等。

### 可能

**我们用 え 行黏性词干来构成动词的可能形式**，意思是你 <code>can do</code> 这个动词。

接在 え 行黏性词干上的那个补助动词，是 る / られる。

![](../media/image102.webp)

**而没错，尽管它只是 る、就那一个字符，它也是一个补助动词**——如果你在一本日语词典里查它（不是日英词典，而是一本真正的日语词典），你会在那里找到 る，作为一个 [助動詞]{じょどうし}、一个补助动词——而它有这两种形式，る 和 られる。

**られる，你会注意到，和所谓的被动** *（受动）*，れる / られる，是一样的，所以一段动词的被动形式和可能形式相同——但因为它们的用法非常不同，你会混淆两者的场合极少极少，所以这其实不是什么问题。

---

所以，我们有 かえる，能买；きける，能听；はなせる，能说，等等；  
再加上 たべられる，能吃。 
::: info
can 是如同 <code>is possible / is able</code> 的那个意思，后面第 10 课会讲。
:::

## お 词干

那么，现在我们来到最后一个黏性词干，お 行黏性词干，而和别的那些一样，它完全一致。

![](../media/image311.webp)

かう 变成 かお；きく 变成 きこ；はなす 变成 はなそ。

### 意志形

**而我们对这个黏性词干所做的，就是接上 う，而且如你所知，う 接到 お 上时一般会把 お 拉长。**

所以 かう 不会变成 kao-u，**它会变成 かおう/kaō**；  

::: info
Dolly 这里说的是发音，不是分别发出 o 和 u，而只是一个长 o。  
:::

きく 变成 きこう/kikō；はなす 变成 はなそう/hanasō。

意志形有若干种用法，而我这里只讲结构，所以我只用一个用法。

かう 变成 かおう，咱们买吧；きく 变成 きこう，咱们听吧；  
はなす 变成 はなそう，咱们说吧。

**在一段动词里，我们在这一段黏性词干末尾加上 よう。** *（当然，还要删掉 る）*

所以 たべる 变成 たべよう，咱们吃吧。

**意志形的一个特殊之处是，你也可以通过改变 ます 的形式、让意志形处于它的正式** *（礼貌）* **模式来构成它。**

而当你这么做时，你说 ましょう 而不是 ます，而当你这么做时，很自然，**你使用 い 行黏性词干，就像你用普通的 ます 时一样。**

所以，い**き**ましょう，咱们走吧。
