# **62. ておく vs てしまう，补助动词的秘密**

[**ておく vs てしまう，补助动词的秘密。ておく てしまう | 第 62 课**](https://www.youtube.com/watch?v=q6vDkjv4ac0&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=64&pp=iAQB)

こんにちは。

今天我们要开始谈我称之为「结构化学习与实际沉浸之间的桥梁」的东西，因为我们学习表达和结构，然后有时当我们在真实使用中遇到它们时，我们不太明白它们在那里做什么。

我要拿我的赞助人 Kimika-sama 的一个例子，她给了我这句话：

<code>各団体には私からよく説明しておく</code>

现在，Kimika-sama 能够相当正确地翻译这句话（它在英语里大致意思是

<code>I will give each group a good explanation from me</code>），

但仍然不明白为什么 <code>おく</code> 被用作 <code>説明する</code> 的补助动词。

![](../media/image807.webp)

而为了更充分地理解那一点，我想我们需要稍微更深入地研究某样东西。这就是这样一个事实：日本人非常喜欢他们的补助动词，他们在各种不同的情况下相当频繁地附加它们。这是我们从英语的角度能理解的东西吗？

我会说是的，能。我们在英语里也做同样的事，虽然不是在动词上那么多，而是在介词上，尤其是介词 <code>up</code> 和 <code>out</code>。

![](../media/image536.webp)

我们把东西 eat up、我们把东西 make up、我们 cry out、我们 lose out、我们 think up 一个主意、我们 think out 一个主意，等等等等。现在，**日语没有任何介词。** **一个都没有。** 如果你以为它有，是时候把那本教科书扔出窗外了。

它用来替代这些英语介词 <code>up</code>、<code>out</code> 等等的东西，是动词——补助动词。而日语补助动词和英语动词补助介词之间的区别，首先在于它们要多得多，然后，正因为如此，它们要具体得多。如果你看看英语使用者使用 <code>up and </code>out<code> — they even </code>peace out 的各种方式——不管那是什么意思——你就能看到，因为只有少数几个，它们被到处用、用在各种情况里，而它们被使用的方式只有很少量的道理。

---

现在，因为补助动词更多，它们可以更有针对性。所以，即便它们被广泛使用、在各种各样的情境里，如果我们明白我们需要一个相当宽泛的解释，我们一般都能分辨出任何一个给定的补助动词在做什么。

所以 <code>-ておく</code> 在这里做的，其实就是它一直在做的。如果我们说 <code>窓を開けておく</code>，我们所说的是
"把窗户打开，为的是窗户会开着，而且大概通风会进入房间"。

![](../media/image784.webp)

为了某个目的打开它，把那个动作放到位置上：

<code>おく</code>，它意思是 <code>put in a place</code>（放在一个地方）。把那个动作放到位置上，使得它然后
以我们想要的方式改变情况。在这个情况里，是给房间通风。

而这里的 <code>説明</code> 也一样。<code>説明しておく</code>——把解释这个动作，或者那个解释，放到位置上，使得在那之后，每个团体都会明白正在发生什么，他们不会再对那件事一无所知。

---

现在，我们可以把这个和另一个非常常见的补助动词比较，那就是 <code>しまう</code> 以及它的各种变体，比如 <code>ちゃった</code>、<code>じゃった</code> 等等。我们可以说 <code>説明してしまう</code>，但那会有一个完全不同的含义。

![](../media/image613.webp)

在这个特定的情况里，它大概会意思是
"我会径自去向他们解释，即便那不是我被期望去做的事，或者也许不是人们想让我做的事。
我就径自去向他们解释吧——<code>説明してしまう</code>

在另一个情况里我们也许会说类似这样的话

<code>聞かないでよ。さくらは説明してしまうから</code>，

它意思是 <code>Don't ask, because Sakura will explain</code>

![](../media/image688.webp)

但那个 <code>しまう</code> 所暗示的，大概类似这样
"别问，因为如果你问了，Sakura 就会解释，而我们就会在这里被 Sakura 又长又啰嗦的解释困上几个小时。"

所以，<code>しまう</code> 有各种各样的含义，其中一些是负面的，不是所有都是负面的，但 <code>おく</code> 有一个完全不同的意思范围。

---

**<code>しまう</code> 谈的是径自去
做某事，某事偶然发生；**

正如我在关于 <code>しまう</code> 的视频里说过的<sup>[[44]](./44-如何使用自然地道的日语-ちゃう-ちゃった.md)</sup>，本质上当它处于过去时，所有那些我们可以用 <code>done</code> 表达的意思——<code>I done explained</code>、<code>I done fell over</code>、<code>she done stole my cake</code>、<code>I done won the lottery</code>——不一定是负面的，但它带有那种感叹号的感觉。

**它发生了，即便你也许没料到它，或者你也许不想要它。**

**它发生了。**

---

**<code>おく</code> 没有那种感叹号的感觉。**

**它带有那种工匠般、踏实做事的感觉：**

做它是为了把动作放到位置上、为了达成一个结果、为了把情况从它之前的样子改变成一个更符合我们想要的样子，无论是打开一扇窗，还是向几个团体解释情况是什么……
