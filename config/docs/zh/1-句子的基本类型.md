# **1. 句子的基本类型**

[**第 1 课：日语其实很简单！学校从不教的东西。日语的核心句——有机日语**](https://www.youtube.com/watch?v=pSvH9vH60Ig&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&ab_channel=OrganicJapanesewithCureDolly)

日语最基础的东西，就是日语的核心句。每一句日语从根子上说都有同一个核心。它长什么样？就是这个样子。

我们把它想象成一列火车。每一句日语都由这两个要素构成：**主车厢 A**（main carriage）和 **引擎 B**（engine）。**引擎让句子跑起来，让句子运转。** **车厢必须在那儿，因为没有车厢，引擎就没有东西可拉**。这两样东西就是每一句日语的核心。

我们可以对 A 多说一些，可以对 B 多说一些，也可以把逻辑句组合起来，造出复杂句。**但每一句日语都符合这个基本类型。**

那么，A 和 B 到底是什么？先提醒自己一件事：任何语言里都只有两种句子——<code>A is B</code> 句（A 是 B）和 <code>A does B</code> 句（A 做 B）。<code>A does B</code> 句的例子是 <code>Sakura walks</code>（樱在走）。<code>A is B</code> 句的例子是 <code>Sakura is Japanese</code>（樱是日本人）。

我们可以把它们变成过去时，可以变成否定，可以变成疑问，可以对 A 多说一些，可以对 B 多说一些。但**归根结底，每一句话都能归结为其中一种：<code>A is B</code> 句，或者 <code>A does B</code> 句。**

那就来看看日语里是怎么做的。

## 动词句

在日语里，如果想说 <code>Sakura walks</code>（A 做 B：樱在走），那么 A 就是樱，是主车厢；B 就是“走”，是她做的事，是这句话的引擎。

![](../media/image1055.webp)

“走”在日语里是 <code>あるく</code>。要造出日语的核心句，还差一样东西，**那就是每一句话的销钉——が**（ga）。

**が 是日语语法的中心。每一句日语都绕着 が 转。有些句子里我们看不见 が，但它始终在那儿，始终干着同一件事。它把 A 和 B 连在一起，让它们成为一句话。** 所以我们的核心 <code>A does B</code> 句就是 <code>**さくらが**あるく</code> = <code>**Sakura** walks</code>。

## 系词句

现在来看一句 A is B 的句子：<code>Sakura is Japanese</code>，或者按我们的说法，<code>Sakura is a Japanese person</code>。A 还是樱，B 是 [日本人]{にほんじん}，意思是“日本人”，而**我们又一次需要 が 把它们连起来。所以我们要把 A 车厢——也就是主车厢——画成带着一个 が 的样子，因为主车厢、也就是句子的主语，永远带着一个 が，用来把它接到引擎上。**

于是就有了 さくらが日本人——还差一样东西。还有一样东西我希望你跟它交上朋友，那就是 だ（da），也就是系词（copula）。<code>さくらが日本人だ</code> = <code>Sakura is a Japanese person</code>。

![](../media/image632.webp)

你可能见过它的花哨版本 です，但先学朴素简单的形式有非常充分的理由。所以我们就学 だ。你看 だ 这个字，就像一个左边封了口的等号。这是对它功能最完美的助记，因为**だ 告诉我们 A 是 B。**

为什么左边要封口？因为它只能单向工作。从逻辑上想一想：さくらが日本人だ 意思是 <code>Sakura = Japanese person.</code>。但反过来不成立：日本人都是樱——他们并不都是樱。樱是日本人，但日本人不一定是樱。

## 形容词句

现在我们有了 <code>A is B</code> 句和 <code>A does B</code> 句。日语核心句还有一种形式，因为它一共有三种形式。第三种形式，就是句子里有一个描述性的词——形容词。

**在日语里，描述性的词以 い 结尾**（i），就像英语里它们也常常这样：happy、sunny、cloudy、silly。日语里完全一样：happy——[嬉]{うれ}しい；sad——[悲]{かな}しい；blue——[青]{あお}い。

这些词我们不必全都去背，但我们必须了解以 い 结尾的日语形容词，因为它们构成了第三种句子。那就挑一个简单的：ペン（这词很好记，因为它就是“笔”）——<code>ペンが[赤]{あか}い</code> = <code>pen is red</code>。

你注意到了，这句话里没有 だ。为什么？**因为 い 形容词 [赤]{あか}い（红）——它的意思不是“红”，而是“是红的”。だ 的功能、那个等号的功能，已经长在这些 い 形容词里面了。**

![](../media/image557.webp)

以上就是日语句子的三种形式。**它们都以句子的主语开头，都用 が 连接**，而结尾可以有三种方式：以动词结尾，动词以 う 段音收尾；以系词 だ 结尾；或者以 い 结尾，因为最后一个词是形容词。现在你已经懂日语的基础了。
