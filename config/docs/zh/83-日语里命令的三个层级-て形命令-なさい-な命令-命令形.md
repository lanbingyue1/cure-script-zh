# **83. 日语里命令的三个层级：て形命令、なさい、な命令、命令形。**

[**日语里命令的三个层级：て形命令、なさい、な命令、命令形。第 83 课**](https://www.youtube.com/watch?v=zayeW4AQ0Is&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=90)

こんにちは。

今天我们要谈在日语里发出命令和请求的方式。你大概已经知道其中一些了，但我想我们要稍微深入一些你可能还没意识到的东西。

**我们将从最不强势、最不强烈的，走向最强势的**，所以我们会从一个人人都知道的开始，也就是 て形。

## て形

有些资料会告诉你，て形 本身就是一个命令或请求形式。**那只对了一半。它是命令或请求的缩略。**

如果我们说 <code>ちょっと待って</code>（等一下），**这是一个缩略**，缩略自 <code>ちょっと待ってください</code>（请等一下）

![](../media/image1039.webp)

而且大概正因为如此，它是最不容易冒犯人的一种，尽管**它仍然很随意。**

现在，有时你会听到人们说的不是 <code>ちょっと待って</code> 而是 <code>ちょっと待って**て**</code>。这是怎么回事呢？

![](../media/image200.webp)

本质上，他们说的是 <code>**Wait a little bit and I'll be back**</code>（等一下，我很快回来）。**言外之意是，这段等待的时间会很快结束。**

而这实际上其实是 <code>ちょっと待って**いて**</code> 的缩略。如我们所知，<code>待っている</code> 意思是 <code>exist in a state of waiting</code>、<code>be waiting</code>，在英语里。**所以 <code>ちょっと待ってて</code> 其实是把这个 <code>待っている</code> 放进 て形**，**好让你被要求或被指示去做的事，是存在于一种等待的状态中。**

而它的言外之意是，**就稍微存在一会儿，存在于一种等待的状态中。** **当然这不一定是等待，它可以是任何事，** **但言外之意是，就做一会儿，就短暂地存在于那种状态中。**

---

**如果我们不说 <code>ちょっと</code>**（我们也不一定说），**那么就没有任何东西表明是一段短时间，但那永远是** **用 て形 告诉某人去存在于某种特定状态的言外之意。**

### て形 与 ない 补助形容词

关于用来告诉或请求某人做某事的 て形，另一件要知道的事是：如我们所知，**任何动词的否定对应形容词，** **都是通过简单地把补助形容词 <code>ない</code> 附加到 あ-词干上构成的。**

**而补助形容词 <code>ない</code> 其实很不寻常，因为它有两个 て形。** 它有规则的 て形，它和其他任何 て形 一样，通过把 -て 附加到 く-词干上构成，所以那是 <code>なくて</code>，**但它还有一个不规则的 て形 <code>ないで</code>。**

![](../media/image697.webp)

而当它附加到一个动词上时，这只会被用在两种情形里。

#### ないで - ない 的不规则 て形

一种是当我们说 <code>do B without doing A</code>（做 B 而不做 A）时，所以 <code>話さないで歩く</code> 意思是 <code>walk without talking</code>（不说话地走路）。**另一种是当我们在做那个 て形 构成的命令或请求时。**

而再一次，它是 <code>ないでください</code> 的缩略。所以如果我们说 <code>**泣かないで**</code>（不要哭），**那是在使用 <code>ない</code> 的这个次级的、专门的 て形**，**它专门用于构成否定命令或请求**，**以及我们讨论过的那另一种用法。**

而有时在动漫里，当一只怪物朝她逼近时，你会听到某人尖叫 <code>来ないで!</code>（别过来）。

![](../media/image955.webp)

在英语里我们大概会说 <code>Keep away!</code>。在日语里我们说 <code>来ないで!</code>

## なさい

现在，接下来轮到我们命令层级里的 <code>なさい</code>。**<code>なさい</code> 被附加到动词的 い-词干上**，而**当你把 <code>なさい</code> 附加到一个动词的 い-词干上时，你就把它变成一个命令。**

![](../media/image740.webp)

所以，<code>起きなさい</code> 是 <code>get up / wake up</code>（起来 / 醒来）；<code>落ち着きなさい</code>（冷静下来，安定下来），**我们把 <code>なさい</code> 附加到 <code>落ち着く</code> 的 い-词干上，** **它的意思是 <code>calm down</code> 或 <code>settle down</code>，并把它变成一个命令。**

---

**<code>なさい</code> 是那种父母对孩子下的命令，** **老师对全班下的命令，诸如此类。** **如果它是由有权下这种命令的人下的，它就不冒犯人。**

---

所以，举个例子，在动漫 <code>借りぐらしのアリエッティ</code> 里，阿莉埃蒂的父亲说 <code>寝なさい</code>。**那是 い-词干，对于一段动词，我们当然是通过简单地** **去掉 -る 来构成的，也就是 <code>寝る</code>**（睡觉，或上床睡觉）**加上 <code>なさい</code>**。

### な - なさい 的缩略

**这里可能会让人困惑的一件事是，<code>なさい</code> 有一个缩略** **而它可能和一个意思相反的另一个缩略混淆。** **而那个缩略就是 <code>な</code>。**

当我们把 <code>な</code> **附加到动词的 い-词干上**时，那我们其实是在把 <code>なさい</code> 缩略。**所以如果我们说 <code>準備しな</code>，我们是在说 <code>準備しなさい</code>（准备好，做好准备）**：<code>準備する</code>，<code>する</code> 的 い-词干，<code>し</code> + <code>なさい</code> 或 <code>な</code>。

![](../media/image402.webp)

现在，那本身并不特别令人困惑。可能让人困惑的是，如果我们说，比如，<code>バカにするな</code>（别耍我，别耍她）；

![](../media/image317.webp)

<code>それを食べるな</code>（别吃那个！\[可能有毒\]）。**这意思相反！**

**我们把 <code>な</code> 既用于一个做某事的命令，** **也用于一个不要做某事的命令。** 那我们怎么区分这两者呢？幸运的是，这非常容易。

**如果 <code>な</code> 被附加到 い-词干上，那它就是 <code>なさい</code> 的缩略。**

![](../media/image819.webp)

**它永远都是。**

---

**如果它不是附加到 い-词干上，而是附加到整个逻辑小句上** **像在 <code>それを食べるな</code> 里那样，那它就不是 <code>なさい</code> 的缩略。** **它其实是一个与 <code>ない</code> 相关的更古老的否定。**

![](../media/image729.webp)

所以其实，尽管它们一开始可能看起来令人困惑，而当你被某本教科书告知只需记住它们各自黏附于哪些特定形式时，它们大概确实令人困惑，但在实践中它其实并不令人困惑。

**一个只黏附在 <code>なさい</code> 会黏附的 い-词干处，** **而那就是意思是 <code>なさい</code> 的那一个！** **另一个则用一个否定化的 <code>な</code> 收尾一个完整的逻辑小句。**

## 真正的命令 / 命令形

而现在我们来到真正的命令形式，日语里的 <code>命令形</code>。

![](../media/image531.webp)

**而它的构成非常简单，就是使用一个五段动词光秃秃的 え-词干，或者，** **对一段动词，我们照常去掉 -る，并用 -ろ 替换它。**

所以你可能会在动漫里听到人们说 <code>黙れ!</code> **那是动词 <code>黙る</code>**（安静，沉默）**变成的一个命令：** **<code>Be quiet!</code>**

**而这真的相当有力。** **它比 <code>うるさい!</code>** 更强、潜在也更具冒犯性（如果你想把这一点跟下去，[**我做过一个关于 <code>うるさい</code> 的视频**](https://www.youtube.com/watch?v=1jBOq1EHwvs)。）

**它本身并不冒犯人** *（命令形 这个形式）*。**如果某人真的有权发号施令，他们可能会用它。** **而说话粗鲁的人可能会在朋友之间或对敌人用它。**

你可能会在少年动漫里听到很多次，那里的人往往说话粗鲁。**它在少数情况下也能表达急迫。** **你常会听到的一个情况是，当一个角色陷入严重麻烦时** **喊出 <code>助けてくれ！</code>，它就像 <code>助けてください！</code>** **但把它变成一个真正的命令、一道指令。**

现在，显然一个深陷麻烦的人在试图帮助他的人面前，不是想侮辱或冒犯谁。**所以这个 <code>くれ</code> 在这个情况下所做的事，是表达情况的急迫性。**

然而即便在这里，我也得说我只听到过**男性角色用这个 <code>助けてくれ</code>。** 女性角色，即便在最危急的关头，也往往会满足于 <code>助けて!</code>

**而这显示出真正的 <code>命令形</code> 命令形式其实有多么微妙。** **<code>くれ</code> 真的是唯一的那个不规则 <code>命令形</code>，除了** **那两个常规的不规则动词，也就是 <code>する</code> 和 <code>くる</code>。**

![](../media/image995.webp)

**所以 <code>くれる</code>（向下给 / 给我）变成 <code>くれ</code>。**

::: info
显然，如所示，くれ 是 **くれる** 的一种形式；不是 [来]{く}る（那一个有 [来]{こ}い）
:::
---

而，如你所见，**它是一种特别敏感的用词，** **因为你在求一个恩惠，但你是在强求它，** **你在命令某人给你一个恩惠。**

现在，为了完整起见，我要说还有另外两种发号施令的方式，它们主要用于别的事情，但也可以被用作命令形式。

## のだ / んだ 结尾

**其中一个是 <code>のだ / んだ</code> 结尾，它被放在一个完整逻辑小句的末尾**，而[**我做过一个关于这个 <code>のだ / んだ</code> 结尾的视频**](https://www.youtube.com/watch?v=lYvIOi8Q3I8)，我会在我头顶上方以及下面信息区放一个链接。

如我在视频里解释的，**它有一系列很广的用法**，**但其中一个用法是把某件事变成一个命令。** 所以如果我们说 <code>宿題をする**のだ**</code>，我们字面说的是 <code>**It's that** (you) do (your) homework</code>（就是（你）做（你的）作业）。

![](../media/image220.webp)

这会有点像英语的 <code>You're going to do your homework</code>。**它是一个命令。**

## ように

**另外，<code>ように</code>，作为句尾它往往更多地和** **祈祷、请愿和请求联系在一起，它也能构成一个命令。**

::: info
![](../media/image1093.webp)
:::

---

而我提到这些的主要原因是，**如果你在你的沉浸里遇到它们** **而你看到某个通常在做别的事的东西** **看起来像一个命令，<code>のだ</code> 或 <code>ように</code>，那就别被它搞糊涂。** **在这些情况里，它是一个命令。**
