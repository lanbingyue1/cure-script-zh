# **89. 为日语祛魅。普遍主语**

[**为日语祛魅。让世界上最讲逻辑的语言闪耀吧！普遍主语 第 89 课**](https://www.youtube.com/watch?v=CEgGnitwXGA&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&ab_channel=OrganicJapanesewithCureDolly)

こんにちは。

今天我们要谈一个正是日语根基的东西，我们从第一课起就一直在谈它。**而那就是语法上的主语，我们用火车语言所说的 <code>A-car</code>（A 车厢）。**

![](../media/image732.webp)

而如我们所知，每个日语句子都必须有**一个 A 车厢、一个主语、日语里的 <code>主語</code>**，以及**一个 B 引擎——也就是谓语，或日语里的 <code>述語</code>。**

**换句话说，每个句子都是在说某事物的一些什么。**

![](../media/image112.webp)

现在，有些人主张日语里没有主语；有些老师这么做，包括 Tae Kim 老师，而

![](../media/image906.webp)  
一般来说，这是因为他们对这门语言实际如何运作没有很好的把握。有些日本人，一小部分语言学家，也为日语提出一个无主语的模型。

::: info
再一次，这只是模型上的差异，就像 Dolly 提出没有活用、没有被动一样。通常，就本土衍生的日语语法语言学而言，如果某个东西被称为 x，用它来描述这门语言在语言学上是可行的，但有些模型有它们自己的体系，出于各种原因，要么与它们相合、要么不相合。  
就像 Dolly 下面所说的，这些模型存在只是为了把语言描述成某种连贯的块，同时找到一些共同点，但它们在某些地方可能有分歧。  
用哪个模型由你决定，最终只要你不再需要解释和术语、把语言自动化了，你无论走哪条路都应该能达到流利，但学习大多数（尤其本土）语言学模型里的普遍共识是有帮助的。

![](../media/image342.webp)
:::

**如我之前所说，语法、结构、模型，随你怎么叫它们，都不是语言的源代码。它们是事后描述语言的手段。** 所以，为日语设计一个不使用主语概念的模型也许是可能的，但这其实只会是把术语搬来搬去而已。

曾有一个日本人相当愤怒地闯进我的评论区，说我把主语这个概念带进来是在把日语西方化。现在，我想如果你了解我的工作，你就知道我不把日语西方化。

我把日语当日语来教。**无主语模型究竟是否真的有效，我不知道。我没有研究过它们。**

**但我们需要表明的是，我们所使用的、也是大多数日本语言学家所使用的那个主语模型，是有效的，而且一直有效、完全有效、可靠且可预测。**

## The <code>Null-Subject</code>

**有些语言在语言学里被称为 <code>null-subject languages</code>（零主语语言），这并不是说它们没有主语，而是说它们的主语并不总是可见的，而这正是日语里的情况。**
::: info
这个不可见主语的东西，如果你的母语也有（显然），在日语里就更容易把握。这就是为什么英语母语者（显然）往往对此感到困难，因为英语大多需要一个直接说出／可见的主语，以及为什么会有那些令人困惑的解释，试图把英语的 <code>Subject must be voiced/visible</code>（主语必须被说出／可见）方式强加到日语上。
:::
![](../media/image805.webp)

比如在西班牙语里，**我们一般不说**，<code>**Yo** soy Americana</code>，尽管教科书教我们要那样说。**而我们不这么说的原因是 <code>yo</code> 是多余的。**

**<code>Soy</code> 暗示 <code>I</code>（我），所以如果我们只说 <code>Soy Americana</code>，那就是我们所需说的一切。其他都是多余的。英语里也一样。**

如果我们说 <code>I am American</code>，我们其实不需要那个 <code>I</code>，因为 <code>am</code> 暗示 <code>I</code>。**我们不会把 <code>am</code> 和 <code>I</code> 以外的任何东西一起用，所以那个 <code>I</code> 是多余的。**

**只不过英语不允许你丢掉它。所以这只是规则的问题。** 日语不是这样运作的，因为日语没有像 <code>am / is / are</code> 这样的活用。事实上，尽管教科书怎么说，它根本没有活用。

**在日语里，零主语完全由语境决定。而当语境没把它说清楚时，它一般默认为 <code>I</code>。**

---

**这几乎正是英语 <code>it</code> 所做的，只不过英语里的 <code>it</code> 没有被归零。**

![](../media/image930.webp)

所以如果我说 <code>**It** fell from the sky / **It** ate my breakfast / **It**'s half the size of the other one</code>，**除非语境给出答案，否则你完全不知道 <code>it</code> 是什么。**  
**这就是零代词在日语里运作的方式。**

**我们能看见、能听见 <code>it</code>，而我们看不见、听不见那个零代词，这个事实对这一切没有任何影响。**

那么，如果我们拿那种人们试图称之为 <code>subjectless</code>（无主语）的句子，比如拿一个像 <code> *(zeroが)* 疲れた</code> 这样的句子。

![](../media/image467.webp)

**现在，它字面上只意为 <code>Tired</code>（累了），所以它可以被叫作一个无主语句子，但它绝对不是**——除非你出于自己的理由想避开 <code>subject</code> 这个术语。

当我们说 <code>疲れた</code> 时，**我们不是在说月亮上的兔子累了。我们不是在说米老鼠累了。**

**我们不是在说疲倦像一片紫色雾霭一样笼罩已知宇宙。我们是在说 <code>I am tired</code>（我累了）。** 如果不是那样，日语就不会是一门语言，因为我们就做不到一门语言需要做的基本事情，即对事物 A 做出陈述 B。

如果我看着一个女孩说 <code> *(zeroが)* 綺麗なのね?</code>

![](../media/image381.webp)

**再一次，我不是在说月亮上的兔子漂亮，也不是说生活在总体上漂亮。我有一个非常明确的主语，我自己和听者都知道它。**

## Indeterminate Subject

**现在，有些情况里我们有一个不确定的主语**，而有些人可能会试图主张，这些至少是我们那神秘的、无主语的日语句子。**但事实上它们和它们的英语对应物没有区别。**

所以我们可能会说 <code> *(zeroが)* 晴れそうだ</code>，它意思是 <code>*(***it***)* looks like being fine</code>（（它）看起来会晴朗）。

![](../media/image224.webp)

而你可以问 <code>What looks like being fine? The weather, the day, this part of the world?</code>（什么看起来会晴朗？天气、今天、这个世界的这一部分？）**没有一个确切的答案。**

**而这当然在英语和日语里都是一样的。主语是不确定的。在英语里我们知道有一个主语，因为它的位置由 <code>it</code> 占据着。**

**那日语呢？我们只是硬把一个主语塞进去吗？不，我们不是。注意 <code>だ</code>，系词 <code>だ</code>。**

![](../media/image760.webp)

我们都知道 <code>だ</code> 是什么<sup>[[79]](./79-系词更深层的秘密.md)</sup>（如果你不知道，[**我会链接一个视频**](https://www.youtube.com/watch?v=euHYPcMoao4)，这样你可以跟进）。

*---

**系词告诉我们，一个事物是另一个事物。**

![](../media/image686.webp)

如果我们说 <code>Roses **are** flowers / Mary **is** an artist / Today **is** Saturday</code>，**我们是在把一个事物（主语）连接到另一个事物（谓语），  
或者把 A 车厢连接到 B 引擎。**

**这就是 <code>だ</code> 所做的，而这就是它所做的全部。**

**所以我们知道这个句子有一个零主语，尽管它没有由 <code>it</code> 占据位置标记出来。**

![](../media/image567.webp)

**我们看不见它，我们听不见它，但我们确知它在那里，因为没有了它，<code>だ</code> 就毫无意义。**

## Really Subjectless sentences in Japanese

**现在，日语里其实有一种真正是无主语的句子。** 你在英语里也能找到它，但它在日语里稍微更常见一点——但也没那么常见。

而**它是个像** <code>大阪にたどり着いた桜たち</code> **或** <code>恥ずかしくなったハナコ</code> 这样的句子。

::: info
我在第二个例句里把名字 Hanako 写成了片假名。
:::
![](../media/image869.webp)

**这些其实不是句子，它们也不会被大多数语言学家当作句子**来对待。**它们是简单的被修饰的名词。** 所以我们是在说 <code>Arrived-at-Osaka Sakura and friends</code>（到了大阪的樱一行人）。

**我们不是在说 <code>Sakura and friends arrived at Osaka</code>（樱一行人到了大阪）。我们只是说 <code>Sakura and friends</code>（樱一行人），并用修饰语 <code>arrived-at-Osaka</code>（到了大阪的）来修饰他们。**

**<code>恥ずかしくなったハナコ</code>——我们不是在说 <code>Hanako became embarrassed</code>（花子变得尴尬了），我们是在说 <code>Embarrassed Hanako</code>（尴尬的花子）。**
::: info
或者我猜 <code>Hanako, **who became embarrassed**…</code>（花子，她变得尴尬了……）

![](../media/image925.webp)
:::
::: info
抱歉缩放得很糟，又被 <code>Youtubed</code> 了。这种修饰基本上可以翻译成英语里某种关系小句。Dolly 的链接指向第 46 课。
:::

我们什么时候用像这样的 <code>sentences</code>？

嗯，不很常见，但**它们能被用在叙述中，因为它们本质上所做的是要么总结之前发生的事**——你特别常在比如说游戏里看到这个，当你加载时它们给你一个对已发生事情的小回顾——要么是在描述已发生事情的结果：<code>And the result was, **an embarrassed Hanako**</code>（而结果就是，一个尴尬的花子）。

**这真的就是，我认为，我们能找到的、也许可被称为无主语句子的唯一例子，但它其实不是一个无主语句子，因为它不是一个句子。** **它只是一个带了一点修饰的名词。**

**所以如果你遇到这些，** 而如果你在做沉浸，你会时不时遇到这些，**你并没有找到一个无主语句子，你找到的是一个偶尔会被用在日语里的特定叙述手法。**

它当然不会给那些说日语里没有主语的人的论点增添任何分量，因为这些是所谓句子中非常小的一小撮，而且它们当然不会影响这个事实：**一个真正在向我们讲述某事物某些事情的句子，总是有一个 A 车厢和一个 B 引擎，一个主语和一个谓语。**
