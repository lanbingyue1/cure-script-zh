# **59. 存在不可翻译的日语！如何理解它**

[**存在不可翻译的日语！如何理解它｜第 59 课**](https://www.youtube.com/watch?v=wLrK_YxdPoM&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=61&pp=iAQB)

こんにちは。

今天我们要讲一件让相当多的日语句子对英语学习者来说难以理解的事。

![](../media/image598.webp)

那就是我称为 <code>the problem of passivity in Japanese</code>（日语里的被动性问题）的东西。我这里说的不是所谓的日语被动，那实际上是受动补助动词。那是个问题，因为人们倾向于在它不是被动的时候称它为被动，但实际上还有好几种日语结构比这更深，它们被当作被动来看待和翻译——尽管它们实际上并不叫被动——从而造成问题。

而这很重要，因为如果我们把它们看成被动的，那我们就会误解这些句子，我们就不会理解为什么逻辑助词处在它们所在的位置，尤其是句子更复杂的时候，  
我们根本就没法弄明白到底发生了什么。

那么，如我之前所说，日语里其实并不存在真正的被动语态，但这里要考虑的一点是，有某种我们可以称为日语整体的被动性质的东西。而这和英语里存在的语法被动语态毫无关系。这更是一种哲学上的被动，而非语法上的被动。

而这里的 <code>passive</code>，我指的就是 active 的反面。如我之前解释过的，日语动词的亚当与夏娃是 <code>ある</code> 和 <code>する</code>，<code>ある</code> 意思是 <code>be</code>，<code>する</code> 意思是 <code>do</code>。

![](../media/image593.webp)

虽然我们称它们为 <code>Adam and Eve</code>，我们其实应该把它们称为 <code>Eve and Adam</code>，因为日语有一种倾向，把 <code>being</code> 视为先于并优先于 <code>doing</code>，而英语倾向于反过来想事情。英语本质上倾向于行动主义。

而有一整系列日语动词，描绘的并不是我们所理解的动作，而是存在状态——这些状态在语法上被当作好像它们事实上是动作一样。再者，理解情况正是如此，对于理解句子如何运作至关重要。

而我们可以从一个通常其实并不被翻译成被动、但如果翻译成被动会稍微好一点的东西开始，那就是我们已经在另一个语境里看过的东西：如果我们说 <code>本が分かる</code>，它被翻译成英语是 <code>I understand the book</code>，而它根本不是那个意思，因为如我们所见，书是这个句子里被 が 标记的主语。

![](../media/image21.webp)

所以是在做某件事的是书，不是我。我什么都没做。而事实上，如果我们把它翻译成 <code>The book is understandable (to me)</code>，对句子结构的扭曲要小得多。

这几乎就是日语在说的。书是主语，实际在做那个动作的是书。<code>The book is understandable to me</code> 之所以不是一个完美的翻译，是因为如你所见，这实际上不是一个 A-is-B 句子。

所以我们不该说 <code>The book is understandable (to me).</code>。要把日语弄对，我们必须说的是 <code>The book **does** understandable (to me).</code>。而这在英语里当然完全讲不通，因为在英语里 <code>being understandable</code> 被视为一种状态。

但在日语里，它被视为一个动作，我们可以称之为 <code>stative action</code>（状态性动作），一种“存在”类的动作，就像 <code>being</code> 本身。即使在英语里，我们也能说某个东西 <code>exists</code>。但一般来说，英语要求东西蹦来蹦去地做点什么，才会说它们在采取任何种类的动作。

但在日语里，存在于特定状态这个动作常常由一个动词来表达。而这很重要，因为它延伸到一整系列日语词，延伸到 できる 以及任何一个附带了可能助动词的动词。

所以如果我们说 <code>日本語ができる</code>

![](../media/image911.webp)

它被翻译成 <code>I can do Japanese</code> 或 <code>I can speak Japanese</code>，后者更加奇怪，因为里面并没有 <code>speak</code>，而它实际说的是 <code>Japanese is possible (to me)</code>，但再一次，这是一个 A-is-B 结构，而事实上这真的是一个 A-does-B 句子。它在说的是 <code>Japanese **does** possible (to me)</code>。

那么，这看起来可能有点吹毛求疵，但它不是吹毛求疵，因为助词、结构、句子的整个框架都不同。而在像这样的简单句子里，它也许不太重要，但随着句子变得更复杂，这整个问题就变得更重要，因为我们开始遇到一些句子，除非我们认出它们实际的结构是什么，否则根本无法理解。

---

而有一整系列动词，指称在英语里会被称为状态的东西。而在这些情况下，英语翻译总是被动的。而它们必须是被动的，因为在英语里确实没有另一种方式来说它们。

比如，<code>乱れる</code>——散乱或无序；<code>欠ける</code>——有缺口、受损或不足；<code>映る</code>——被反射或被投射。

![](../media/image1006.webp)

如你所见，其中每一个我都用英语被动来翻译了，因为这是把它们翻译成自然英语的唯一方式。

**但它们在日语里其实不是被动的。** 这些被视为由以下这些东西所做的动作——
-   那个无序的东西，
-   那个损坏的东西，
-   那个被反射的东西。

所以，如果没有别的选择、只能把它们翻译成被动，那我们这么做难道不也正当吗？答案是：是的，如果我们想做的只是告诉一个不懂日语、也没在学日语的人别人在说什么，或者更准确地说，一个英语母语者在同样情形下会说什么，那么我们当然完全正当。

但如果作为日语学习者，我们不知道句子实际在做什么，我们就会把自己弄得一团糟。我们会看着句子，纳闷它们是什么意思，而如果我们尝试自己造句，我们就是造不出来，因为我们会去寻找被动结构，会试图按照一些我们没被介绍过、也不理解的原则来造句。

**所以这里要理解的是，在日语里，动词能够、而且常常确实表达在英语里只能被表达为存在状态或被动动作的东西。**

---

然后还有另一组动词，在类型上和这密切相关，它们被翻译成 <code>becoming</code>（变成）某个特定的东西：
<code>濡れる</code>——变湿；
<code>濁る</code>——变得浑浊或泥泞。

![](../media/image511.webp)

再者，在日语里，这不被说成 <code>becoming</code> 任何东西。  
它本身就是单纯的一个动作。

如果我们想在英语里找一种说法来把它表达出来，我们就得发明一个像 <code>muddify</code> 或 <code>cloudify</code> 或 <code>wetiniflicate</code> 这样的词，但事实上这些词当然在英语里并不存在。

**而在日语里理解它们的关键，不是试图把它们翻译成英语，而是看清它们在日语里实际是如何运作的，并且意识到在这些情况下逐字对应的翻译是不可能的。**

而这些“变成”类的词，比如 <code>濁る</code> 或 <code>濡れる</code>，也可以用在持续现在时里，把我们带回到之前那些词所具有的被动状态。

所以，比如 <code>濁ている</code>：我们说的是一个在英语里只能翻译成 <code>be cloudy</code> 的东西，但在日语里，再一次，它是 <code>exist in a state of cloudiness</code>。

所以这是一个相当简单直接的问题，但我们吸收并理解这个原则非常重要，否则我们会在整整一系列日语表达上遇到很多麻烦。。
