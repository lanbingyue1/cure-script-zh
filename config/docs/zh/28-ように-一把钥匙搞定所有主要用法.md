# **28. ように - 一把钥匙搞定所有主要用法**

[**第 28 课：You ni——一把钥匙搞定所有主要用法！懂了就很容易**](https://www.youtube.com/watch?v=IE7WgIOOGbM&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=30&pp=iAQB)

こんにちは。

*今天*我们要讲 <code>ようになる</code>、<code>ようにする</code>、<code>ことにする</code>、<code>ことになる</code>*（才不是）*。嗯，这些表达的所有元素我们都已学过，所以我们现在要做的，就是看看它们在这些情况下如何组合在一起、它们是什么意思，以及它们为什么是那个意思。

那我们就快速复习一下 <code>になる</code> 和 <code>にする</code>。如我们所知，两个最根本的日语动词是 <code>ある</code> 和 <code>する</code>。<code>ある</code> 是所有自移动词之母，<code>する</code> 是所有他移动词之父。

<code>なる</code> 与 <code>ある</code> 密切相关——<code>ある</code> 意思是 <code>be</code>（存在）；<code>なる</code> 意思是 <code>become</code>（变成）——所以我们可以说 <code>ある</code> 和 <code>なる</code> 是同一个动词的静态和动态版本。也就是说，同一个动词静止着和在时间中运动着。

现在，我们知道当我们在一个名词后面用 <code>になる</code> 时，我们的意思是某物变成了那个名词。

![](../media/image1038.webp)

<code>に</code> 标记转变的目标，而 <code>なる</code> 是转变本身，也就是那个变成。

## ようになる

那么，当我说 <code>ようになる</code> 时……嗯，我们上周看了 <code>よう</code>，对吧，我们看到当我们在比较事物或把事物比作彼此时，<code>よう</code> 意思是一个 <code>form</code>（形态）或一种 <code>likeness</code>（相像）。它的基本意思是一个形态或一种存在状态。

当我们说 <code>りきしは山のようだ</code>——<code>sumo wrestler is like a mountain</code>（相扑力士像一座山）——我们不是在说那位相扑力士 <code>is</code>（是）一座山，我们是在提取那座山的形态或存在状态，并把它应用在那位相扑力士身上。我们不是在说那位相扑力士就是那座山，我们是在说那位力士是山的 <code>よう</code>，也就是山的形态或存在状态。

所以在英语里我们说那位力士 <code>like</code>（像）那座山；在日语里我们说那位力士是山的形态或存在状态——我们也许可以说，是山的 <code>likeness</code>（相像）。现在，当我们在今天要讲的这些表达里使用 <code>よう</code> 时，我们不是把它加到一个像 <code>山</code> 这样的名词上，而是把它加到一个完整的逻辑小句上。

教科书有时说我们是在把它加到一个动词上，但我们真正做的，是把它加到一个带动词引擎的逻辑小句上。

![](../media/image364.webp)

而 <code>よう</code>，如我们所知，是一个名词；那个逻辑小句变成那个名词的形容词性成分、描述成分，所以我们知道任何动词引擎连同它所领起的逻辑小句都能变成形容词性成分，所以我们不是在说 <code>のよう</code>，我们这里不是在说别的东西的相像。所以当我们有一个逻辑小句加上 <code>ようになる</code> 时，我们是在说某物变成了、或进入了那个逻辑小句的存在状态或形态。

所以，比如，如果我们说 <code>彼を信じるようになった</code>，我们是在说 <code>I came to believe him.</code>（我变得相信他了。）

![](../media/image893.webp)

<code>彼を信じる</code>（或 <code>zeroが彼を信じる</code>）——<code>I believe him</code>（我相信他）——是一个逻辑小句，而我们是在说，我移动进了那个状态，我变成了那个逻辑小句的状态：<code>I came to believe him.</code> 这常常和一个可能补助动词一起用。

比如，我们可能会说 <code>日本語のマンガが読めるようになった</code>——<code>Japanese manga became readable (to me)</code>（日语漫画变得（对我）可读了）。

![](../media/image304.webp)

如你所见，在两种情况里，某物都在改变它的状态。我把我的状态从相信他变成了相信他；漫画把它的状态从不可读变成了可读。在所有情况里，我们谈的都是一种状态变化，某个人或某个东西现有状态从一个状况到另一个状况的变化。

而如果你想知道，为什么我们在日语里最常说的是漫画从不可读变成可读，而不是像英语里我们通常做的那样，说这个人从不能读漫画变成能读漫画，请去看关于可能补助动词的那节视频课，我在那里解释了这是怎么运作的。<sup>[[10]](./10-补助动词-可能形补助动词.md)</sup>

## ようにする

现在，当我说 <code>ようにする</code> 时，我们知道 <code>にする</code> 结构是 <code>になる</code> 结构的他移版本。如果我们说 <code>まじょがさくらをカエルにした</code>，我们是在说 <code>the witch turned Sakura into a frog</code>（女巫把樱变成了一只青蛙）。

![](../media/image93.webp)

所以 <code>ようにする</code> 就是使某物进入一个状态。它不是靠自己进入的；是某个人在使它进入那个状态。所以如果我们说 <code>よく見えるにする</code>——<code>よく見える</code> 意思是 <code>look good</code>（好看），所以 <code>よく見えるようにする</code> 就是使某人或某物好看。

现在，<code>ようにする</code> 有一个延伸的含义，那就是当我们说某个本质上相当于 <code>please make sure that you do something</code>（请你务必做某事）的东西时。所以，我们可以说 <code>ドアにかぎをかけるようにしてください</code>，那意思是 <code>please make it so that you lock the door</code>（请让情况变成你锁上门）。

![](../media/image771.webp)

而我想你能看出这里和单纯说 <code>ドアにかぎをかけてください</code> 之间的区别，后者只是 <code>please lock the door</code>（请锁门）。在一种情况里，你有点假定那个人会想当然地把它锁上；在第二种情况里，你对此做了特别的强调：<code>Please make it so that you lock the door (this is important, so please make it be that way)</code>（请让情况变成你锁上门（这很重要，所以请让它成为那样））。

这里的 <code>It</code> 就和它在英语里会指的一样——那个 <code>situation</code>（情况）、那个 <code>circumstance</code>（情形）——“请把那个情况从你不锁门的那种，变成你锁门的那种。”所以这给这个指示或建议做了特别的强调。

现在，与此相关的是，当你可能说一些关于你自己的事时，通常与你定期做的事有关，比如 <code>毎日歩くようにする</code>。而那字面上意思是 <code>\[I\] (try to) make it so that \[I\] walk every day</code>（（我）（试着）让它成为（我）每天走路）。

但当你这么表达时，而不是只说 <code>毎日歩く</code>——那只是说 <code>I walk every day</code>（我每天走路）——其含义是你试着这么做。你不一定总能成功。而且，你看，和另一个用法一样，对于你会不会做到是有某种怀疑的。

除非你心里对这事会不会发生有某种怀疑、并正试图让它发生，否则你不会说 <code>Please make it so that you lock the door</code>。

## ことにする

当你把它说成关于你自己的事时——<code>毎日歩くようにする</code>——还有另一个因素在起作用，那就是当是你自己时，你也可以用 <code>ことにする</code>，而它表达的是一个坚定的决定，我们下周会在这节课的后半部分谈它。所以如果你选 <code>ようにする</code> 而不选 <code>ことにする</code>，你本质上就留下了一点怀疑的余地。

## <code>Cause-and-effect</code> usage of ように

现在，<code>ように</code> 也能用在后面有一个小句、前面也有一个小句的情况下，以表达 <code>do one thing in order that another thing may happen</code>（做一件事，以便另一件事发生）。

![](../media/image756.webp)

教科书把这当作一条不同的语法、一个不同的语法点来对待，但事实上它并不是，它和普通的 <code>ようにする</code> 是一样的，它看起来有点不同的唯一原因，是我们在英语里把它说得稍微不同。但我们不该想着英语；我们该想着日语。那我们就来看看它是怎么运作的。

我们拿一个我们已经有的句子：<code>よく見えるようにする</code>——<code>make something (or someone) look better</code>（使某物（或某人）更好看）。现在，我们把它改成 <code>よく見えるように口紅をつける</code>——“为了让她更好看（或我更好看，或某人更好看），涂口红”。

![](../media/image992.webp)

现在，如你所见，英语里表达这两个想法的方式不同，而这就是为什么教科书和传统解释谈起来，就好像我们有两条各自独立、互不相关的语法点。但如果你看看正在发生什么，就能看出它们其实是同一回事。

在一种情况里，我们是在说 <code>make someone or something look better</code>（使某人或某物更好看），不指明手段。我们只是用那个中性的、万能的动词 <code>する</code>，它是根本的他移动词。当我们说 <code>よく見えるように口紅をつける</code> 时，<code>口紅をつける</code> 只是替换了那个 <code>する</code>。

而不只是不具体地说一句 <code>make someone look better</code>，它说的是 <code>do a specific thing in order to make someone look better</code>（做一件具体的事，以便使某人更好看）。现在，<code>する</code> 也是一个动作；它只是一个不具体的动作。它只是 <code>do/act/make something happen</code>（做／行动／使某事发生）。

<code>口紅をつける</code> 具体说明了在某个特定情况下那个 <code>する</code> 可能是什么。所以你看，我们这里有着完全相同的结构，而不是两条各自独立的 <code>grammar points</code>（语法点），就像他们喜欢叫的那样。

## ように at the end of a sentence

而最后一点说明是，你有时会在句末听到 <code>ように</code>，通常是一个 ます 结尾的句子。这主要用在祈祷和请愿上。所以你可能会说 <code>日本に行けますように</code>。

而你可能会在一座神社说它，或在对着流星许愿时说它，或者也许只是在你表达一个愿望、希望一个朋友能去日本时。我们为什么用它？嗯，很明显它算是一种 <code>ようにする</code> 的缩略。

如果你是在对一位神明或一位仙女说话，它可能是 <code>ようにしてください</code> 的缩略。那么，下周我们接着讲 <code>ことになる</code> 和 <code>ことにする</code>。
