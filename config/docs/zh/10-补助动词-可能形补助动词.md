# **10. 补助动词 & 可能形补助动词**

[**第 10 课：<code>Japanese conjugation</code>（日语活用）的神话被戳破！另外，可能形动词形式的秘密被解锁**](https://www.youtube.com/watch?v=qcOhHmU0znI&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=12)

こんにちは。

今天我们要谈主要的补助动词以及可能形。**当我说 <code>the main helper-verbs</code>（主要的补助动词）时，我指的是标准西方日语语法描述里称为 <code>conjugation</code>（活用）的那些东西。** 我提到这个词只是因为我不想让你在别的地方看到 <code>conjugation</code> 时感到困惑。

当它们谈 <code>conjugation</code> 时，它们指的就是这个。**但事实上，日语里根本没有所谓活用这回事。** **我们所做的一切，就是给四个动词词干加上补助词。** 而补助词有很多，只要你不把它们当作活用，它们大多只是一个额外词汇量的问题。

![](../media/image942.webp)

在某些情况下它们被称为 <code>conjugation</code>，在另一些情况下则不是，而它们每次都是完全一样的过程。唯一的区别是，其中一些碰巧——而且只是非常模糊地——像欧洲语言的活用，而另一些则不像。各种混乱都源自把日语补助动词和补助形容词与活用混为一谈，但既然我们不打算使用它们，我们在这里就不需要为此担心。好。

## 可能形补助动词

那么，我们要看的第一个主要补助动词是可能动词。我们已经看过补助词了，对吧？我们看过补助形容词 <code>ない</code>，它构成否定，还有 <code>たい</code>，它用于表达一个动作的意愿性。

![](../media/image314.webp)

我们也看过补助动词 <code>がる</code>，它被附加到一个形容词上。**现在我们来看可能形补助动词，而它附加到 え-词干上。**

![](../media/image973.webp)

**我们用 え-词干做的事，没有我们用 あ-词干和 い-词干做的那么多**，但也有一些。而其中只有一个是动词，所以这里没有混淆的余地。**可能形补助动词有两种形式，它们是 <code>-る</code> 和 <code>-られる</code>。**

人们可能会被 **补助动词的五段形式** 弄得有点不安，因为它 **只是一个字符，る(ru)。** 但那完全不该让你担心，而且因为它只会加到 え-词干上、不能单独使用，它非常非常容易认出来。

**<code>-られる</code> 是可能形补助动词中加到一段动词上的那个形式** ——我们之前讨论过五段动词和一段动词，对吧？所以，<code>かう</code>（买）变成 <code>かえる</code>（买-能）；<code>きく</code>（听）变成 <code>きける</code>（听-能）；<code>はなす</code>（说）变成 <code>はなせる</code>（说-能）；<code>もつ</code>（拿）变成 <code>もてる</code>（拿-能），等等。

::: info
变成 え-词干，然后是五段可能形的 る。还要注意这个……  

![](../media/image588.webp)

![](../media/image824.webp)

**它们的言外之意有一些区别，Dolly 在第 54 课里进一步把它们讲清楚了。  
Dolly 在这里似乎犯了个错误，把 聞こえる 称为他移动词，但它应该是自移动词，正如她在评论开头所暗示的（+与 Imabi 等其他来源相比较）。**
:::

**而用 <code>たべる</code>，它是一个一段动词**，我们做我们一向做的事，**就是把 -る 去掉，再加上我们打算加的任何东西。** 于是 <code>たべる</code>（吃）变成 <code>たべられる</code>（吃-能）。所以这非常简单，对吧？

**这种可能形的构成只有两个例外，它们就是那两个日语不规则动词，<code>くる</code> 和 <code>する</code>。** <code>くる</code> 变成 <code>**こ**られる</code>，但 <code>する</code> 出人意料地变成 <code>**できる**</code>。**できる 是 <code>する</code> 的可能形。**

![](../media/image1089.webp)

而 **这是一个有趣的词，因为它也表示 <code>come out</code>（出来）**——字面上它由汉字 <code>out</code> 和 <code>come</code> 构成——<code>[出]{で}きる</code>，出る（出去）来る（来）

![](../media/image656.webp)

而如果我们说 <code>にほんごが**できる**</code>，我们不是在说 <code>I can do Japanese</code>（我会日语），我们是在说 <code>Japanese **is possible**</code>（日语是可能的）/ ***<code>does</code> possible***

![](../media/image1136.webp)

而如果我们说、或暗示 <code>わたしはにほんごが**できる**</code>，我们说的是，<code>To me, Japanese **is possible**</code>（对我来说，日语是可能的）。

::: info
*(Dolly 给出 <code>does possible</code>，是为了暗示它是「A 做 B」，而不是「A 是 B」)*
:::

而如果你看到一个小孩子也许正试着用纸折出什么东西，她可能会说，<code>I'm trying very hard, but it won't come out right</code>（我非常努力，但它就是弄不对）——而这正是 できる 在日语里的用法，不是吗？而 できる 有一些有趣的用法，展示了「某物是可能的」这个想法和「某物出来」这个想法在日语里是如何紧密相连的。但我们现在不谈那个——那稍微高级一点。

可能形只有一个危险区，而它和我们上周处理过的东西非常非常接近<sup>[[9]](./9-日语句子的主语与表达愿望-ほしい-たい-たがる.md)</sup>。所以如果你看过那一课，这一课对你来说应该非常容易。我们来看一个典型的句子：<code>ほんがよめる.</code>

![](../media/image950.webp)

那么，标准课本通常把它译成 <code>I can read the book</code>（我能读这本书）。**但那不是它的意思**，如果你跟了我们的上一课，你就能清楚地理解这一点。看 が 在哪里。が 标记的是什么？**它标记的是这本书！** 那这个句子的施事是谁呢？**是这本书。**

![](../media/image177.webp)

我们在说一些关于这本书的事。**所以书是主车厢，而 <code>よめる</code> 是引擎。** 我们在说 **这本书是可读的，读这本书是可能的。**

---

如果我们加上 <code>わたしは</code>，我们是在说这本书 <code>to me</code>（对我来说）是可读的。我们字面上说的是，<code>In relation to me, the book is readable</code>（就我而言，这本书是可读的）。**但这不表示、也不可能表示 <code>I can read the book</code>。** 如果我们想说 <code>I can read the book</code>，那这本书就必须用 を 标记，不是吗？而我必须用 が 标记。而其实这么做是可能的，**但那不是通常的做法。**

但也请记住，如果我们想如英语所愿那样强调自我，那我们就得改变助词。如果我们字面上想说 <code>**I** can read the book</code>——<code>**わたしが**ほんをよめる</code>。

---

很多人认为这是糟糕的日语。

::: info
我猜这不是日本人倾向于说话的方式。它也许可以被称为 <code>Englishised</code>（英语化的）日语，因为它把重点先放在自我上、当作主语，而这不是他们在日本倾向于思考的方式。
:::

搞清楚它是不是糟糕的日语不是我们该做的事。重点是，大多数时候你会看到 <code>**ほんがよめる**</code>，而 **<code>(わたしは)ほんがよめる</code> 不可能字面上表示 <code>I can read the book</code>。** **它的意思是 <code>The book is readable</code>（这本书是可读的）。**

::: info
可以说 わたしは 来把自己设为主题（“至于我，这本书是读得下去的”），但通常不会提出来
:::

所以那足够简单，而只要我们记住这一点，我们就不会把那些助词全都推进疯狂的悖理之中。

![](../media/image429.webp)

所以这其实和上周我们讨论过的关于 -たい 以及愿望形容词的那些问题非常相似。**如果我们只是把那个 が 在脑子里摆正，其余一切都会各就各位。** 而就像 たい形 一样，如果我们说 <code>(わたしは)ケーキがたべたい</code>，

![](../media/image665.webp)

**是那个蛋糕在引发想要** *（对我个人而言——主题）*，但如果我们只说 <code>(わたしは)(zeroが)たべたい</code>，我们确实表示 <code>(In relation to me) (I) want to eat</code>（就我而言，我想吃）/ *eat-wanting-am*，

![](../media/image785.webp)

**因为当那里没有某个特定的食物来做「被想要」这件事时，那就是我来做那个想要。**

::: info

我是那个因为饿了而就是想吃点东西的主语；在这里我也是主题

不过，要注意那里没有任何食物存在，所以它默认落到 <code>me</code>（我）。零が（以及零は）取决于情境/句子的上下文，Dolly 说……

![](../media/image31.webp)
:::

可能形也一样。所以我们说，<code>(わたしは)ほんがよめる</code> – <code>(to me) the book is read-able</code>（对我来说，这本书是可读的），

![](../media/image315.webp)

但如果我们只是想表达 <code>I can read</code>——不是“我能读这本书，或者我能读报纸，或者我能读小樱的秘密日记”，而只是 <code>I can read</code>（我能读）——那我们就说 <code>わたしがよめる</code>，或者干脆 <code>よめる</code>，它表示 <code>(zeroが)よめる</code>。

![](../media/image335.webp)

**而我们真的成了这个句子的主语。** 我相信有人会觉得这令人困惑，但如果你跟了上一课，这应该完全清楚。

而让我们记住，日语总是像乐高一样拼合在一起，

![](../media/image625.webp)

所以可能形补助动词，即使它只是那单个假名 る(ru)，也只是一个像大多数补助动词一样的规则一段动词，我们能用它做的事，和我们对其他补助动词做的一样。

::: info
我猜 Dolly 的意思是可能形的作用方式像一段动词，所以如果要给可能形加上任何东西，就像任何一段动词一样把 る 去掉，再附加到 え-词干上。Dolly 在其中一条[**评论**](https://www.youtube.com/watch?v=qcOhHmU0znI&lc=UgxYARujuNXKheHlgNJ4AaABAg)下的回复

五段动词的 <code>potential form</code>（可能形）是一段式的，因为 る 补助词是一段式的……五段在这里是个障眼法。我们一把任何一段式补助词附加到一个五段动词上，我们面对的就是一个一段式实体，之后我们所做的一切都遵循一段式模式……所以不存在五段动词变成一段动词的问题。实际发生的是一个五段动词附加了一个一段式补助词。
:::

**我们总能认出它，因为它是唯一附加到 え-词干上的那一个，而我们能用它做我们对任何其他一段动词所做的一切。**

![](../media/image169.webp)

所以：<code>あるける</code> – 能走；<code>あるけない</code> – 不能走；<code>あるけた</code> – 那时能走；<code>あるけなかった</code> – 那时不能走。**而这种规律性即使对不规则动词也一样。** 所以：できる – 可能；<code>できない</code> – 不可能；<code>できた</code> – 那时可能；<code>できなかった</code> – 那时不可能。

而它真的就这么简单。
