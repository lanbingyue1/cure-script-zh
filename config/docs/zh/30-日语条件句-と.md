# **30. 日语条件句：と**

[**第 30 课：日语条件句：とTO。教科书不会告诉你的东西。**](https://www.youtube.com/watch?v=IkolA524WC0&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=32&pp=iAQB)

こんにちは。

今天我们要开始讲日语的条件句（conditional）。条件句就是你说像 <code>If...</code> 或 <code>When...</code> 这类话的时候。日语里有好几种不同的条件句，这会给学习者带来一些困惑。我们用哪一种、什么时候用、为什么？

老样子，我们往往从教科书那里拿到一份清单，附带一堆复杂的说明；也老样子，如果我们能理解底层的逻辑，就大有帮助。那么，这一课我们从条件句 と 开始。其实，我们已经见过这个 と 了。

它就是那个 <code>exclusive and</code>（排他的“和”）助词。我这里说的不是布尔逻辑。我说的是这个事实：日语里有两个表示 <code>and</code> 的词，用来连接两个名词。

![](../media/image405.webp)

一个是 や，や 和英语的 <code>and</code> 一样。它的意思是某样东西 <code>and</code> 另一样东西，<code>and</code> 也许还有其他东西。如果我们说 <code>hat and coat</code>，我们很可能还穿着鞋、裙子、裤子和其他东西，但我们只说 <code>hat and coat</code>。

在日语里，如果我们说 <code>ペンや本</code>——<code>pen and book</code>——我们说的是，就像英语的 <code>and</code> 一样，<code>a pen and a book and maybe some other things and maybe not</code>。但如果我们说 <code>ペンと本</code>，那就是排他的。

我们是在说 <code>pen and book and nothing else</code>。这一点很重要，因为这与我们用作条件句的完全是同一个 と。教科书往往把这个 と 讲得好像它和表示 <code>and</code> 的 と 是不同的东西，但并不是——是同一个。

还有另一个 と，那是引用助词，我们在不止一课里已经讲得比较详细了。它和表示 <code>and</code> 的 と 是分开的。但条件句的 と 不是：它是同一个 と。一旦我们明白这一点，就更容易看清这个条件句到底是怎么回事。

现在，我们还需要知道另外一件事：这个 と 是个助词，但它不是逻辑助词。它也不是非逻辑助词。

![](../media/image878.webp)

我这话是什么意思？逻辑助词是用来标记名词的格的助词。你不需要知道那是什么意思——掌握那种理论知识并不重要。

用大白话说，它的意思是：它告诉我们这个名词在句子里相对于别的名词、相对于动词在做什么。が 助词告诉我们这个名词正在存在或正在做某事；を 助词告诉我们它正被施加某事；に 助词告诉我们它是一个目标。

![](../media/image256.webp)

所以逻辑助词的作用，是告诉我们谁对谁做了什么、在哪里、在何时。非逻辑助词 は 和 も 标记主题，而主题不是一种逻辑构造。它们告诉我们我们在谈论哪个名词，但它们不告诉我们它在句子里扮演什么角色。

关于逻辑助词，要点在于它们必须依附于名词。它们除了依附于名词之外什么也做不了。这很明显，因为那就是它们的功能——告诉我们一个名词在句子里扮演什么角色。

と 不是逻辑助词，因此，虽然它可以依附于名词，它也可以依附于一个逻辑小句，而正是这一点使它得以成为条件句。好。现在我们知道得够多了，可以往下走了。

如果我说 <code>冬になると寒くなる</code>——<code>When it becomes winter (or, if it becomes winter) it gets cold.</code> 那么，这为什么和 と 的 <code>exclusive and</code>（排他的“和”）功能有关？之所以有关，是因为我们说的是只存在一种可能性，从我们谈论的事只能得出一种结果。

冬天来了，天就会冷——没有别的可能。下雨了，地面就会湿——没有别的可能。它也可以用于夸张。我们之前讲过夸张，对吧？

夸张就是你说一样超出事实的话。人类语言一直这么干。所以，有人可能会说 <code>それを食べると病気になる</code>——<code>If you eat that, you will get sick.</code>

![](../media/image762.webp)

那么，这不像冬天来了天变冷，或者下雨了地面变湿那样。你吃了它也可能不生病，但这是个夸张。你想对某人说的是 <code>If you eat that, you will get sick</code>。

<code>If you keep playing those games, you'll fail the exam.</code> 再说一遍，那个人也可能一直玩那些游戏、考试还是通过了，但夸张的说法是 <code>Do A and B will happen</code>。<code>Keep playing those games and you'll fail the exam.</code>

<code>Eat that and you'll get sick.</code> 我们把某样东西当作一个必然的结果、一个排他的结果、一个不存在其他选项的结果提出来。

我们也可以用这个 と 来表示某事是必要的。我们可以说 <code>行かないとダメ</code>——<code>If I don't go, it will be bad.</code>

::: info
だめ 写成了片假名，通常这样做是为了风格，好在文本里更容易辨认词、避免混淆，或者为了强调它，也许是为了给它更多情感力量之类的。
:::

<code>勉強しないと行けない</code>——字面上是 <code>If I don't study, it can't go</code>，但它的意思是 <code>If I don't study, it won't be good</code>（<code>...it won't do</code>，就像英语里我们可能会说的）；而它实际的意思是 <code>I must study / I've got to study</code>。

而且你经常会听到它单独出现。比如 <code>逃げないと!</code> 它的字面意思就是 <code>We don't run and...</code> 也就是说 <code>If we don't run...</code> 这里的言外之意是，如果我们不跑，就会有坏事发生。

所以如果在动画里有人说 <code>逃げないと!</code>，他们其实只是在说 <code>Run! / We must run.</code> 而在这个意义上，と 因为如此绝对、如此排他，比 ば／れば 之类的类似用法更强，也更口语一点。

下次我们会讲 ば／れば 这个结构。
