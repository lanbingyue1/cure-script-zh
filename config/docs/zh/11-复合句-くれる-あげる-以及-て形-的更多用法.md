# **11. 复合句、くれる、あげる 以及 て形 的更多用法**

[**第 11 课：复合句、kureru、ageru、更多 て形 用法**](https://www.youtube.com/watch?v=3X2ZCWazrDw&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=13)

我们现在已经完成了十课，是时候换个节奏了。我们现在学到的东西已经足够让我们开始看一些真正的叙述了。一开始会稍微简化一点，但我们可以用它来把目前学到的东西整合起来。我们也会学到新的结构元素，因为即使在最简单的故事里，我们也会遇到一些需要学习的东西。但这也许是一种更有趣的做法。所以请在下方的评论里告诉我你的想法。好的。

现在让我们进入一个我相信我们大家都知道的故事。

`ある日アリスは川のそばにいた.`

现在，这是一个简单的句子。<code>[川]{かわ}</code> 这个词意思是 `river`，而 **`そば` 意思是 `beside`，它是一个名词。**

![](../media/image937.webp)

所以 `川のそば` 就是 `the beside of the river`（河的旁边）。就像我们把某物放在桌子的 `on`（上面）或桌子的 `under`（下面）上，**我们也总是用 に 来标记它**，所以 `beside of the river` 就是 Alice 所在的地方。

![](../media/image564.webp)

`ある` 意思是 `a certain`（某个），所以 `ある日` 就像 `one day` 或 `a certain day`，而让我们注意，这里发生的是我们以前见过的。**`ある` 是那个意思是 `exist` 或 `be` 的动词**，而我们在这里做的是我们在关于所谓形容词的视频课里见过的<sup>[[6]](./6-形容词.md)</sup>。**我们可以把任何引擎变成一个形容词。** 所以，**`ある` 是一个 `A does B` 引擎、一个 う-引擎**，所以如果我们说 `本がある`，我们是在说 `There is a book / a book exists`。

![](../media/image358.webp)

**而如果我们把那个 `ある` 引擎移到书的另一侧，我们把它变白，它就变成一个描述词、一个形容词性的东西。** 所以我们是在说 `ある本`——`an existing book / a certain book / a book that there is`。

![](../media/image350.webp)

而这是一样的：`ある日`——`a certain day`。

`ある日アリスは川のそばにいた`

![](../media/image608.webp)

现在，下一句会稍微更复杂一点，但别担心，有一个完全能运转的机器人帮你时，它总是容易的。（其实，我不太算完全能运转，但就向你展示日语而言，我是。）

`おねえちゃんはつまらない本をよんでいてあそんでくれなかった`

![](../media/image186.webp)

所以我们这里有一个相当复杂的句子，让我们把它拆开。`おねえちゃん` 意思是 `big sister`（姐姐）：`ねえ` 是 `sister`；`-ちゃん`，我相信你知道，是一个可爱、亲切的敬称；`お-` 也是一个敬称。所以，`おねえちゃん`——`big sister`。

`つまらない` 意思是 `dull` 或 `boring`。`本`，如我们所知，是 `book`。`よむ` 意思是 `read`；`よんでいる`——我们**把 `よむ` 放进 て形 并加上 `いる`**，它意思是 `is reading`；然后我们把 `いる` 本身放进 て形。

那我们为什么要做这一切？让我们看看。`おねえちゃんはつまらない本をよんでいて`——`Big sister is reading a boring book`（姐姐正在读一本无聊的书）——但接着那个 -て……**て形 有很多不同的用法。** **在这个情况里，它会补全一个小句。** `Big sister is reading a boring book`——那是一个完整的小句，对吧？

![](../media/image451.webp)

**而如果我们把那个最后的 う-引擎变成 て形，我们所说的是，会有别的东西跟在这个小句后面。** **我们在表明，我们正在造一个由不止一个小句组成的复合句。** 所以这就像说 <code>Big sister was reading a boring book **and...**</code>（姐姐正在读一本无聊的书，而且……）。而那个别的东西来了：`あそんでくれなかった`。

![](../media/image1113.webp)

`あそぶ` 意思是 `play`（玩），而那个也在 て形 里，对吧？`あそぶ` --> `あそんで`。如果你对如何构成这些 て形 有任何疑问，请回去看关于 て形 的视频课并温习一下<sup>[[5]](./5-动词分组与-て形.md)</sup>。

`あそんでくれなかった`

现在这是 て形 的另一个用法。**て形 极其重要，它做各种不同的事情。** 它在这里做什么？嗯，`あそぶ`，如我们所知，意思是 `play`。

`くれる` 意思是 `give`（给），**而它专门意思是 `give downwards`（向下给）**。而我们在日语里说 `give downwards` 的原因，是因为我们总是对人有礼貌。**所以我们总是把自己表示为低于别人，而把别人表示为高于自己。**

![](../media/image86.webp)

所以**如果我说 `くれる`（给），我总是意思是某人在把某物给到我或给到我身边的人。**

但 Alice 的姐姐给了——或者没给——Alice 什么呢？

![](../media/image391.webp)

嗯，不是那本书。事实上，不是任何实际的物体。**她在给出那个由 て形 连接到 `くれる` 的动作。** 她在把玩这个动作给 Alice——或者在这个情况里，没给。

那我们这么说是什么意思？**嗯，我们说 `くれる` 不只用于给出一个东西——一本书、一件礼物、一颗糖——我们也用它来给出一个动作、为我们的利益做某事。** **这在日语里非常非常常用，所以理解它很重要。** 如果某人为我们的利益做了某事，我们把那个动作变成 て形，并加上 `くれる`。**如果我们为别人的利益做了某事，我们把那个动作变成 て形，并加上 `あげる`，它意思是 `give upward`（向上给），换句话说，给到你、给到另一个人。**

`くれる` 和 `あげる`——向下给到我或我的群体／<code>**あげる**</code> **向上给到你或别人、或你的群体、或他们的群体。**

那么这个句子的第二部分是什么？它是 `あそんでくれなかった`——"她没玩／她没给 Alice 玩的陪伴／她没为 Alice 的利益玩"。

![](../media/image344.webp)

它和我们在英语里找到的任何东西都相当不同，但它也非常富于表现力，是我们其实在英语里也希望能有的东西。

那么现在让我们再次看整个句子。`おねえちゃんはつまらない本をよんでいてあそんでくれなかった`——`Big sister was reading a boring book and did not play \[with Alice\]`。

![](../media/image108.webp)

注意，**我们这里有两个完整的小句**：
*小句 1：* `おねえちゃんはつまらない本をよんだ`——那本身就是一个完整的小句，对吧？

*小句 2：* `おねえちゃんはあそんでくれなかった`——`Oneechan did not play for Alice's benefit`

**而我们把这两者用 て形 连接在一起。**

---

**我们在这里应该注意到的一点是，`おねえちゃんはつまらない本をよんで` 并没有告诉我们时态。** **我们不知道她是现在、将来还是过去正在读一本无聊的书。我们要读到句子的末尾才知道。**

![](../media/image1016.webp)

在英语里，我们会在复合句的两半上都放时态标记。我们会说 `Big sister WAS reading a boring book...`，所以我们已经知道它是过去时。**但在日语里，我们把那个时态标记 -た 或 -かった 放在末尾，而我们每句只需要一个时态标记。**

![](../media/image461.webp)

`よんでいて` 可以意思是 `is reading`，也可以意思是 `was reading`，**但因为 `あそんでくれなかった` 是过去时，而且它是同一个句子的一部分，我们已经把所有东西都放进了过去。**

嗯，我们今天在 Alice 的冒险里没走多远，对吧？但当我们习惯真实文本并学会基本的叙述结构时，我们可以推进得更快。
