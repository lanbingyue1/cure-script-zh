# **52. 真实母语语境中的深度日语句子分析**

[**真实母语语境中的深度日语句子分析 | 第 52 课**](https://www.youtube.com/watch?v=I38yhYh4Lfg&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=54&pp=iAQB)

こんにちは。

今天我们要弄脏双手，深入一些真实的日语，这些日语承蒙我们的日本合作频道 Akasic Tails 提供。我们要考察一些我们会在现实生活中遇到的真实日语结构，学习如何分析它们，而一旦我们把这一点在脑子里弄清楚，我们就能在当场飞快地理解它们。

上周我们看了一则日语 <code>怪談</code>（怪谈）——一个恐怖故事——而第一句里就有太多重要材料要分析，以至于我们没能读超过第一句。那么，这周我想我们可以再往前推进一点、也快一点地进入故事。所以，我现在要给你们播放我今天想分析的那部分，然后我们开始分析。当然，我们会从第二句开始，因为第一句我们已经相当彻底地分析过了。

那么，接下来的部分是 <code>飲み会が終了した後</code>，而这是一个时间陈述。它在设定我们现在要描述的那个动作的时间。

![](../media/image285.webp)

那么，严格来说，我们应该说 <code>後に</code> 而不只是 <code>後</code>，但同样，我们可以把它省略掉，因为我们是在相对不正式地说话。那么，设定好时间之后，我们接着说发生了什么：<code>彼女はアパートを出てしばらく歩いていた</code>。

![](../media/image749.webp)

所以，她离开公寓走了一会儿。

那么接着我们有 <code>ふと先輩の家に携帯電話を忘れてきたことに気づいた</code>。

![](../media/image448.webp)

<code>ふと</code>——突然——<code>先輩の家に</code>——在先辈的家里——<code>携帯電話</code>——手机——<code>を忘れてきたことに気づいた</code>——忘れてきた 是 忘れる（忘）连接到 <code>来る</code>。

<code>忘れてくる</code> 字面上是 <code>forgetting-coming</code>（忘着来）——或者说它真正的意思是 <code>leaving behind</code>（遗落）：<code>忘れてきた</code>，也就是把她的手机忘在先辈的公寓里、就这样走过来。<code>ことに気づいた</code>——她意识到那就是她做过的事。<code>こと</code> 造出一个名词，或者说把它之前的一切都捆成那个名词。

所以，把她的手机忘在先辈的公寓里，就是她现在意识到的那个 <code>こと</code>。

那么，为什么是 <code>ことに気づく</code> 而不是 <code>ことを気づく</code> 呢？

![](../media/image485.webp)

英语的日语词典和教科书会告诉你，<code>気づく</code> 是一个动词，意思和英语的 <code>realize</code>（意识到）一样。而在实践中它的意思大体相同，但在结构上它不一样。它由两个我们其实已经很熟悉的词合成的。

一个是 <code>気</code>，意思是 <code>spirit</code>（精神）或 <code>mind</code>（心）或 <code>feelings</code>（感情），另一个是 <code>付く</code>，意思是 <code>stick</code>（贴）或 <code>adhere</code>（附着）。所以它字面上的意思是 <code>spirit stick</code>（精神贴附），而我们所做的是把我们的精神贴到某物上，也就是说，我们的注意力、我们的心、我们的感情附着到了某个特定的东西上。

而在英语里，我们用另一种方式表达它，说我们 <code>realize</code>（意识到）——也就是 make real（使成真）——一个事实。在日语里，是我们的精神附着到一个事实上。

在日语里，一个非常常见的表达是 <code>気を付けてください</code>，它被译成 <code>take care</code>（当心），但它字面上的意思是 <code>stick your spirit</code>（把你的精神贴上去）。把它贴到什么上呢？嗯，把它贴到你的周围环境上，把它贴到你正在做的事情上。

换句话说，就是留心。那么，译成 <code>take care</code> 其实在文化上比 <code>pay attention</code>（注意）更好，因为 <code>pay attention</code> 听起来像一道命令，不是吗？

而那并不是说 <code>気を付けて</code> 的那种氛围。
::: info
Dolly 老师说的是 <code>気をつくて</code>，但我认为她想说的其实是 気を付けて，因为前者似乎根本讲不通，而我也没能找到任何关于它的东西，尤其是没有指向所谓 <code>take care</code> 之类含义的内容……我的理论是她口误了，但没人注意到。
:::
在实践中，从文化上它更接近 <code>take care</code> 的意思，所以这个翻译不错，但结构并不一样。

所以现在我们明白为什么我们说 <code>ことに気づく</code> 而不是 <code>ことを気づく</code> 了。如果我们把一张海报贴到墙上，那面墙、也就是它被贴到的那个东西，并不是直接宾语，对吧？直接宾语是海报；墙是那个动作的最终目标。

而最终目标，在日语里，总是用 に 标记。如我们所知，间接宾语、最终目标，是用 に 标记的。

那么，即使我们把人的施事从这个句子里拿掉，只说 <code>The poster sticks to the wall</code>（海报贴在墙上），我们仍然是在说 <code>to the wall</code>（到墙上），不是吗？我们并不是在说 <code>The poster sticks the wall</code>（海报贴墙），如果墙是直接宾语，我们才会那么说。

我们是在说 <code>The poster sticks to the wall</code>。墙是海报贴附的目标。所以同理，如果我们把我们的精神贴到某物上，或者我们的精神贴到某物上，那么它贴到的那个东西就是目标，而不是那个贴附动作的直接宾语。

那么，知道这一点很重要，因为它是另一个小小的例子，说明 <code>えいほんご</code>——也就是所谓的英语式日语语法，你在教科书和网站上到处都能找到的那种东西——

![](../media/image743.webp)

它只是用另一种方式搞乱我们对一门极其、极其有逻辑的语言的逻辑和结构的理解。

因为它们会告诉你的是 <code>気づく</code> 是一个意思是 **realize**（意识到）的动词，但它要接 に”。

那么，先把“没有任何动词能接 に 或任何其他逻辑助词（只有名词才能接逻辑助词）”这个事实放在一边，我们知道它们的意思。它们的意思是，这个词——意思是 <code>realize</code>——在英语里把被意识到的东西当作直接宾语，而它其实把被意识到的东西当作一个目标，因此用 に 标记它，并且“这是日语那些你必须逐个记住的奇怪怪癖之一，因为它是如此随机、如此不讲理”。它根本不是随机、不讲理的。

![](../media/image104.webp)

虽然 <code>気づく</code> 大体上等同于英语的 <code>realize</code>，它的结构并不一样。我们不是在 real-izing（使成真）、不是在把某物变得真实，我们是在把我们的精神贴到某物上，而那个某物是一个目标，因此它用 に 标记，正如目标总是用 に 标记一样。
::: info
显然，那个被 に 标记的某物是一个名词，像 こと。而不是像某些教科书说的那样，是动词 気づく <code>takes に</code>（接 に）。只是再提一下这一点，因为它可能有点令人困惑。
:::
日语并不搞随机的不合理。

如果你想要那个，你得去欧洲语言里找。

而如果我可以在这里插一句小小的脚注。这种说动词“接助词”的说法，是极其、极其误导人的。

![](../media/image753.webp)

说逻辑助词只能属于名词、永远不能属于动词，这并不只是吹毛求疵。我说过，当他们谈到动词接助词时，我知道他们在说什么，但他们所谈论的东西在每一个场合都错得可怕。它基于这样一个谬误：逻辑助词能相对于不同的动词执行不同的功能。

而它们永远、永远不能。会这么想的唯一原因，就像在这个情况里一样，是误解了那个动词实际在做的事，通常是因为他们假定它和它最接近的英语对应词运作得一模一样，而事实往往并非如此。

而正如我们在可能形补助动词和主观性形容词那里看到的，这个谬误覆盖了日语的一大片领域，并且对许多学生无法理解日语负有很大的责任。因为它看起来那么不合逻辑、那么随机，而事实上它完全合乎逻辑。这就是为什么我们叫它们 <code>logical particles</code>（逻辑助词）。

![](../media/image471.webp)

无论句子里涉及的是哪个形容词或动词，它们从不改变自己的功能。它们永远、永远做同一件事。而如果你对我在这里说的有任何困惑，请看这门课的第九课。我现在就为它放一张卡片上来。

<code>彼女はアパートで引き返し先輩の部屋に戻って呼び鈴を押す</code>

![](../media/image806.webp)

所以她回到了先辈的公寓。<code>引き返し</code>，那表示 <code>return</code>（返回），而正如我们之前见过的，动词的 い-词干——那个动词是 <code>引き返す</code>，意思是 <code>return</code>——尤其是在叙述中，我们可以用动词的 い-词干，就和我们用动词的 て形 把它变成复合句的第一个小句一样。

那么，她回到了先辈的公寓——<code>先輩の部屋に戻って呼び鈴を押す</code>。她回到先辈的房间，按了门铃。

<code>呼び鈴</code>：<code>呼ぶ</code> 是 <code>call</code>（呼叫），<code>[鈴]{りん}</code> 是 <code>[鈴]{すず}</code>（<code>a small bell</code>，小铃铛）的音读，所以 <code>呼び鈴</code> 是一个 <code>call-bell / a bell for calling</code>（呼叫铃 / 用来呼叫的铃）。

<code>押す</code>：她按铃。而正如我们之前见过的，在日语叙述里，允许在过去时的叙述中使用现在时的句子，来增添临场感。而这里的感觉是，我们到这里来到了一个点，几乎像楼梯上的一个平台，我们在那里歇一会儿，把这个点当作我们的现在。

她按了铃。

<code>ところが反応がない</code>

![](../media/image839.webp)

<code>ところが</code> 是一个我们常常会在叙述里遇到的表达。再说一次 <code>が</code>：这个 <code>が</code> 显然不是助词 が。它是另一个 <code>が</code>，一个转折连接词，本质上表示 <code>but</code>（但是）。

为什么我们要给它加上 <code>ところ</code> 呢？嗯，正如我们在之前某一课里讨论过的，<code>ところ</code> 意思是 <code>place</code>（地方），它也可以表示时间上的一个点。它几乎像是时间里的一个歇脚处。

它可以说是给了我们一个临时的 <code>now</code>（现在）。所以当我们说 <code>ところが</code> 时，我们说的是 <code>at that point / at that time, but</code>（在那个点上 / 在那个时候，但是）。

所以我们把它当作一个叙述连接词，来标记“某件与我们预期或愿望相反的事正在发生”这个事实。

那么，<code>ところが反応がない</code>。所以尽管她按了铃，却出乎意料、或者说与我们期望、愿望相反，没有任何回应。

而当她转动门把手时……<code>回す</code> 如我们所知，<code>回る</code> 是 <code>go around</code>（旋转），<code>回す</code> 是 <code>回る</code> 的他移动词版本，所以它是 <code>cause to go around</code>（使旋转）。

当她使门把手转动、当她转动门把手时，<code>鍵は掛かっていなかった</code>。那把锁存在于一种没被锁上、没被扣上或挂上或固定的状态中。这是一个看起来有点令人困惑的表达，因为它来自一个事实：日本人常常把“钥匙”这个概念和“锁”这个概念混成一个。严格来说，这可以被称为不正确。

![](../media/image454.webp)

我们真正说的是 <code>錠前が掛かった</code>——锁被扣上或挂上了，但在日语里说“钥匙被扣上或挂上”（<code>鍵が掛かった</code>）很常见，而正确地说它甚至会显得有点不自然。

---

而因为门没有锁，<code>彼女はそのまま中に入っていた</code>——她走了进去。

![](../media/image121.webp)

<code>そのまま</code> 我们在另一个视频里讨论过<sup>[[42]](./42-基础词汇混淆-まま.md)</sup>，而如我们所知，<code>まま</code> 是一种未被改变的状况。<code>そのまま</code> 意思是 <code>in that unchanged condition / just as it is</code>（处于那种未被改变的状况中 / 就照它原来的样子）。而我们可以在这里看到这个概念是如何被稍稍延伸的，我们会经常发现这种延伸。

所以，比如，如果我们谈的是毛豆，而我们说 <code>そのまま食べる</code>，我们的意思是“就照它原来的样子吃，不改变它们的状况来吃，不再对它们做任何进一步的处理就直接吃<code> and this is what </code>そのまま”在这里的意思。

因为门没有锁，她就那样走了进去，就带着她当时的状态。她没有再按铃，她没有等着被邀请，而是 <code>そのまま</code>——处于那一刻未被改变的状况中——她走了进去……
