# 简介

首先，这个项目能存在，全靠 Mordraug 和 Nunko 花了大量时间把 Cure Dolly 的全部视频转录下来，并分享在[这个 Google Docs](https://docs.google.com/document/d/1XpuXerkGU8waJ4DPDNJA4bGeqOvM-csXjTe57iHARHc/) 里。万分感谢他们！

至于我这边，[我（Kellen）](https://bento.me/kln)把脚本转成了 Markdown，稍微调整了格式，并用 Vitepress 发布——比起 Google Docs 或 PDF，我觉得这样更方便。

离线 EPUB 阅读支持和生成功能由 [coffeepebble](https://github.com/coffeepebble) 构建。

::: tip 离线阅读
你可以把整门课程作为 EPUB 电子书下载到阅读器和手机上：[**下载 EPUB**](https://github.com/lanbingyue1/cure-script/releases/latest/download/cure-dolly-zh.epub)。
:::

## 改动了什么

1. 出于个人偏好，把 <u>下划线文字</u>改成了 **加粗**。
2. «引号» 里的文字都变成了着色的 `highlighted`。
3. 把注释形式从 *斜体文字* 改成了专用容器。

4. 我加了一个非常粗糙、不精确的课程分组。这纯粹是为了让列表能折叠起来。
5. 把逐行文本合并成便于阅读的段落。
6. 给所有课程之间加了互链。
7. 增加了可读的俄语和中文翻译。
8. 增加了英语、俄语和中文版本的离线 EPUB 下载。

在所有这些改动过程中，可能还有别的地方坏了，但应该没有严重的问题。
