# **31. ば / れば 条件形**

[**第 31 课：ば 条件形。它真正的意思，以及如何轻松使用它。**](https://www.youtube.com/watch?v=O81EPCsPUpw&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=33&pp=iAQB)

こんにちは。

今天我们要谈条件形 ば/れば。上周我们看了 と 条件形，我们看到它特有的特点是它的排他性，即它暗示只有一种结果可能。在很多情况下，我们可以使用任何或大多数条件形而不会在很大程度上改变意思，但每个条件形都有它自己特有的性质。

所以今天我们要看 ば/れば 的特殊性质，以及它做的一些事情和它为什么做这些事。首先，ば/れば 是什么？ば/れば 是一个补助词，我们把它加到动词的 え-词干上。

![](../media/image409.webp)

え-词干是较少使用的词干之一，但 ば/れば 就是使用它的东西之一。所以，对于五段动词，我们把它加到 え-词干上；而对于一段动词，一如往常，我们只是把它加到……我们只是去掉 -る 并加上一段动词形式 -れば。

对于那两个不规则动词，在这个情况里它们完全像规则的一段动词一样运作。所以 <code>来る</code> 变成 <code>来れば</code>，<code>する</code> 变成 <code>すれば</code>。其实，<code>来る</code> 和 <code>する</code>，我要说，事实上是一段动词，但它们是强一段动词。

强动词是一个能改变其元音发音的动词。在英语里我们有 <code>come</code> 和 <code>came</code>、<code>eat</code> 和 <code>ate</code>。而 <code>来る</code> 和 <code>する</code> 在某些情况里会改变它们的元音发音。<code>来る</code> 在否定形里变成 <code>こない</code>，<code>する</code> 变成 <code>しない</code>。

但在这个情况里它们完全不改变它们的元音发音，所以那非常简单——它们就完全像它们根本上所属的一段动词那样运作。对于形容词，我们去掉 -い 并使用补助词 -ければ。

![](../media/image739.webp)

你也许会注意到，当我们对形容词做任何事，除了单纯去掉 -い 并加上我们打算加的东西之外，那些特定的形容词性变化全都来自 か-き-く-け-こ 段。所以，形容词的否定形是 -くない（<code>面白い</code> --> <code>面白くない</code>）；过去形是 -かった（<code>面白い</code> --> <code>面白かった</code>）；而**ば 条件形是 -ければ**（<code>面白い</code> --> <code>面白ければ</code>）。

所以某种意义上我们可以说，如果形容词有一个 え-词干，那它会是 -け。而那正是我们在那种情况里所用的。那么 ば/れば 的特殊特点是什么？

-と，如我们所知，它的特殊特点是它的排他性。ば/れば 的特殊特点是它被用于假设。所以它必须永远意思是 <code>if</code>（如果）。**它永远不能意思是 <code>when</code>（当……时）**，因为我们永远不能确定条件是否会发生，因而如果我们用它来谈过去发生的事，那它必须是没发生的事，因为如果它确实发生了，我们就不是在处理一个假设，而是在处理一个事实。

现在，ば/れば 这种假设的性质使它能够被用在许多常见的、非常重要的日语表达里。举个例子，<code>どうすればいい</code>。它字面上意思是 <code>how, if I act, will be good</code>（怎么做，如果我行动，会好）。

而我要在这里顺便指出，虽然 <code>する</code> 一般被翻译成 <code>do</code>，但在很多情况里，把它表达成英语最好的方式是 <code>act</code>（行动）。所以，举个例子，如果我们说 <code>静かにする</code>，我们不是在说 <code>do quietly</code>，我们是在说 <code>act quietly</code>（安静地行动）。

所以，<code>どうすればいい</code>——<code>how, if I act, will be good</code>。而在英语里我们通常会说是 <code>What should I do?</code>。但在日语里我们不是那么说的。

如我们将看到的，这部分是因为 <code>should</code> 这个概念在日语里不太一样，而 ば/れば 常被用来解决这个问题。我们一会儿就会回到这一点。

ば/れば 的另一个常见用法是在 <code>すればよかった</code> 里。举个例子，<code>かさを持ってくればよかった</code>。在英语里我们会说 <code>I should have brought an umbrella</code>（我本该带一把伞）。

我们在这里其实说的是 <code>If I had brought an umbrella, it would have been good</code>。<code>持ってくる</code>，正如我在别处解释过的，我们把 <code>carry</code> 这个词和 <code>come</code> 这个词结合起来，意思是 <code>bring</code>（<code>carry-to-here</code>，带到这儿来），而我们注意到 <code>よかった</code> 把它扔进了过去时。

如你所知，在日语里，我们在逻辑小句的末尾标记过去时。所以，即便下面这一点也许是真的：如果现在正在下雨，那么假如我带了伞它会好，而且它现在仍然会好，我们仍然用那个最后的 <code>よかった</code> 把整件事扔进过去时。

<code>かさを持ってくればよかった</code>——<code>I should have brought an umbrella / I wish I had brought an umbrella.</code> 现在注意，在这两种情况里，<code>どうすればいい</code> / <code>かさを持ってくればよかった</code>，我们都在用这个 <code>if it were done, it would be good</code> 来表示 <code>should</code>。

而这在一个甚至更常见的日语结构里再次发生。<code>勉強しなければいけない</code>——<code>If I don't study, it won't go / it won't do.</code> 现在，我们在这里其实说的是 <code>I must study</code>（我必须学习）。

![](../media/image1010.webp)

日语里其实并没有一个表示 <code>must</code> 的词，所以我们总是用这种方式来构造它。我们说 <code>If I don't... (whatever it is)</code>，然后我们可以说 <code>it won't be good / it will be bad / it'll be a disaster...</code>

无论我们说什么，某个否定结构接着跟在后面，而我们所说的是 <code>I must go / I've got to go / I've got to do this / I've got to do that</code>，而这是因为我们没有 <code>got to</code> 那个结构，我们在日语里也没有 <code>must</code>。它总是有这种相当冗长的「如果我不做，它会不好／如果我不做，它不行／如果我不做，它糟了」——<code>[無]{な}ければダメ</code>。

而因为它确实是一种非常啰嗦的表达某个像 <code>must</code> 或 <code>got to</code> 这样常见意思的方式，它在随意口语里常常被削减到只剩下 <code>しなければ</code> 甚至 <code>しなきゃ</code>，后者是 <code>しなければ</code> 的缩略，而不加上那个否定结尾，因为那只是被隐含的。然而，即便在非常随意的口语里，它也常常被完整地说出来，而我认为这是为了强调那个 <code>must</code> 的性质。

<code>なぜ行かなければいけない?</code>——<code>Why have I got to come/go?</code>
