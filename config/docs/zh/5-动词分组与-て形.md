# **5. 动词分组与 て形**

[**第 5 课：日语动词分组与 て形。把动词第 1、2、3 组变简单。Organic Japanese**](https://www.youtube.com/watch?v=GzEVLMDC8nw&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=5)

こんにちは。

今天我们要讲日语动词分组。日语动词分成三组，而这些分组除了在我们准备对动词的形式做某种改变时之外，都无关紧要。但因为我们要相当频繁地做那种改变，理解这三组就很重要。

## 一段动词

日语动词的第一组叫作一段动词，或者 <code>one-level</code>（一档）动词。有些人把它们叫作 <code>る-verbs</code>（る 动词），这是个非常蠢的名字。如果你非要这么叫，我们大概该叫它们 <code>いる/える verbs</code>（いる/える 动词）。它们是最简单、最基本的一类动词。

![](../media/image537.webp)

当我们想做任何改变时，我们总是用同样的方式做。**我们所做的就是去掉末尾的 -る，然后接上我们想接的任何东西。** 一段动词只能以 -いる 或 -える 结尾，也就是说，以 い 行的一个假名、或 え 行的一个假名加 -る 结尾。

![](../media/image910.webp)

## 五段动词

第二组动词是到目前为止最大的一组，而且 **一个动词所能拥有的任何结尾，这一组的动词都能拥有。**

![](../media/image300.webp)

动词总是以 う 音结尾，但不是所有 う 段假名都能作动词的结尾，不过它们中有很多可以，而且它们全都能构成五段动词。它们叫五段动词，或者 <code>five-level</code>（五档）动词，原因我们很快会看到，而正如我所说，**它们能以任何 う 音结尾，包括 -いる 或 -える。** 与一段动词不同，**它们也能以 -おる、-ある 或 -うる 结尾。**

所以唯一存在歧义的时候，就是我们遇到一个以 -いる 或 -える 结尾的动词时。这些动词大多数是一段动词，但也有一批数量可观的以 いる/える 结尾的五段动词。区分它们并不像你可能想的那么难，我为此做了一个 [**视频**](https://www.youtube.com/watch?v=VDmaSJ4s6Qo)，虽然它比这一课稍微进阶一点。

## 不规则动词

第三组动词是不规则动词，而这里的好消息是它们只有两个。

![](../media/image565.webp)

你知道你西班牙语或法语课本里那一页又一页的不规则动词吧？嗯，日语只有两个。还有另外几个动词只在一个很小的方面不规则，但极少。**不规则动词是 くる（come）和 する（do）。**

## -て 形

那么既然我们知道了这三组，我们就要来看看如何把它们变成 -て 形和 -た 形。正如我上周<sup>[[4]](./4-日语的动词时态.md)</sup>解释的，我们需要这两个形式来构成日语的现在时和过去时。它们还有许多其他用途，我们会随着这门课一路学下去。

而正如我上周演示的，一段动词总是非常简单。**你所做的永远只是去掉 -る，然后接上你打算接的任何东西，在这个例子里就是 て 或 た。**

至于五段动词，如你所料，它们分成五组（[五段]{ごだん}，五档动词），而我不久前为此做了个视频。所以我要做的是现在就放那个视频，因为它把事情讲得相当清楚。

好，放视频。

五段动词有五种可能的结尾——这就是它们叫五段动词、也就是五档动词的原因。

![](../media/image897.webp)

而虽然那看起来有点难，其实并不。我们反正可以把其中两档合并，因为它们如此接近，我们只需要学一次。而我要把主要的组逐一过一遍。

### 第一五段组

第一组是我称作 UTSURU/うつる 的动词。那些就是以 -う、-つ 和 -る 结尾的动词。うつる 这个词在日语里——如果你不认识它，现在正是学它的好时机——うつる 意思是从一样东西移到另一样东西上，而这正是我们在这里做的事——把我们的动词从一种类型移到另一种。

所以以 -う、-つ 和 -る 结尾的动词都以同样的方式变成 て形。**我们去掉 -う、-つ 或 -る，把它替换成一个小 -っ 加 て（在 た形 里则是 た）。**

所以 わらう——laugh，变成 わらって（Waratte）；  
もつ——hold，变成 もって（Motte）；  
とる——take，变成 とって（Totte）。

那么，你会注意到 うつる 中间有个 つ。

![](../media/image994.webp)

而 うつる 动词的 て形是使用一个小 っ 加上那个 て 构成的。**它是唯一名字里含 つ 的组，也是唯一 て形结尾里含 つ 的组。**  

所以它真的很容易记住。

::: tip
你可以通过在 T 段假名前输入 t 来打出小 っ，比如 った（tta），或者用 X 键 + tsu。这也适用于 <code>あ, い, う, え, お</code> 假名——ぁ（X + a）、ぃ（X + i）……另外注意 づ（输入 - Du）和 ぢ（Di）——不规则的 ず 和 じ 假名形式。以防你哪天需要打它们，这种事是会发生的。而 ん 是 <code>nn</code>。
:::

### 第二五段组

第二组是我称作“新热潮”的组。在日语里，当某样东西真的兴起、变得流行时，我们叫它 ブーム（BUUMU）。那是个英语词，对吧？Buumu，一股新 Buumu！

所以，我把这一组叫作新热潮组，因为据我所知，没有哪个日语词能用 ぬ、ぶ 和 む 拼出来，而我想让你注意这组动词的一点是：**它们全都以我所谓的钝音结尾——ぬ、ぶ、む。**

![](../media/image35.webp)

它不是像 す、つ、く 那样的尖锐音，也不是像 る 或 う 那样的中性音。它是钝音——ぬ、ぶ、む（Nu、Bu、Mu）。这很重要，因为结尾也是个钝音。**て形结尾是 -んで，た形是 -んだ。**

所以 しぬ，**唯一以 -ぬ 结尾的动词**，变成 しんで / しんだ；  
のむ——drink，变成 のんで / のんだ；あそぶ——play，变成 あそんで / あそんだ。

这就是新热潮组，钝音结尾的动词。而因为只有有限数量的可能假名能用作动词结尾，它们包含了所有钝音，**除了 ぐ（Gu）。** 我们马上就要讲到它。

### 第三和第四五段组

我告诉过你，其中两组可以合并——那就是 く 和 ぐ 组。**要构成以 -く 结尾动词的 て形，我们切掉 -く，加上 -いて，在 た形 里则是 -いた。**

所以 あるく——walk，变成 あるいて / あるいた。

那么，如果我们在那个 -く 上加两个点〃（浊点），把它变成 -ぐ，就完全一样，只是 て 结尾上也有浊点。

![](../media/image459.webp)

所以 あるく 变成 あるいて，但 およぐ——游泳，变成 およいで。

但如你所见，这两者大体上是一样的。只是如果原动词上有浊点，て形 上也有浊点。あるく，あるいて；およぐ，およいで。

### 第五五段组

现在我们就只剩一个了，那就是 す。**而以 -す 结尾的动词去掉 -す，加上 -して。** 你会注意到，如果你跟过我们的上一课 *(不太确定是哪一课，但会被讲到)，* 我们只是在做那件常规的事：把 す 假名移到它的 い 行对应假名 し。

![](../media/image491.webp)

所以 はなす——talk，变成 はなして；那个把动词变成正式 *（礼貌）* 动词的 ます 补助动词，在过去时里变成 ました。

::: info
每当 Dolly 对 です 或 ます 使用 <code>formal</code> 这个说法时，它其实应该是 POLITE（礼貌），日语里这两个说法有区别，不确定她为什么没提这一点，但区分它们相当重要，如果你去查它们的定义，词典会把它们标为礼貌。**它们属于 丁寧語（礼貌语）。所以把它们叫作礼貌更准确。**
:::

那么现在我们把所有五段动词都讲完了。在那个老视频里我看起来是不是很年轻？

### 例外

现在，我们来看例外。**总共只有三个：我们那两个不规则动词，以及另外一个小家伙。**

而这些非常简单。くる（come）变成 きて；する（do）变成 して。

而 いく——动词 いく（to go）——因为它以 -く 结尾，你会预期它变成 いいて，但它没有，它变成 **いって**。

![](../media/image1057.webp)

而这些就是仅有的例外。所以如果你把这个视频／*这一课* 过几遍，我想你会发现，要确切知道在所有情况下如何构成 -て 形和 -た 形是相当容易的。
