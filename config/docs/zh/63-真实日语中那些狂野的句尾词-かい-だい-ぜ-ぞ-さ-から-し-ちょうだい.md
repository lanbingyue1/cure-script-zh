# **63. 真实日语中那些狂野的句尾词 かい、だい,、ぜ、ぞ、さ、から、し、ちょうだい**

こんにちは。

今天我们要谈更多那些东西——只要我们一离开理论日语那座有围墙的花园、冒险进入真货的野树林，它们就立刻迎面撞上我们。人们常问我的一个话题，是他们遇到的各种句尾词。而我说的不是那些温驯的，像 <code>ね</code>、<code>よ</code> 和 <code>な</code>——如果你有兴趣，我为此做过 [**一个视频**](https://www.youtube.com/watch?v=IWEok4Ivfyc)，我会在我头顶上方放一个链接。

但今天我们要谈一些更口语化、更不传统的句尾词，一旦你进入 <code>wild Japanese</code>（狂野日语），
在动漫、漫画等等里面，你就会遇到它们。

## かい

那么，我常被问到的一个是 <code>かい</code>，
而 <code>かい</code> 只是 <code>か</code> 的一种软化的、口语化的形式。如我们所知，<code>か</code> 在正式日语里被常规地用来构成疑问句——在正式日语里，我们在句子末尾使用 です/ます 装饰。所以我们说 <code>何々しますか / 何々ですか</code>。

但在口语日语里，我们并不那么经常用 <code>か</code> 作为句尾的疑问标记。**我们在其他位置确实会用它**——我做过一个视频讲我们使用 <code>か</code> 的各种方式<sup>[[39]](./39-か-助词-buried-questions-かな-もんか-かどうか.md)</sup>，我也会在我头顶上方放上那个链接。但在非正式说话里我们总体上不倾向于用它，就是不像在 です/ます 日语里那样、在句子末尾标记疑问。

而那并不是因为它不合语法——事实上它完全合语法——而是在现代日语里它已经变得听起来有点粗鲁，所以虽然你也许会在称兄道弟、<code>one of the boys</code>（哥们儿之一）的男人之间听到它，你在女性说话里、或在任何想稍微客气一点的人的说话里，就不那么常听到它。那我们怎么办呢？大多数时候，我们在说话里干脆用一个上升语调，或者在书写里、在我们描绘随意说话时用一个问号。而这没什么问题。

西班牙语就不断地通过仅仅给相应的陈述句加上一个上升语调来构成疑问句，那里没有任何问题。日语里也没有任何问题。有时我们会加上 <code>の</code>，它有歧义，因为它既可以标记一个疑问，也可以标记一个陈述，但同样，那其实无所谓，因为语调一样管用。

![](../media/image1087.webp)

不过，我们确实有一个非正式、听起来不粗鲁的疑问标记 <code>かい</code>。你也许会以为它会被一直使用，**但并不是**，
因为它听起来的确非常口语化，有时还有一点点……嗯，乡土气。有些来源说它主要是男性用语，而那算是半对。你不会听到很多较年轻的女性说话者用它，但你确实有时会听到较年长的女性说话者用它。

## だい （& どうだい）

<code>かい</code> 还有一个搭档，那就是 <code>だい</code>。

**<code>だい</code> 其实就是 <code>だ</code> 加上 <code>かい</code>。**

所以这是 <code>かい</code> 在
以系词结尾的句子、也就是以 <code>だ</code> 结尾的句子里所用的形式。

![](../media/image318.webp)

而我关于 <code>かい</code> 说过的一切，几乎同样适用于 <code>だい</code>，
**除了** 有一个特别的搭配 <code>どうだい</code>，它被使用得广泛得多。所以，如果某人正在吃什么东西，而你说 <code>どうだい?</code> —— <code>what's it like? / how is it?</code>（它怎么样？/ 味道如何？）——他们可能会说 <code>[美味]{おい}しい!</code> 或者可能会说 <code>[不味]{まず}い</code>，但 **用那种形式来问，是任何人都能做的事，只要是在一个非正式的场合。**

## ちょうだい

人们也会遇到 <code>ちょうだい</code> 这个表达，**而它和 <code>かい</code> 或 <code>だい</code> 毫无关系；**
**它是 <code>ください</code> 的一个非正式对应说法。** 所以它通常是加到动词的 て形 后面，来请人做某事。它有时被认为属于女性用语 **但它并不专属于女性。**

![](../media/image422.webp)

## ぜ、ぞ、さ

随意说话里其他真正的句尾标记是 <code>ぜ</code>、<code>ぞ</code> 和 <code>さ</code>。那么，<code>ぜ</code> 和 <code>ぞ</code> 非常简单。它们只是口头上的感叹号，给你正在说的无论什么东西添上一点力量。**它们相当粗鲁，的确属于男性用语**
**而它们属于那种你大概会看到**
**在动漫和漫画里比在现实生活中更多的**东西。

![](../media/image606.webp)

<code>さ</code> 类似，但它远没那么粗鲁。**它被使用得广泛得多**，你会看到很多它，你也会在现实生活中听到它。它往往被称为男性用语，但同样 **它并不专属于男性用语**。各种各样的人都在用它。

**重要的是不要把 <code>さ</code>——那个赋予强调的句尾词——**
**和 <code>さあ</code> 搞混，后者出现在一个句子的开头，更像是一种思考时的停顿那种表达。**

---

那么，还有一些句尾词 **并不是句尾词，但实际上是有效的句尾词**，因为人们确实会在句子的引擎之后把它们弹上去。

![](../media/image965.webp)  
这里，Dolly 还建议去看这个关于伪句尾词的 [**视频**](https://www.youtube.com/watch?v=Au5JOtcwE7A&ab_channel=OrganicJapanesewithCureDolly)，分别是 のに 和 なのに。

其中之一是 <code>から</code>。

## から <code>sentence-ender</code>

那么，<code>から</code>，如你所知，**在技术上并不是一个句尾词。**
**它是一个连接词，把两个逻辑小句连接起来，构成一个复合句。** 所以 <code>から</code> 的一个正规用法可能是：<code>さくらが来ないから帰ります</code>，它的意思是
<code>Because Sakura isn't coming, I'm going home / Sakura isn't coming, so I'm leaving</code>。（因为小樱不来，我要回家了 / 小樱不来，所以我走了。）

不过，你也可以在你正要离开时干脆说 <code>さくらが来ないから</code>，
而那只是把那句子的另一半留作未说，因为它很明显。那么，从那里出发，<code>から</code> 就可以被加到很多句子上，来暗示有别的什么要来。

**那个额外的别的什么并不总是完全清楚。** 事实上，<code>から</code> 可能是在执行软化它所标记的东西、或强化它这两种功能之一。

![](../media/image456.webp)

它可以通过让这个陈述感觉像是在解释来软化它；它可以通过让它听起来像是某个逻辑论证的一部分、或某个听者理应理解并同意的自然推论，来强化它。

所以，比如，如果你在一个不该骑自行车的地方骑自行车，而某个官方人员走上来对你说 <code>自転車に乗るのは禁止ですから</code> \[礼貌语气\]，那是安抚性的，他们其实想说的只是 <code>It's forbidden to ride a bicycle around here</code>（这一带禁止骑自行车），但通过在它末尾加上 <code>から</code>，他们有点在软化它、把它变成给你的一个解释。

![](../media/image1070.webp)

反过来，他们也可能会说 <code>自転車に乗るのは禁止ですから</code> \[严厉语气\]，而那有不同的言外之意。在那里，<code>禁止</code> 因为那个 <code>から</code> 而被更加用力地砸了进去。

![](../media/image978.webp)

所以，<code>から</code> 可以有各种各样的用法，常常取决于上下文、取决于它们被说出来的方式、取决于说它们那个人的举止，以及取决于整个情境。

## し 句尾词

<code>し</code> 是另一个非常常见的句尾助词，它和 <code>から</code> 相似，意义处于同一区域。<code>し</code> 其实可以组合各种条件或陈述，**但它最常见、最常规的用法是组合理由。**

所以，比如，我们可能会说，<code>遅くなったしさくらが来ないし帰ります</code>，而那意思是“因为天晚了，又因为小樱不来，我要回家了”。而 **这是 <code>し</code> 最标准的用法。**

---

但接着我们常常会为仅仅一个条件用它，暗示还有别的。比如，如果我们说 <code>遅くなったし帰ります</code>，我们是在说 <code>because it's gotten late, I'm going home</code>（因为天晚了，我要回家），**但我们也在暗示，天晚了这个事实并不是唯一的理由：** <code>Because it's gotten late (and for other reasons) I'm going home.</code>（因为天晚了（还有其他原因），我要回家。）

而这，在这个特定情况下，大概暗示的不只是天要晚了，**也是因为小樱不来，但我们把那更私人的部分留作了未说。**

那么反过来，我们可能会说 <code>さくらが来ないし帰ります</code>，而这一次我们把最重要的部分、我们离开的真正理由放了进去，但通过说 <code>し</code> 而不是 <code>から</code>，我们同时也在说 <code>Because Sakura isn't coming (and for other reasons) I'm leaving.</code>（因为小樱不来（还有其他原因），我要走了。）

**这样做的作用，是把压力从小樱身上卸下来。** 尽管她可能是主要原因，我们通过暗示还有别的理由，把它稍稍冲淡了一点。
**而我们可能会在根本没有任何别的理由时这么做，**
**仅仅作为一种软化和冲淡这个陈述的方式。**

另一个例子可能是，假设你又在那片你不该骑车的地方骑自行车，而这一次一个朋友走上来对你说，<code>自転車に乗るのは禁止し</code>。

![](../media/image575.webp)

::: info
是的，通常，在 禁止 之后、し 之前会有 だ。但因为这是随意的，它被省略了。
:::
那么，**这个陈述和那个 <code>から</code> 陈述之间的区别，**
**仅仅在于 <code>し</code> 在冲淡它。** 它是在说“哦，因为这里禁止骑自行车，还有其他原因……”

**那么，其实根本没有任何 <code>other reasons</code>（别的理由），但**
**这样做的作用是让它听起来更口语化一点、更友好一点**，
而它把那个 <code>から</code> 稍稍模糊化了一点——它可能听起来太像一道命令。它只是在说 <code>Oh, for that and other reasons</code>（哦，为了那个还有其他原因）。

而这种 <code>vaguing up</code>（模糊化）的策略在语言里经常发生。在英语里，它常常是通过给你正在说的东西加上像 <code>like</code> 或 <code>kinda</code> 这样的词来做的。

那么，这些句尾词起作用的方式，光从结构、或光从抽象的讲解是学不会的。**我们需要沉浸在日语里，去感受**
**人们说这些东西时到底是什么意思。**

但反过来，理解其结构、理解它们究竟是如何拼合在一起的，会给我们一个实实在在的助力，让我们能理解我们的沉浸。它相当像一根绳子和爬山。

![](../media/image718.webp)

::: info
