# **26. 比喻：ようだ・のように・のような ・みたい**

[**第 26 课：日语比喻的水晶般逻辑：のように・のような ・みたい 语法**](https://www.youtube.com/watch?v=Ft_zw0mdeyI&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=28&pp=iAQB)

こんにちは。

今天我们要讲 <code>ようだ</code>，并简单提一下她的表亲 <code>みたい</code>。我们会发现，<code>ようだ</code> 构成了一个滑动刻度的另一端，与我们在前两课讨论过的推测和相似表达相对。

![](../media/image709.webp)

一端是 <code>そうだ</code>，另一端是 <code>ようだ</code>，中间是 <code>らしい</code>。所有这些表达都可以放在一个完整的逻辑句末尾，以表示那句话要么是我们听到的，要么是我们根据手头的信息或根据我们所看到的推测出来的。但当我们把它们接到单个词上时，我们就有了这个含义的滑动刻度。

关于 <code>そうだ</code>，如我们所知，我们用它来推测某物的性质。我们可以说 <code>おいしそうだ</code>——<code>It looks delicious /I haven't tried it, but I think if I did, I would find it delicious.</code>（它看起来很好吃／我没尝过，但我想如果我尝了，会觉得好吃。）用 <code>らしい</code>，我们有着大得多的主观程度。<code>らしい</code> 在许多方面与 <code>そうだ</code> 重叠，但它也能做 <code>そうだ</code> 做不到的事。

它能把某物比作别的东西，比作我们知道它不是的东西。我们可以说一只动物 <code>ウサギらしい</code>——<code>rabbit-like</code>（像兔子）——即便我们知道它不是兔子。我们可以说一个人 <code>子どもらしい</code>——<code>child-like</code>（像孩子）——不管她事实上是不是孩子。我们并不一定是在推测那只动物是兔子、或那个人是孩子。我们只是在做那个比较。

## ようだ ・ように・ような

现在，<code>ようだ</code> 能走得更远。它能造出真正的隐喻或明喻。所以用 <code>ようだ</code>，我们可以说像 <code>a sumo wrestler is like a mountain</code>（相扑力士像一座山）或 <code>a person runs like the wind</code>（一个人跑起来像风）这样的话。嗯，如果你愿意，这些是文学风格或诗意的明喻、隐喻。

我们并不是说那位力士有任何像山的地方，除了他又大又结实这一点。我们并不是说一个人有任何像风的地方，除了她很快这一点。而我们判断 <code>ように</code> 是否在这样运作的方法之一，是我们可以和它一起用 <code>まるで</code> 这个词。所以我们可以说 <code>まるで風のように走った</code>——<code>ran just like the wind</code>（跑得就像风一样）。

字面上，<code>まるで</code> 意思是 <code>roundly</code>（圆圆地）。

![](../media/image137.webp)

<code>[丸]{まる}</code> 意思是一个 <code>circle</code>（圆）或一个 <code>round</code>（圆形），所以当我们说 <code>まるで</code> 时，我们意思是 <code>roundly/wholly/completely</code>（彻底地／完全地／完完全全地）。而这是一种夸张法，它常见于许多语言，当然包括英语。我们可能在英语里说 <code>That wrestler is exactly like a mountain.</code>（那个力士简直就像一座山。）

我们甚至可能说 <code>I literally froze to death.</code>（我真字面意义上冻死了。）嗯，这跟我们真正的意思相反：我们不是说我 <code>literally</code>（字面意义上）冻死了，我们是在说我们比喻意义上冻死了。在字面的现实中，我们看起来还活着。我们不是说那个力士 <code>exactly</code>（简直）像一座山。

他头顶上又没有雪！但我们说 <code>exactly</code> 和 <code>literally</code> 这类话的原因，是为了给一个诗意的明喻加强调。而在日语里，这里的通常搭配是 <code>まるで</code>。

而这也展示了 <code>ようだ/ような/ように</code> 与其他造相似表达之间的区别。你不能把 <code>まるで</code> 和 <code>そうだ</code> 或 <code>そうです</code> 一起用。你不该把 <code>まるで</code> 和 <code>らしい</code> 一起用。它和那些表达不搭。

我们在进行一种诗意的奇思遐想时才用 <code>まるで</code>。它是一个夸张的表达，标示着一个明喻或隐喻即将到来。当我们说一个人 <code>子どもらしい</code> 或一只动物 <code>ウサギらしい</code> 时，我们是在把现实稍微延伸一点；我们是在把它比作某样它可能是、但并不是的东西。

现在，如果我们看看这些表达的用法，就能看到，一如日语中的常态，它们非常有逻辑。

![](../media/image1115.webp)

教科书有时会给你列出连接方式和用法。但事实上它们都讲得通。我们不需要一份清单来告诉我们 <code>ようだ</code> 也能用作副词 <code>ように</code>，或它能作为形容词 <code>ような</code> 放在某物前面——因为这些连接正是你能和任何一个形容词性名词做出的同样的连接。

我们唯一要知道的是，就像 <code>らしい</code> 而不像 <code>そうだ</code> 一样，我们能把它和任何种类的名词一起用，而不只是形容词性名词。而那也讲得通，因为用 <code>らしい</code> 和 <code>ようだ</code> 两者，我们都能把某物比作别的东西，而用 <code>そうだ</code>，我们只能推测某物的性质，也就是某种能用一个形容词或形容词性名词表达的东西。而当我们把它接到一个动词上时，如我们所见，它有着稍微不同的意思。

不过，<code>ようだ</code> 有一个其他几个没有的特殊连接。

![](../media/image510.webp)

如你所知，我们可以干脆把它放到一整个句子上，就像我们能对其他两个做的那样，含义是 <code>(that sentence) is what appears to be the case</code>（（那句话）是看起来如此的情况）。但我们也能把它放到一个完整的句子上，含义不同。我们这么做是为了把整个句子变成我们的明喻。

所以，比如，我们可以说 <code>まるでゆうれいを見たかのような顔をした</code>——<code>She had a face (or made a face) exactly as if she had seen a ghost.</code>（她有一张脸（或做了个表情），简直就像她见了鬼一样。）

![](../media/image222.webp)

现在，如我们所见，<code>she had seen a ghost</code> 是一整个逻辑小句。在日语里，<code>she</code> 那里我们有零助词，但它是一个完整的逻辑小句：<code>she saw a ghost</code>——<code>ゆうれいを見た</code>——<code>zeroがゆうれいを見た</code>。现在，接着我们把 <code>か</code> 放到它的末尾。这个 <code>か</code> 是什么？

## The か particle

我们还没有大量地谈过这个 か 助词，因为在 です/ます 日语里，我们用它来标记一个疑问。你可以在非正式日语里用它来标记疑问，而这也正是我们在这里通常用的，但大多数时候我们并不用，因为说来矛盾，把一个 <code>か</code> 放在一个非正式疑问句末尾似乎不太礼貌——它往往显得有点生硬或唐突。

不过，这个疑问标记 <code>か</code> 有另一个重要功能。那就是它能把一个陈述打包成一种疑问，而这里正在发生的就是这个。我们一开始用 <code>まるで</code> 来标示我们即将使用一个明喻。

然后我们做出我们完整的陈述——<code>ゆうれいを見た</code>——<code>zeroがゆうれいを見た</code>——<code>she saw a ghost</code>（她见了鬼）。接着我们加上 <code>か</code>，而这就把它变成了一个疑问。它给了我们我们的 <code>if</code>（如果）——<code>as if she had seen a ghost</code>（就好像她见了鬼一样）。

而那个 <code>か</code> 给了我们那个带疑问意味的 <code>if</code>。事实上，她并没有见鬼，所以这并不真是一个陈述；它是一种可能性、一种潜在性、一个如果。她实际所做的，也许只是看到了 PayPal 向她收取国际汇款手续费的那张账单。

我们并不是在暗示她真的见了鬼。我们是在暗示她所呈现的那张脸——<code>顔をした</code>——类似于她若——<code>か</code>——见了鬼时本会呈现的那张脸。

现在，关于这个 <code>か</code> 我们要理解的另一点，是它实际上把它所标记的那个逻辑小句名词化了。

![](../media/image568.webp)

所以它所做的，就是把这个完整的逻辑小句变成一个疑问、一个假设、一个如果，而它随后在结构上充当一个名词。所以它能被 の 标记，而那只可能发生在一个名词上。于是这个新名词、这个我们从一整个逻辑小句造出的对象，现在就能由助词 の 连接到另一个名词。

<code>よう</code> 是一个 <code>form</code>（形态）或一种 <code>likeness</code>（相像）——<code>やまのよう</code> 是山的形态，<code>風のよう</code> 是风的形态或相像，而在这个情况下，<code>ゆうれいを見たかのよう</code> 是我们从见了鬼这个假设造出的那个对象的相像。现在，再一次，这不是我们能用其他任何几个做到的事。我们甚至不能用 <code>みたい</code> 做到，它在大多数方面运作得和 <code>のよう</code> 几乎一模一样。

## みたい

<code>みたい</code> 是 <code>よう</code> 不那么正式的表亲，大体上意思相同，大体上能用在同样的地方。

![](../media/image676.webp)

它就像那个 <code>よう</code> 一样是一个形容词性名词，能配上 <code>に</code> 变成副词，或配上 <code>な</code> 变成放在名词前的形容词，就像任何形容词性名词都能做的那样。关于它要记住的主要事情，就只是它不那么正式，所以你不会在一篇论文里用它。

另一方面，在很多时候你可能会在对朋友说话时优先选它而不是 <code>ようだ</code>，只因为它听起来不那么正式、更亲切一点。但你不能把它和一个完整的句子一起用。

你能把它和一个完整句子一起用，以推测那句话是事实，但你不能把它配上 <code>か</code>，来把一个完整的句子用作明喻。你得为此使用 <code>かのようだ/かのように</code>。另一点要注意的是，有时，大概因为它非常随意，<code>だ</code> 或 <code>です</code> 会从 <code>みたい</code> 那里被省掉。

你可能会说 <code>まるでヒツジみたい</code>——<code>just like a sheep</code>（就像一只羊）。

![](../media/image1.webp)

这并不符合正确语法——你应该说 <code>みたいだ</code>——但省掉它非常常见。把 <code>ようだ</code> 的那个省掉则不常见。
