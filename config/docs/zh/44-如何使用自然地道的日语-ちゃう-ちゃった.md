# **44. 如何使用自然地道的日语：ちゃう、ちゃった**

[**如何使用自然地道的日语：chau、chatta 到底怎么运作 ちゃう、ちゃった | 第 44 课**](https://www.youtube.com/watch?v=VyZWoJCSQ5Q&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=46&pp=iAQB)

こんにちは。

今天我们要讲一个你在动画、漫画、日常对话、轻小说，以及任何你会遇到真实的所谓随意——也就是非正式——日语的地方都会不断碰到的东西。嗯，我们要用一个小小的窍门，从英语的视角来理解它是怎么运作的。当然，标准解释不会给你这样的窍门，因为它们连日语结构底层原理的基础都不解释。于是我们就得到了三个盲人摸大象的效果。

我肯定你听过这个故事。第一个人摸到大象的一条腿，说大象像一棵树；第二个人摸到它的鼻子，说它像一条蛇；第三个人摸到它的尾巴，说它像一根绳子。当然这些都不完全错。大象确实会表现出所有这些特质，但如果你把它们当作孤立的事实呈现，却不解释整件事底下有一头大象、是它让一切讲得通，那你就是在把事情弄得比它需要的难得多。

而标准英语所谓的日语语法，从一开始讲语言结构时就这么做，这是灾难性的；然后它又对所谓的 <code>grammar points</code>（语法点）一而再、再而三地这么做。而它把它们叫作 <code>grammar points</code> 这个事实本身，就是问题的一部分，因为这些大多其实并不是什么点，它们是逻辑结构，而如果我们理解了结构，就不必把它们当作一个个独立的、没有意义的 <code>points</code> 来死记。

那么，我们今天要讨论的是接在动词末尾的 <code>-ちゃった</code> 或 <code>-じゃった</code> 这样的说法。现在，如果我们看传统解释，会读到它表示一个已经完成或结束的动作，或者一个我们后悔的、不小心做的动作，或者刚刚意外发生的事。他们通常不会在这里补充说，它也可以表示发生的某件非常好的事，或者它其实可以在将来时里用作 <code>-ちゃう</code> 或 <code>-じゃう</code>——这似乎会与我们刚刚学到的一切相矛盾，对吧？

那么，与其去看尾巴、腿和鼻子，我们不如先看看真正的大象。首先，<code>-ちゃう</code> 或 <code>-ちゃった</code> 其实是 <code>しまう</code> 这个词过去时的缩约，它的意思是完成或结束。

![](../media/image127.webp)

所以，如果你听过日本童话，你会发现它们常常以 <code>おしまい</code> 这个套语结尾。而 <code>しまい</code> 是 い 词干，它使 <code>しまう</code> 变成一个名词，所以它的意思是 <code>the finish / the ending / the end</code>（结尾／结局／结束）。

![](../media/image1064.webp)

现在，如果你把它变成过去时，就是 <code>しまった</code>，而 <code>しまった</code> 可以单独作为一个表达使用，它通常意思是 <code>Something's gone very wrong / This is not at all satisfactory</code>（事情出了大问题／这完全不令人满意）：<code>しまった!</code>。也许把它放进英语最好的方式是说类似 <code>That's done it</code> 或 <code>That's the end!</code> 或类似的话。

现在，我们可以把这个 <code>しまった</code> 当作补助动词，接到另一个动词的 て形上。我们这么做的方式是：把另一个词变成 て形，然后加上 <code>しまった</code>。而 <code>-てしまった</code> 缩约成 <code>-ちゃった</code>。

![](../media/image236.webp)

现在，如果 て形是 <code>で</code>（如我们所知，在某些词里它是；如果你不明白这一点，我在之前的一个视频里解释过<sup>[[5]](./5-动词分组与-て形.md)</sup><sup>[[40]](./40-3-日语里的-3-个陷阱-以及如何避开它们.md)</sup>），如果 て形是 <code>で</code>，那么它就不变成 <code>-ちゃった</code>，而是变成 <code>-じゃった</code>，就像 <code>では</code> 变成 <code>じゃ</code> 那样。现在，这比单独一个 <code>しまった</code> 有着宽得多的含义范围。

它可以用在我们不小心做、或但愿自己没做的事上。比如，我们常说 <code>忘れちゃった</code>，那是 <code>忘れる</code>——<code>forget</code>（忘记）——加上 <code>-ちゃった</code>。有一首名曲 <code>ネコ踏んじゃった</code>，非常好玩，我会在下面的信息区放一个[**链接**](https://www.youtube.com/watch?v=GpqGiKJt3cQ&ab_channel=ichigoclub15)。

它的意思是 <code>I trod on the cat</code>（我踩到了猫）：<code>踏む</code>——<code>tread (on something)</code>（踩、踏）。所以我们能看到它这里有一种负面意味，但它也可以是很棒的事。

我们可能会说 <code>スーパーヒーローになっちゃった</code>——<code>I became a superhero.</code>（我变成了超级英雄。）那么这些东西有什么共同点呢？意外的事、我们后悔的事、我们非常高兴的事。

我会这样表达它，我会这样把它翻译成英语，因为这是我认为能覆盖几乎所有 <code>-ちゃった</code> 情况的英语表达，那就是 <code>done</code> 这个词。<code>忘れちゃった</code>——<code>I done forgot</code>；<code>猫踏んじゃった</code>——<code>I done trod on the cat</code>；<code>スーパーヒーローになっちゃった</code>——<code>I done became a superhero.</code>

在所有这些情况下，意思都非常相似。我们是在说它发生了、它已经完成了、它是既成事实，而言外之意大体上是，我们本没料到它会成为事实，或者它不是大多数人通常本会料想成为事实的东西，但它就是。它 <code>done happened</code>（确确实实发生了）。而如果我们理解了这一点，那就很容易理解 <code>-ちゃった</code> 被使用的所有不同情形。

这与英语里 <code>done</code> 唯一真正的区别是，我们不只用它讲过去的事。我们也用它讲将来的事。所以我们可以说 <code>夏休みが終わってしまう</code>，意思是 <code>the summer vacation will done end</code>（暑假将会确确实实地结束）。现在，当然你不能在英语里这么说，但本质上那就是你在说的意思。

它就会那么待着、那么走、那么结束。事情就会那样发生，它就会结束，而我们对此无能为力。如果你正要告诉某人一件尴尬的事，你可能会说 <code>君のは笑っちゃうだろう</code>——<code>You'll probably laugh</code>，或者说 <code>You'll probably done laugh / You'll probably just up and laugh.</code>（你很可能会笑出来。）

再一次，意思是一样的，但在日语里我们也可以把这个意思投射到将来。我们可以说 <code>今日はどんどん飲んじゃう</code>，那是 <code>Today, I'm going to drink like crazy</code>（今天我要拼命喝）。

<code>どんどん</code> 是 <code>one after another in rapid succession</code>（一个接一个、接连不断）；<code>飲んじゃう</code> 是 <code>done drink</code>（痛痛快快地喝）。再一次，我们不能在英语里把它放在将来，但在日语里可以。

所以如果我们理解这些是怎么运作的，就不必为它们所有不同的情况准备一大堆复杂的解释。它们的运作方式一直是一样的，只要我们想的是它们的运作方式，而不是把它们翻译成英语后的最终结果。
