# **76. 正确的「打开」？｜あく、あける、ひらく、ひらける、開く、開け**

[**正确的「打开」？aku、akeru、hiraku、hirakeru｜あく、あける、ひらく、ひらける、開く、開け｜第 76 课**](https://www.youtube.com/watch?v=QEInorgR6Rs&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=78&pp=iAQB)

こんにちは。

今天我们要看一个本身很重要、但也能照亮日语里某些微妙之处的东西，而那些微妙之处在我们深入沉浸时非常有用。那么，我们要看的是说某件事的四种不同方式，而在英语里它们全都由 <code>open</code> 这一个词涵盖。

![](../media/image867.webp)

那么，这些是 <code>開く</code>、<code>開ける</code>、<code>開く</code>、<code>開ける</code>。　

::: info
它们分别读作 あく、あける、ひらく 和 ひらける，尽管它们有着相同的汉字和送假名。Dolly 在本课后面会说明这一点。
:::

那么，当我们一开始看这些时，它们看起来像两对自移动／他移动词，对吧？而在一定程度上它们确实是。

但这将要说明的是日语里整个自移动／他移动概念的一些微妙之处，与英语及其他西方语言里「他动性」和「自动性」之间那种更技术化、更泾渭分明的对比相对照。

所以，如果你对自移动词和他移动词这个概念（在西方常被称为及物动词和不及物动词）不熟悉，我会在我头顶上方以及下方评论区放上我讲那个主题的视频链接。

我们注意到的第二件事是，当你用汉字写它们时，你其实看不出 <code>あく/あける</code> 和 <code>ひらく/ひらける</code> 之间的区别。那么，这部分是因为它们实际上在许多情况下可以互换，而整体来说，如果不是那种真的需要用 <code>ひらく/ひらける</code> 的情况，  
人们一般会读成 <code>あく/あける</code>。

但如果一个作者想表明她是为了某种特定效果而使用 <code>ひらく</code>（我们稍后会看其中一些效果），她会用平假名来写它，以便把事情说清楚。

好。那么先让我们拿下最上面的两个，<code>あく・あける</code>。<code>あく</code> 是自移。<code>あくる</code> 是他移。它们都意思是 <code>open</code>。所以，<code>あく</code>：门开了、瓶子开了；<code>あける</code>：开门、开瓶。

至少理论上如此。

![](../media/image730.webp)

在实践中，我们会常常听到日本人说像 <code>目を開く</code>（睁开眼）这样的话，而这在语法学家眼里技术上是不正确的，因为 <code>開く</code> 是自移，而他们把它用在了一个他移的方式上：睁开眼。

那么，我在这里有点在挑战语法学家，我马上会告诉你为什么，但你应该坚持实际的语法模型，因为日本人确实把他动地使用 <code>開く</code> 的情况数量有限（我在这里用 <code>transitively</code> 这个词是故意的——你马上就会明白为什么），而你不会想去背哪些是那些情况。

如果你把 <code>あける</code> 用作他移版本——张嘴、开门、开任何东西——你永远不会出错。那永远正确。

那我为什么在挑战这个官方观点，即 <code>あける</code> 应当是自动词？嗯，我在这里略微觉得，日本语法学家有点受西方思维、以及西方「及物性和不及物性」概念的影响。

当日本人说 <code>目を開く</code> 时，我相信它背后的本能或感觉是，睁开眼是朝向 ある 那一侧的、我们在我讲他动词那一课里谈过的 ある・する 地图。

![](../media/image669.webp)

换句话说，睁开眼更接近自移、更接近那种「然后去做」，与开门、开瓶或开某个其他外部物体相对。

那么，这是我对这件事的看法，你想的话可以忽略它，但我们接下来会讲到更多这类微妙之处，而那些是没有任何人争议的。

## 開く（ひらく 和 あく）

那么现在让我们看看 <code>あく</code> 和 <code>ひらく</code> 之间的区别。

![](../media/image990.webp)

它们都意思是 <code>open</code>。<code>あく</code> 官方上来说是自移，尽管我们能看到这里有一点余地；<code>ひらく</code> 则相当正式地既是自移又是他移。

它们之间的区别和自移或他移毫无关系。它和我们所谈的那种「打开」有关。

所以如果我们谈开一个瓶子、把一个盒子的盖子拿掉、诸如此类，那绝对是 <code>あける</code>。另一方面，如果我们谈一朵花开放，那绝对是 <code>ひらく</code>。

所以某个展开、摊开的东西，是 <code>ひらく</code>。某个只是从关着变成开着的东西，是 <code>あく・あける</code>。

而如果你喜欢日本儿歌，你很可能听过那首手游戏歌，唱的是「むすんでひらいててをうってむすんで」。

![](../media/image919.webp)

<code>むすんで</code> 是 <code>結ぶ</code>，意思是 <code>gathered or joined</code>，指的是握起来的手。<code>開いて</code> 指一只像盛开的花那样摊开的手。

那么，有各种各样它们两者可以互换的领域，但即使它们可以互换，它们也是在强调一个方面而非另一个方面。

![](../media/image621.webp)

所以，比如，一扇对开门可以 <code>あく</code>（开）或 <code>ひらく</code>（张开）。眼睛一般是 <code>あく</code>，但也可以说 <code>ひらく</code>，而在这些情况下当我们用 <code>ひらく</code> 而不是 <code>あく</code> 时，它有点像电影里你把镜头拉近到某人的眼睛慢慢睁开、或者门慢慢敞开。

它更有那种实际打开、摊开过程的感觉。所以这给出了一种英语里没有的微妙之处，只要选择 <code>ひらく</code> 而不是 <code>あく</code>，就能把它注入到口语或写作里。

那么，当我们来到更隐喻或抽象的用法时，这个区分又变得重要了。比如，我们可以说 <code>店をあける</code> 或 <code>店をひらく</code>，它们都意思是 <code>open a shop</code>，但 <code>店をあける</code> 暗示的只是早上开门营业，或者午休后开门之类的，就是字面上把店打开，只是把门打开好让顾客能进来。

![](../media/image60.webp)

<code>店をひらく</code> 暗示第一次开一家店、向公众开放。换句话说，像花一样摊开，从一个关着的东西变成一个开着的东西。

而这里顺便说一句：对于雨伞，它也会摊开，你可能会倾向于说 <code>ひらく</code>，但我们通常不用那个，开伞一般用 <code>さす</code>。

![](../media/image1062.webp)

## 開ける（ひらける）

那么，<code>ひらける</code> 又是怎么回事呢？

日本语法学家，或者说至少其中许多人，实际上把 <code>ひらける</code> 指定为 <code>ひらく</code> 的自移版本。

![](../media/image73.webp)

但那其实根本讲不通，因为 <code>ひらく</code> 本身就是既自移又他移。那么这里实际上是怎么回事呢？这相当有意思。

<code>ひらく</code>——它可以要么自移要么他移——在地图上更靠 <code>する</code> 那一侧，比 <code>ひらける</code> 更甚。而我这么说是什么意思？

![](../media/image540.webp)

嗯，我不久前做了一个视频，讲我称为「不可翻译的日语」的东西。而那是关于一些真的无法在英语里再现的日语动词，因为它们表达的是状态而非动作，而其方式在英语里根本不出现。

一个非常简单常见的例子是 <code>分かる</code>，英语词典和教科书常常把它翻译成 <code>understand</code>。

![](../media/image622.webp)

它当然不意思是 <code>understand</code>，但当你得到一个更好的翻译时，那往往会趋向 <code>be understandable</code> 或 <code>be clear</code>，而那要接近 <code>分かる</code> 实际的意思得多，但真正的意思无法被翻译成英语，因为它实际上不是一个像 <code>clear</code> 或 <code>understandable</code> 那样的形容词。它是一个动词。

所以我们真正说的是 <code>do understandable / do the act of understandability</code>，而这根本没有英语翻译。而像这样的状态动词有很多，我在那个视频里讲过它们。

而 <code>ひらける</code> 真的更接近成为这类东西之一。<code>濡れる</code>，它常被翻译成 <code>become wet</code>，但它实际上不意思是 <code>become wet</code>——它可以包含那个，但暗示着 <code>existing in the state of being wet</code>。

它可能指 <code>become wet and then continue to be wet</code>，或者也可以只指 <code>be wet</code>，但当然它不是 <code>be wet</code>，它实际上是 <code>do wet</code>，而那无法翻译成英语。

<code>ひらける</code> 也一样。所以它被用在像这样的情况里，比如，我们常常说 <code>運が開ける</code>，它意思是 <code>one's luck opens</code>。

![](../media/image278.webp)

那么，我们可以说 <code>運が開く</code>，那会意思是 <code>one's luck unfolds like a flower, becomes open</code>，但 <code>ひらける</code> 暗示的不只是展开，而是继续存在于那个展开的状态里。

我们更倾向于说 <code>店をひらく</code> 的原因，一部分是因为它比 <code>ひらける</code> 更他移，而我们实际上是对店做这件事，是我们在开它；还因为重点在于开这家店这个行为。

<code>運がひらける</code>：对运气实际打开这个动作的强调，不如它将要改变这个事实重要。从那时起，我们会变得幸运，而此刻我们没那么幸运。

所以，我觉得这给了我们一个视角，不仅看到日语里表示「打开」的这四个词、以及它们如何运作、如何相互作用。很多时候它们彼此重叠，你用哪一个都不太要紧。

在某些情况下，它真的很重要，或者是为了你具体想说的东西，或者是为了你想通过说它来营造的细微差别、蕴含和氛围。
