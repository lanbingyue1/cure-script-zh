# **12. 引用助词 と、复合动词与复合名词** 

[**第 12 课：と 引用助词的秘密——外加复合动词、复合名词——以及更多的爱丽丝！**](https://www.youtube.com/watch?v=7dYT6Xf1BkA&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=14)

こんにちは。

今天我们要继续上周开始的故事课。而这次我们可以进行得快一点。那么，我们先复习一下到目前为止读过的故事。

>ある日アリスは川のそばにいた。

（有一天，爱丽丝在河边。）

>お姉ちゃんはつまらない本をよんでいてあそんでくれなかった。

（姐姐在读一本无聊的书，没有和爱丽丝玩。）

>「おもしろいことがない」とアリスは言った。

![](../media/image1099.webp)

「おもしろい」的意思是 `interesting or amusing`（有趣、好玩的）；「こと」的意思是 `a thing`（一样东西）。而在日语里，我们有两个常见的词表示 `thing`，它们是 もの 和 こと。

![](../media/image369.webp)

现在，**もの 是最通常意义上的东西：一个物理的东西——一顶帽子、一本书、一副眼镜、富士山。** **こと 是更抽象的一种 `thing`：一件事、一桩事、一种情况。** 所以，当我们说 `Is there anything in that box?` 时，我们指的是 もの。而当我们说 `The thing is...` 时，我们通常指的是 こと。 

所以，「おもしろいことがない」的意思是 `There's nothing interesting going on here, no interesting circumstance.`（这里没有什么有趣的事在发生，没有什么有趣的情况。）

言った——言う 的意思是 `say`，你可以看到它就像一个嘴巴，有声波从中传出来。 

![](../media/image539.webp)

**但这里要注意的重要一点，是那个小小的助词 と。**

![](../media/image431.webp)

**其实有两个 と 助词：** 一个意思是 `and`，非常简单；**另一个就是我们所说的 `quotation particle`（引用助词）**，而这里我们要处理的就是它。**当我们引用某人说了某事，甚至想了某事时，我们就用这个助词 と。它有点像一种你能听得见的引号。** 

如你所见，我们在日语里使用方引号，它们相当于英语的引号，**但我们也使用 と。** 所以我们不只是说 ` 'Nothing interesting is happening,' Alice said`。我们说 <code> 'Nothing interesting is happening,' **と** Alice said</code>。现在，と 在结构上是一个非常有趣的助词，几分钟后我们会更深入地看看它。

>そのとき、白いウサギがとおりすぎた。

![](../media/image580.webp)

「そのとき」：その 意思是 `that`，とき 意思是 `time`，所以我们字面上说的是 thattime，` but this is a bit more like saying ` 就是“就在那时／在那一刻／在那时”。**所以我们就像使用其他相对时间表达那样来用它：我们不需要加 に 或任何别的东西，我们只要说出时间，然后接着叙述在那个时间发生的事就可以了。**

在这个特定的句子里，「そのとき」的用意在于：就在爱丽丝一直在说没有什么有趣的事发生的那一刻，就在那时，这件事发生了。

そのとき、白いウサギがとおりすぎた。

白い 意思是 `white`；它是一个 い形容词。ウサギ 意思是 `rabbit`。而「とおりすぎた」由两个词组成，它在做一件我们在日语里会一遍又一遍、一遍又一遍见到的事。**它用一个动词的 い 词干来接上另一个动词，赋予它额外的含义。** 所以 とおる 意思是 `pass through`（穿过），すぎる 意思是 `exceed or go beyond`（超过、越过）。于是 とおりすぎる 把这两个词连在一起：とおる（穿过）；すぎる（越过），合起来意思是 `passing by`（经过、路过）。一只白兔经过。

![](../media/image46.webp)

そのとき、白いウサギ (white rabbit) とおりすぎた (passed by)。

---

>ふつうのウサギではなくて、チョッキをきているウサギだった。

![](../media/image595.webp)

> ふつうのウサギではなくて…

现在，ふつう 意思是 `ordinary`（普通），其余的你都已经知道了。**ではない 意思是 `it isn't / it wasn't`，我们把它变成 て形，因为这是一部分复合句**——我们上周看过复合句，对吧？ 

*（第 11 课，Dolly 给了 7，但可能是个错误，因为那里并没有 て形……不过也可以看看 5）*

所以，「ふつうのウサギではなくて」= `It was not an ordinary rabbit.`（那不是一只普通的兔子。）

> …チョッキをきているウサギだった。

チョッキ 意思是马甲；きる 意思是 `wear`（穿），所以「きている」意思是 `be wearing / be in the act of wearing`（正穿着）。**而 `だった` 当然是系词的过去时。** 

![](../media/image857.webp)

所以这句话是：`It was not an ordinary rabbit, it was a wearing-a-vest rabbit / it was a rabbit that was wearing a vest.`（那不是一只普通的兔子，那是一只穿着马甲的兔子。）

>ウサギはかいちゅうどけいを見て「おそい！おそい！」と言って、はしり出した。

![](../media/image56.webp)

> ウサギはかいちゅうどけいを見て…

かいちゅうどけい 不是一个我们会经常碰到的词，因为如今这种玩意儿已经不多了，但它是我们将会看到极多的某种东西的一个例子，那就是：在日语里，如你所知，**我们可以通过用 の 标记第一个名词来用一个名词修饰另一个名词**（或用 な，它是 だ 的一种形式）**但当我们不只是用一个名词修饰另一个名词，而是构成一个新名词时，我们也可以干脆把它们撞在一起。** 

**我们不必像处理动词那样对它们做任何修饰**（动词我们要把它们变成 い 词干），**但名词不能这么做，名词没有任何词干，它们不以任何方式修饰——所以，当你把两个名词放在一起造一个新名词时，你只是把它们彼此推到一起。这和我们英语里的做法是一样的，像 seaweed 或 bookshelf 这样的词。我们只是把两个名词推到一起造出一个新名词。** 

---

那么这个名词「かいちゅうどけい」的各部分：[懐中]{かいちゅう} 是一个稍微不寻常的名词——意思是 `in one's pocket or the inside of one's pocket`（在口袋里／口袋内侧），而 [時計]{とけい} 是一个非常常见的词——意思是 `clock or watch`（钟或表）（在日语里，不管是大钟还是小钟，我们都用同一个词），所以 [懐中時計]{かいちゅうどけい} 就是怀表。

而我们把「**ど**けい」而不是「とけい」的原因，就是《爱丽丝在汉字国》里爱丽丝所说的“ten-ten 挂钩”，**也就是说，当你像我们这里这样把两个名词推到一起，而第二个以 `t` 或 `k` 这样的尖锐音开头时，我们就把它换成对应的浊音，如 `d` 或 `b`。** *（＝Rendaku 连浊 - sequential voicing）*

![](../media/image899.webp)

::: info
它通常发生在：复合词中第二个名词有一个尖锐的训读（Kun’yomi）音，而该音有一个对应的浊音——h -> b、t -> d、k -> g、tsu/s -> z、sh -> j 等等。音读（On’yomi）复合词通常没有这种变化，有时，如果前面是 `n`，它也能触发这种变化。
:::

当然，在日语里你是通过给假名加上那两个小标记 ゛*(だくてん)* 来做这件事的，于是 と 变成 ど、た 变成 だ、く 变成 ぐ、さ 变成 ざ 等等。 

所以，比如，如你所知，あお 是蓝色，そら 是 `sky`（天空），当你把它们放在一起，你得到的不是 あおそら，而是 あお**ぞ**ら。我们把浊点放到那个尖锐的词上，爱丽丝把那个叫作 `ten-ten hooking`（浊点挂钩）。*（ten-ten，字面意思 `dot-dot`（点点），似乎是 dakuten 的口语叫法* ゛*）*

就好像那两个小点、那两只小爪子，勾进它前面的词里，把它们变成一个词。**这是一件你会经常见到的事。** 

就像在英语里你不能用任意两个名词这么做一样，但也有大量名词是由两个名词构成的，只要其中一个名词不是像 かいちゅう 这样稍微不寻常的，它们就非常好理解，就和在英语里一样。

然后我们有： 

『…「おそい！おそい！」と言って…』

## と 引用助词

现在，我们要看看这个 と 实际做什么，而随着我们进入更复杂的句子，像这句一样的三层复合句，我们就会开始看到它变得多么有用。

![](../media/image2.webp)

**と 在结构上实际做的，是把它所标记的东西**——那可能是像这样的两个词，也可能是一整段带有各种其他语法的内容——**它把它所标记的东西当作一段引用，并有效地把它变成一个单一的名词。**

---

所以一个 と 车厢，是一个用 と 标记的白色名词车厢。而随着我们往下走，我们会发现**它不仅用来标记人们说的话和人们想的事，还用来标记各种各样其他的东西。** 这节课稍后我们会有一个这样的例子。**但这个 と 结构本质上是在把被 と 标记的东西变成一个准名词，然后 と 再让它充当后面那个动词的修饰语。**

![](../media/image322.webp)

当它像那样是一段简单的引用时，动词会是 言う（说），但也可能是 考える（想）或 思う（想、觉得），不过它还可以是很多别的东西，稍后你就会看到。**所以这就是任何一个 と 标记的陈述的结构。**

『「おそい！おそい！」と言って、はしり出した。』

おそい 意思是 `late`（迟）。**而为了让它成为一个句子，我们显然必须在这里有一个零代词。** 所以兔子要么是在说 `It's late!`，要么是在说 `I'm late!`。

![](../media/image56.webp)

***ウサギは(zeroが)かいちゅうどけいを見て「おそい！おそい！」と言って、はしり出した。***

***ウサギ 至于 (它/他) 怀表 看了-and `late! late!` 说了-and 跑-冲了出去。***

在迪士尼版本里，当然，它是 `I'm late!`。

「おそい！おそい!」( `I'm late! I'm late!`)

**这一次我们不需要在 ウサギは言って 里说 と，因为我们已经有了句子开头处的 ウサギは，而这是一个复合句。** 所以复合句的后半部分有着和前半部分相同的主车厢、相同的主语。

『「おそい！おそい！」と言って…』

( <code>The rabbit said, **I**m late! I'm late!'</code>)

而那个 言って 又是一个复合的 言って，所以这次我们有一个三层深的复合句。

![](../media/image175.webp)

::: info
蓝框——被引用的兔子的话似乎也有一个 zeroが，因为意思是（我）迟了。
:::

兔子看了看它的表，它说「おそい！おそい！」，然后……它做了另一件事：

> はしり出した。

はしる 意思是 `run`（跑），出す 字面上意思是 `take out`（拿出），但这是我们在日语里会非常常见到的一种组合。再一次，我们用的是那个 い 词干，也就是主要的连接词干，把 はしる 连接到 出す。那它在这里是什么意思呢？

![](../media/image480.webp)

嗯，**那个 出す 当它连到一个动词上时，意思是那个动词的动作 `erupted`（迸发出来）。** 所以我们可以说某个人 泣き出した：[泣]{な}く 是 `cry`（哭），我们把 泣く 的 い 词干连接到 出す，而 泣き出す 意思是 `burst out crying`（突然哭起来）。我们可以说 笑い出す：笑う 是 `laugh`（笑），如果我们把 笑う 的 い 词干连接到 出す，我们就是在说 `burst out laughing`（突然笑起来）。而在这个情况下发生了什么？兔子突然冲出去跑起来——它撒腿就跑。

ウサギはかいちゅうどけいを見て「おそい！おそい！」と言って、はしり出した。

（兔子看了看它的怀表，它喊了一声 **I**m late! I'm late!'，然后冲出去跑了起来。）

![](../media/image793.webp)

>「ちょっとまってください」とアリスはよんだ。

![](../media/image228.webp)

「ちょっとまってください」是一个你在日语里会听到很多的短语。有时 ください 会被省掉。它是什么意思？ 

ちょっと 意思是 `a little`（一点）；まって 是 <code>[待]{ま}つ</code> 的 て形，意思是 `wait`（等）；而 ください 意思是 `please`（请）。它其实和 くれる 有关，那个我们上次谈过*（第 11 课）*；它也是指“给下来”——也就是 `please give down to me / please lower down to my level`（请给我下来／请降到我的水平），所以那是一种礼貌地说 `please give`（请给）的方式。但它不只是给一样东西，正如 くれる 和 あげる 那样，它不只是给一样东西，**它也可以是，如果你把它连到一个动词的 て形上，给出那个动词的动作。** 所以你看，它和我们上周学的那个 くれる 和 あげる 非常相关。

> ちょっとまってください

现在，因为这太常见了，很多时候当我们把一个动词变成 て形并对某人说时，它就有点像 てください 的缩略。「ちょっとまってください」意思是 `Please wait a little`（请稍等一下）。所以她是在请兔子停下；她想和兔子见一见面。

「ちょっとまってください」とアリスはよんだ。

所以我们又有了那个 と 助词，引用助词，当我们引用任何东西时都需要它，然后是 よんだ。「よんだ」：那是什么意思？嗯，我想我们以前碰到过 よんだ，对吧？它的意思是 `read`，`read` 的过去式。那是 読む 的 た 形——在这个情况下是 だ形。**但在这个情况下它不一样。它是 呼ぶ 的 だ 形。**

![](../media/image801.webp)

如果你还记得我们关于 て 和 た 形的那节课<sup>[[5]](./5-动词分组与-て形.md)</sup>，新浪潮组的动词，以 ぬ、ぶ 和 む 结尾的动词，它们的 て形都用 んで，た形都用 んだ。**所以 読む 和 呼ぶ 的过去形都是 よんだ。** 幸运的是，我们不太容易把“读”和“叫”搞混，对吧？这个 呼ぶ 意思是 `call`（叫）、`shout out`（喊出）。它可以在英语里 `call` 被使用的任何意义上表示 `call`。你可以叫某人的名字，你可以把一个苹果叫作柠檬（但你会是错的），或者你可以大声喊。

「ちょっとまってください」とアリスはよんだ。

（“请等一下！”爱丽丝喊道。）

でもウサギはピョンピョンとはしりつづけた。

![](../media/image836.webp)

::: tip
如果你想打出 [続]{つづ}ける，你必须打 tsuDUkeru。Dzu 会给出 `ｄず`。
:::

でも 意思是 `but`。はしる 意思是 `run`。我们先把 ピョンピョン 放一放。つづける 意思是 `continue`（继续）。所以再一次，我们有了这种拿一个动词的 い 词干的形式，はしる 变成 はしり，然后我们在它上面加上动词 つづける（继续）。所以「ウサギははしりつづけた」意思是 `The rabbit continued running`（兔子继续跑）。 

---

**ピョンピョン 是我们在日语里会经常见到的一种东西，那就是一个重复的词，它是一个音效。** 日语里有许许多多这样的词，\[例如\]「シクシク」，那是哭泣的音效。其中有些会是字面的声音，有些则描述各种各样的状态。所以我们后面会遇到很多这样的词。 

ピョンピョン 几乎就是一个字面的音效。它是某个小东西一路蹦跳的声音，你会听到这个非常多。反正我是听到很多，不过话说回来，我的很多朋友都是会一路蹦跳的小东西。所以 ピョンピョン 是那个声音，或者不完全是声音，它是……如果这是一部动画，你大概会听到那个声音，对吧，ピョンピョンピョンピョン……——但在这个情况下它不一定是你能听到的声音，而是那种感觉，那种像声音一样的感觉，某个小东西、小动物在跳、跳、小跳。 

所以，因为它是一只兔子，它不是像你跑步那样跑，它是以一种小跳、弹跳的方式跑，就像兔子那样。而这里要注意的一点是，我们说 ピョンピョンと。**所以再一次，我们用了那个引用助词。在这个情况下，我们用它来表明兔子是怎么跑的，而因为这严格说来算是一种音效，我们是在 `quoting`（引用）兔子发出的声音，以此告诉我们兔子跑的方式。它是以一种小跳小跳的方式跑的。**
