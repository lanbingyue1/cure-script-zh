# **58. 日语的复合助词。它们如何运作**

[**日语的复合助词。它们真正如何运作 | 第 58 课：助词的组合**](https://www.youtube.com/watch?v=iPiLVZoYhfM&list=PLg9uYxuZf8x_A-vcqqyOFZu06WlhnypWj&index=60&pp=iAQB)

こんにちは。

今天我们要讲 <code>combined particles</code>，或者说 <code>double particles</code>，或者教科书和日语语法网站给它们起的随便什么蠢名字。而我马上就会解释为什么我说它们是 <code>silly</code>。我说的是像 <code>には</code>、<code>にも</code>、<code>-とは</code>、<code>のが</code> 等等这样组合起来的助词。

而如果你去看那些网站，你会发现一大堆规则，比如 <code>you can use に with は and も, but you can't use it with が or で</code>；<code>you can use -と with this, but not that</code>，等等。而你不需要学任何这些规则。如果你理解正在发生什么、以及它为什么发生，这一切都完全合乎逻辑。这里没有什么随机的规则，只有直截了当的逻辑。

它在英语里所谓的日语语法中变得如此令人困惑，原因在于他们给出的不只是错误的答案。他们是在为错误的问题给出错误的答案。他们在问一些从一开始就根本不该被问的问题。

**其实根本不存在 <code>double particle</code> 或 <code>combined particle</code> 这样的东西。** 一直在发生的是，助词只是在像它们往常那样做它们的工作。

那么这些关于它们什么时候能、什么时候不能的随机规则又怎么说呢？嗯，所有这些实际上都基于助词是什么、以及它们实际在做什么。

那么，第一个要做的区分——教科书和网站从不做的区分——就是逻辑助词和非逻辑助词之间的区分。这绝对至关重要。

## 逻辑助词与非逻辑助词

![](../media/image109.webp)

那么，让我们先看看五个主要的逻辑助词。这些是告诉我们句子里正在发生什么的助词。它们给每个名词标上它在句子里扮演的角色，无论它是做某件事的人、被做的那个东西、被做那件事的对象、做那件事的地点，等等等等。

![](../media/image101.webp)

那么，第一件显然要理解的事是，你不能把这五个逻辑助词里的任何一个和任何别的逻辑助词组合起来。为什么不能？因为它们在做什么。它们给每个名词标上它在句子里的功能。一个名词实际上不能同时是超过一个词类，所以把这五个里的任何两个彼此组合起来，根本毫无意义。

---

但你能把它们与非逻辑助词组合，尤其是那两个非逻辑主题标记，は 和 も。你能组合它们，是因为它们在逻辑上不冲突。

は 和 も 不告诉我们任何关于一个名词在句子里做什么的信息。它只是把那个东西标记成一个主题，要么是为了让它成为句子的主题，要么是为了战略上的原因让它成为一个次主题，我们马上就会讲这个。

## 主要助词与次要助词

那么，接下来要知道的事是，那两个主要助词，或者说主要助词和次要助词，也就是，**が 和 を，不与非逻辑助词组合。**

![](../media/image517.webp)

它们为什么不组合？嗯，が 是主要助词：它必须出现在每一种句子里；を 是次要助词：它标记直接宾语。这意味着在任何直接他动的句子里，を 都必须存在，无论我们能不能看见它。

---

那么，我说的直接他动是什么意思？所有教科书和词典都把「他动性」和日语的自移动词、他移动词搞混。而某种程度上这是可以理解的，因为这两者之间有大量重叠。

**但它们不是一回事。**

那么让我们看看真正的他动性是什么意思。如果我说 <code>I walk</code>、<code>I sing</code>、<code>I eat</code>，这些都是自动词，因为我做这个动词，而我没有把它做给任何别的对象。它没有直接宾语。如果我说 <code>I sing a song</code> 或 <code>I read a book</code> 或 <code>I eat bread</code>，那么这就是他动的，因为动词有一个直接宾语。

那么，当我说 <code>directly transitive</code>，我的意思是那些直接作用于一个对象的动词。比如，我可以说 <code>I talk to Sakura</code>，但在英语里，如你所见，我们必须在那里有一个介词。

![](../media/image458.webp)

我们不说 <code>I talk Sakura</code>，所以我们不是直接他动，我们是通过一个介词这个媒介间接他动。

那么，日语有同样的区分。我们**不**说 <code>さくらを話す</code>，它在英语里会相当于 <code>I talk Sakura</code>。我们说 <code>さくらと話す</code> 或 <code>さくらに話す</code>。

![](../media/image534.webp)

那么，请不要带着「に 和 -と 这样的助词和英语介词是一回事」这个想法跑开。它们不是。如果你要把它们和欧洲语言里的东西作比较，你必须把所有逻辑助词和德语或拉丁语的格结构作比较。你可能不知道那些是什么，你也不需要知道，因为我用不需要欧洲语法知识的方式来建模它们。

但这里的要点是，它们不是介词，不过就我们这里的目的而言，我们可以说它们被使用在英语里介词被使用的相同情形下。

所以如果我们说 <code>I eat bread</code>，那是直接他动。如果我们说 <code>I talk to Sakura</code>，那是间接他动。在日语里，如果我们用 を 助词，那就是直接他动。如果我们用另一个助词，比如 -と 或 に，那就是间接他动。

在某些情况下，英语和日语会对什么是直接他动、什么是间接他动有分歧，但绝大多数时候它们实际上是一致的，因为这些是相当基本的人类交流因素。

---

那么，这里的要点是，这两个直接助词——如果我们说 <code>I hit Sakura</code>，任何地方都没有介词。这完全直接。我做打这个动作，我打某个东西，我打樱。我不是 打向 樱，也不是 朝着 樱打，也不是 被 樱打。

我直接打樱。那么，由于这两个助词的直接性，它们不能附加一个非逻辑助词。

所以，如果你想在这里用一个非逻辑助词，你可以这么做。但你这么做的方式永远只是简单地接上那个非逻辑助词，**并把那个逻辑助词省略掉**。

而因为这两个助词对每一句话都如此根本，它们在日语里能被听者理解。

所以，如果我们说 <code>さくらはなぐった</code>——<code>I hit Sakura</code>——这意思是 <code> *(zeroが)* さくらは**zeroを**なぐった</code>，

![](../media/image569.webp)

**但我们不说 <code>さくらはをなぐった</code> 或 <code>さくらをはなぐった</code>。** 因为你不能把任何东西放到这两个直接根本的逻辑助词和它们直接连接的那个东西之间。

所以现在我们就理解了几乎所有你将会听到的古怪规则的基础。你只需要记住这两个事实：**你不能把这五个主要逻辑助词里的一个和另外四个里的任何一个配对**，以及**你不能把非逻辑助词放在那两个主要助词 が 和 を 之前或之后。**

那么，一旦我们知道这些，我们还剩下什么，它又是怎么运作的？我们可以把非逻辑助词和剩下那些逻辑助词里的任何一个配对。而我们这么做的原因，不是为了造出某种奇怪的、不寻常的配对组合。我们只是同时使用两者的功能。

所以我们这里做的最直截了当的事，就是简单地把某个东西变成一个主题。如果我们说 <code> *(zeroが)* 冬には雪だるまを作る</code>，我们是在说 <code>In the winter we make a snowman.</code>

![](../media/image502.webp)

那么，我们可以说 <code> *(zeroが)* 冬に雪だるまを作る</code>。**我们不一定非要在那里有 は。**

那么我们为什么有时会选择在那里放一个 は 呢？嗯，在这个例子里，我们把它变成句子的主题。我们是在说 <code>here's winter/speaking of winter, this is what we do.</code>

而它也扮演 は 作为其造主题本性的延伸而总是扮演的其他角色。我做过 [**一个视频**](https://www.youtube.com/watch?v=9l_ZlQQU4ZE&ab_channel=OrganicJapanesewithCureDolly) 讲 は 的这些多重用法，所以如果你不熟悉这个，请去看一看，因为它对理解这里正在发生什么相当重要。

所以，我们把冬天造出一个主题，同时我们也在把冬天和其他季节区分开来。我们是在说 <code>冬には</code>——<code>As for winter, as opposed to the other seasons, we make a snowman.</code>

那么，如果你正在交谈的那个人来自一个非常非常冷的地方，他们可能会说 <code> *(zeroが)* 春にも雪だるまを作る</code>。

![](../media/image499.webp)

所以他们说的就是 <code>We make a snowman in the spring as well.</code> 所以我们可以用排他助词 は 或用包含助词 も。而两者都加上了那个程度的含义。

那么为什么我们这里有 に 呢？因为我们实际上需要 に。**我们需要 に 来标记我们在一个特定时间做一个活动这个事实。** 这是 に 的逻辑功能。而做完那个之后，我们也可以用它造出一个主题。而这正是我们这里在做的事。

在其他情况下我们可能说 <code>明日学校に行く</code>，那意思就是我明天去学校。如果我们说 <code>明日学校には行く</code>，言外之意就是我们要去学校，但我们不去他们以为我们可能去的别的地方。

如果我们说 <code>明日学校にも行く</code>，我们是在说我除了去某个你已经知道的别的地方之外，也去学校。

所以你看，在每一种这些情况里，我们的非逻辑助词只是给已经在那里的逻辑助词增添含义。它们不冲突，因为一个是逻辑的，另一个是非逻辑的，所以它们没有告诉我们相互矛盾的信息。
**它们告诉我们互补的信息。**

而这就是为什么你能那样使用它们，以及为什么你不能把一个逻辑助词和另一个逻辑助词组合，或者把一个非逻辑助词和另一个非逻辑助词组合。

---

那么，还有别的助词能和其他助词配对，但再一次，这整个配对概念是看它的错误方式。一如既往，助词只是在做它们做的事。

比如，の 助词，如果它是名词化的 の，那个把某个东西变成名词的 の，那么，比如，<code>泳ぐの</code> 是 <code>swimming</code>，**那个名词** <code>swimming</code>，那个叫做 <code>swimming</code> 的活动。

![](../media/image252.webp)

我们可以说 <code>泳ぐのが好きです</code>。我们可以说 <code>泳ぐのをします</code>。

**你可以把任何逻辑助词和 の 组合，因为那种 の 把它前面的东西变成实际上是一个名词，而一个名词可以接任何逻辑助词。**

它可以是一个更长的逻辑小句：<code>さくらと一緒に泳ぐのが好きだ</code>——<code>I like swimming together with Sakura</code>。／ **Sakura together with swimming pleasing is.**
::: info
多给了一点更字面的翻译以防万一，好き 是一个形容词性名词。不过还是以 Dolly 的为准。
:::
![](../media/image190.webp)

但要点是，一旦你把那个名词化的 の 放到它末尾，**当它是那个把某个东西变成名词的 の 时，你就把它当作一个名词来对待**。

而你拿一个名词做什么呢？你在它上面放一个逻辑助词，对吧？所以，这是简单的逻辑。
